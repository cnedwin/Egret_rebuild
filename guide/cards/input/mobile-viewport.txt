# Fit the page to a phone screen and its safe areas

`play`/`play3d`: `fit: 'expand'` fills the window; `portrait` fits turns. Pin edge controls with `game.pin(node, { right: 16, top: 16 })` or use `game.safe` in `arrange(game)` (see `knowledge-base/en/docs/screen-fit.md`). Self-laid page:

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```

```css
html, body { margin: 0; height: 100%; overflow: hidden; }
#stage { position: fixed; inset: 0; width: 100%; height: 100%; touch-action: none; }
.hud-top { padding-top: max(8px, env(safe-area-inset-top)); }
.touch-left { left: max(12px, env(safe-area-inset-left)); }
.panel { max-height: calc(100dvh - 22px); }
```

Later scenes: `node vendor/egret.mjs verify --screens --prepare test/prepare.mjs`; the trusted callback asserts readiness and returns the scene name.

Rules:

- Egret 5 `scaleMode` fixedWidth/fixedHeight/fixedNarrow/fixedWide are `fit` values; the stage follows the window. Pixel art uses `wholeScale: true` for whole device pixels per unit.
- Size the canvas in CSS; `createWorld3DView` resizes its drawing buffer. `maxPixelRatio` defaults to 2; the games use 1.5 to limit high-DPR cost.
- Use `100dvh`, not `100vh`: mobile address bars change the visible height.
- Pad edges using `env(safe-area-inset-*)` with `viewport-fit=cover`, including landscape notches.
- `touch-action: none` on the play area during play only. Menus and long lists (upgrade cards, settings) keep `touch-action: pan-y` so they still scroll.
- Keep HUD text, cards and buttons within short landscape viewports: the measured Samsung FPS run used 873 × 325 CSS pixels.
- `createWorld3DApp` quality `auto`: low for software, touch or height < 600 px; medium for ≤ 4 GB RAM. Custom renderers use `pickWorld3DQuality`.
- Let the player change quality and language on the title screen, and store the choice (in a `try`: private windows may refuse storage).
- Request fullscreen and pointer lock from a trusted press; offer recovery on denial. `await game.pointer.lock({ unadjustedMovement: true })` opts into raw movement; only result status `locked` confirms ownership. `unlock()` cancels acquisition. Use `locked` for later loss and the masks for independent mouse buttons.
