# Load models and files with progress, a deadline and a way to retry

FPS loads all its GLB art before the title appears. Its loader is a good pattern:

```js
const signal = AbortSignal.timeout(90_000);
let complete = 0;
const assets = await Promise.all(files.map(async file => {
  try {
    return await loadGltfFromUrl3D(new URL(file, base), { signal, maxBytes: 24 * 1024 * 1024 });
  } finally {
    onProgress(++complete, files.length);      // a bar, and "Loading game art 3 / 12"
  }
}));
```

Rules:

- Start loading at once, in parallel with making the engine and renderer, and await both before the title.
- Give every request one shared deadline (`AbortSignal.timeout`) and a size cap (`maxBytes`). A stalled request otherwise leaves a loading bar forever.
- Load each file once even when several roles share it; keep a map from file to promise.
- Count progress per file in a `finally`, so failures advance the bar too.
- Required art missing is an error screen with a reload button in the player's language, not a half-drawn game. Optional art falls back to models made in code (FPS keeps `?art=original` for comparisons).
- Dispose what was loaded when loading is abandoned. Each loaded asset has one `dispose()`.
- Add a version to file URLs (`?v=<build>`) so a new release is not served stale from a cache.
- Simplify and texture-compress bought or generated models before shipping; FPS and Rally keep a README beside them with source and changes.
- Load per quality: `pickQualityVariant({ low: 'hero-low.glb', high: 'hero-high.glb' }, quality)`.
- Many small files: pack them with `writeAssetBundle` at build time and read them with `openBrowserAssetBundle`, which fetches only the ranges asked for and can keep entries for offline play.
- Load what is not needed for the first screen after it appears (SnowTemple stages its characters after start-up), but prepare its shader programs before it is first drawn (see `prepare-programs`).

Engine failures carry codes: `ASSET_LOAD_FAILED` with the provider's error in `cause`, `WEB_RESOURCE_HTTP_STATUS` and `WEB_RESOURCE_DEADLINE_EXCEEDED` from the browser resource source.
