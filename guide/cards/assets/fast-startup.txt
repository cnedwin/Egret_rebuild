# A short way from opening the page to playing

Four games reworked their start. SnowTemple measured it on Windows: cold page load to first movement went from 3485 ms to 996 ms, and GLB data received before moving from 12.1 MB to 5.5 MB. The change was loading only what the first moment needs and the rest after the first frame. Lantern Shadows packed 260 modules into one file. Wulin turned its start into a playable prologue. Fetching per file is in `asset-loading`; this card is about what comes first.

Order of a start:

1. An illustrated loading screen in plain HTML and CSS, shown before any script runs.
2. Code and the first screen's files in parallel. List those files in `index.html` (`<link rel="preload">`) so the browser starts on them while the code is still arriving.
3. Engine, renderer and the hero's model together; draw the first frame with them.
4. After the first frame, the rest at two requests at a time: other characters, later scenes, music. Prepare their shader programs before they are first drawn (see `prepare-programs`).
5. If a late file is slow, the part of the game that needs it waits; the rest plays (SnowTemple's fight waits for its roles, the walk does not).

Rules:

- Measure "page opened to first input that moves something", cold and warm, and keep the numbers with the change. Also measure the bytes received by then.
- Many small modules cost a request each. Bundle the game and its vendored engine for release (Lantern Shadows: `tools/bundle.mjs`, one minified file), and many small assets with `writeAssetBundle`, read with `openBrowserAssetBundle`.
- Do not put two copies of a model into separate packs: SnowTemple split shared characters out of its scene packs into one pack of their own.
- Keep the start on the platform's own decoders where they suffice. Lantern Shadows never got past loading on iPhone until its images were decoded by the browser's image element and checked against the manifest's checksums.
- Show a failure over the stage, in words that can be read and copied, with a way to reload. A dead loading bar tells nobody anything.
- Give a long start something to do: a prologue, a title with settings, a tutorial card.
