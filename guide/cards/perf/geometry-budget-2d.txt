# A 2D frame goes black or freezes when shapes exhaust the geometry budget

A 2D frame capture allows 65,536 mesh triangles. `FRAME_BUDGET_EXCEEDED` also covers other limits. Read the full error and stack. If the failing budget is triangles, compare the geometry attached before the action with the geometry attached when it succeeds. Check both startup and the first frame with the effect active.

In Windlamp Post, three radial fills made up 33,124 of the distant station's 33,593 triangles. The first lantern's new glow alone added 16,384 triangles. The last object refused was an unchanged hidden marker worth 61 triangles. The rejected subtotal describes how far the capture got; it does not include later objects and is not a GPU timing measurement.

- Replace large decorative radial fills with a bright core and a few flat translucent shapes. Build the effect once and switch it on for the action.
- Attach distant sections as they are needed, and remove them when they leave play. Moving an attached object off camera or hiding it can still leave its geometry in the count.
- Replay the same action from the same start. Check that the new frame renders, the result stays visible, and the next input still works.
