# Model 3D creatures, props and buildings as smooth fields, not stacked boxes

Boxes merged with `createGeometryBuilder3D` show every seam: hard intersections, sharp edges, flat colours, no shade where parts meet. Build what the player looks at as a distance field instead, and let `createSdfGeometry3D` make the mesh: parts join smoothly, edges round, colours blend at the joins, creases are shaded.

Work in this order, and look at the model after each step with `node tools/model-preview.mjs <Playwright index.mjs> model.mjs model.png`, which draws it from four sides:

1. **Silhouette and proportion first.** Two to five large rounded parts (`sdfEllipsoid`, `sdfSphere`, `sdfBox` with `round`) in one `sdfUnion` with a `smooth` of about a tenth of the main part's size. Exaggerate: a big head reads better at game distance.
2. **Limbs, ears, tails, branches** as `sdfCapsule(from, to, radius, { radiusEnd })`, tapered; one side wrapped in `sdfMirror`. Vases and posts: `sdfLathe`; signs and blades: `sdfExtrude`.
3. **Carve** mouths, windows, doorways and hollows with `sdfSubtract`; give the cut a dark `color` so the hollow reads.
4. **Small details last, in their own group** with a small `smooth` (0.01): eyes, buttons, studs. In the big group they melt away.
5. **Surface**: `sdfDisplace` for rocks and bark; `sdfPattern` for spots, stripes, moss patches and gradients; mesh options `variation: { amount: 0.08 }` and `edges: { amount: 0.4 }`. Three to five colours with one accent.

```js
import { createSdfGeometry3D, createStandardMaterial3D, Mesh3D, sdfCapsule, sdfEllipsoid, sdfMirror, sdfSphere, sdfUnion } from '@egret/engine/world3d';

const fur = 0xf0a040;
const body = sdfUnion([
  sdfEllipsoid([0.6, 0.5, 0.72], { color: fur }),
  sdfSphere(0.42, { at: [0, 0.55, 0.55], color: fur }),
  sdfMirror(sdfCapsule([0.3, -0.2, 0.3], [0.33, -0.62, 0.36], 0.14, { radiusEnd: 0.11, color: fur }))
], { smooth: 0.1 });
const eyes = sdfMirror(sdfSphere(0.07, { at: [0.17, 0.68, 0.9], color: 0x111111 }));
const critter = new Mesh3D(
  createSdfGeometry3D(sdfUnion([body, eyes], { smooth: 0.01 }), { variation: { amount: 0.06 } }),
  createStandardMaterial3D({ vertexColors: true, roughness: 0.75 })
);
```

The material needs `vertexColors: true`; the colours and the baked shade are in the vertices. A mesh is capped at 8000 triangles unless `triangles` says otherwise: 1500 to 4000 suits a prop seen small or many times, 8000 to 15000 a hero seen close. A part thinner than two cells of `resolution` (64 along the longest side) disappears: raise it, or split the model. Make every model once while the level loads, never in a frame, or save it with `exportGlb3D`.

Crates and walls can stay boxes, but make them `sdfBox(size, { round: 0.03 })` so light catches an edge. For a model generated elsewhere or bought, `simplifyGeometry3D(geometry, { triangles })` brings it down to the same budget and keeps its texture seams and materials.
