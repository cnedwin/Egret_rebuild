# The clock of a rhythm game, from the music voice and event time stamps

A rhythm game judges a stroke against the music the player hears. Take the song's time from the music itself, not from frames, and the stroke's time from its event, not from the frame that handles it.

- **The song's time** is the music voice's `position`: it stands still while the mixer is suspended (a pause, a hidden page), so the chart pauses with it.
- **What is heard** is earlier than `position`, which counts what was given to the output. At engine `b5628eb` the two differed by about 41 ms in headless Chromium. `getOutputTimestamp()` on the context says which context time is sounding at which page time:

```js
const audio = scope.use(createBrowserAudio({ buses: ['music', 'effects'] }));
const voice = audio.mixer.play(backing, { bus: 'music', whileSilent: 'start' });

function heardAt(ms = performance.now()) {           // ms: performance.now() or event.timeStamp
  const { context, mixer } = audio, position = voice.position;
  if (mixer.state !== 'running') return position;
  const stamp = context.getOutputTimestamp();
  if (!(stamp?.performanceTime > 0)) return position - (context.outputLatency || 0);
  return position - (context.currentTime - stamp.contextTime) + (ms - stamp.performanceTime) / 1000;
}

window.addEventListener('keydown', (event) => {
  const time = heardAt(event.timeStamp) - settings.offset / 1000;  // the stroke, on the song's clock
  judge(kindOf(event.code), time);
}, true);
```

Rules:

- Judge with `event.timeStamp`, which is in `performance.now()` time; a frame-polled input (a gamepad) can be up to a frame late, so say so.
- Let players measure their own delay: play clicks at known times, take the median of (heard time − click time) over eight or more strokes, and subtract it. Real headphones, Bluetooth above all, add far more than a headless test shows.
- Render the whole backing as one sound and start it once; do not schedule each note as its own voice.
- Check in a browser that the clock never runs backwards and steps with page time between frames.
