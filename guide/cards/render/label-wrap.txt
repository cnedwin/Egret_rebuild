# Wrapping a label to a width

`browser.createLabel` and `browser.createAtlasLabel` break lines only at `\n` and have no width option. For a few lines of help or a hint, break the words yourself with `wrapPlayWords` of `@egret/engine/play`, which any game with that entry in its engine copy may import: it counts a Chinese, Japanese or Korean character as one unit of the font size and any other as about half, breaks at spaces, and between any two wide characters.

```js
import { wrapPlayWords } from '@egret/engine/play';

const lines = wrapPlayWords(help, 400 / 15);          // a width of 400 at font size 15, in units of the size
await browser.createAtlasLabel({ text: lines.join('\n'), fontSize: 15, lineHeight: 23 });
const below = lines.length * 23;                      // what comes under the text starts here
```

Rules:

- Wrap again whenever the language or the layout width changes; the count is an estimate per font size, so leave a little room.
- It does not keep closing marks (，。」) off the start of a line. For text that must break properly, or be selected and edited, use a paragraph: `chooseParagraphProvider` of `@egret/engine/web/paragraph` gives CanvasKit where it loads and a canvas provider where it cannot, as in a WeChat mini game.
- The quality check I3 of the games repository (no English cut off at 390 px) catches misses.
