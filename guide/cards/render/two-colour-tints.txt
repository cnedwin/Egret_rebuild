# Hit flashes and status colours from two-colour material tints

A hit flash, a frozen blue or a burning red needs no extra frames. A shared material has two colours: `light` multiplies the picture, and `dark` lifts its dark parts towards a colour. Every value is between 0 and 1, so `light` alone can only darken; a white flash comes from `dark` near white.

```js
import { createSharedMaterial2D } from '@egret/engine';

const TINTS = {
  flash: createSharedMaterial2D({ light: [1, 1, 1, 1], dark: [0.92, 0.88, 0.8] }),
  frost: createSharedMaterial2D({ light: [0.62, 0.86, 1, 1], dark: [0.05, 0.12, 0.25] }),
  burn: createSharedMaterial2D({ light: [1, 0.74, 0.56, 1], dark: [0.28, 0.05, 0] })
};
// Each frame, from the rules' state:
entry.body.sharedMaterial = entry.flash > 0 ? TINTS.flash : haunt.slow > 0 ? TINTS.frost : haunt.burn > 0 ? TINTS.burn : null;
```

Rules:

- Make each material once and share it; `createSharedMaterial2D` checks and freezes its input, and a value outside 0–1 is refused.
- Set `sharedMaterial` back to `null` for the plain picture.
- Keep a flash short (about 0.07 s) and drive its timer from hit events, so it shows even when many bolts land in one frame.
- `blendMode` changes only the blend of the material and keeps its tints.
