# play's rect and circle sit on their centre and are drawn once

`game.rect(x, y, w, h, color, into)` makes a sprite at `(x, y)` and draws `drawRect(-w/2, -h/2, w, h)` into its graphics: `(x, y)` is the centre, not the top-left corner, and the colour is baked in. The node has no `color` or `fill` to change later; `game.circle` is the same.

```js
// Parts placed by their centres: a boat and its sail.
const hull = game.rect(0, 0, 28, 6, 0x8d5f3c, layer);
game.rect(5.5, -10.5, 9, 11, 0xf7f1e2, hull);   // sail centre, relative to the hull

// Something whose colour or size changes: a sprite, redrawn.
const flake = game.sprite(() => {}, sky);
function paint(color, w, h) {
  flake.graphics.clear();
  flake.graphics.beginFill(color).drawRect(-w / 2, -h / 2, w, h).endFill();
}
paint(0xf4b8c6, 5, 3);   // a spring petal
paint(0xffffff, 4, 4);   // the same node as winter snow
```

Rules:

- Give `rect` and `circle` centre positions; a top-left habit puts every part half its size up and left.
- Use them for shapes that only move, fade or scale; tween `x`, `y`, `alpha`, `scaleX`, `rotation` freely.
- For a shape that changes colour or size (a season's particles, a selection frame, a bar), make one `game.sprite()` and redraw its graphics on change; do not remove and remake it every frame. A text, a shape or a sprite that `update` makes in each of 60 frames running is told as the warning `PLAY_MADE_EVERY_FRAME`, and listed by `node vendor/egret.mjs verify`.

Learnt from Magistrate of Peach Creek (ENGINE-NOTES 5), whose petals turn to leaves and snow with the season, and whose focus frame moves between plots.
