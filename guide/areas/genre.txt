# Kinds of game

A recipe for each kind of game the games repository holds: its loop, its files, the entries it uses, the cards to read first and what done means.

- [genre-tower-defence](../cards/genre/genre-tower-defence.txt) · play engine web · Waves along a path, towers on slots, a bot that plays every wave.
- [genre-survivors](../cards/genre/genre-survivors.txt) · play play3d engine world3d web · A horde, weapons that fire by themselves, pooled sprites and a capped field.
- [genre-match-cards](../cards/genre/genre-match-cards.txt) · engine web · A board of swaps and chains feeding a turn-based card battle.
- [genre-physics-puzzle](../cards/genre/genre-physics-puzzle.txt) · engine web · Aim or place, the world settles, a level proved solvable in Node.
- [genre-deduction](../cards/genre/genre-deduction.txt) · play engine web · Cases as data, an audit that proves each has one answer, long text.
- [genre-story-sim](../cards/genre/genre-story-sim.txt) · engine web · A calendar, places and people as data, every ending reached in Node.
- [genre-rpg](../cards/genre/genre-rpg.txt) · engine web world3d · Quests, a party and fights as rules; the main quest finished in Node.
- [genre-side-scroller](../cards/genre/genre-side-scroller.txt) · engine web · Fixed-step rules for the hero and bosses, a camera and tiles, a pad.
- [genre-rhythm](../cards/genre/genre-rhythm.txt) · play engine web · Charts as data, judging from event times against the music's clock.
- [genre-management](../cards/genre/genre-management.txt) · play engine web world3d · An economy stepped by time, pacing tuned by a bot, time away applied once.
- [genre-tabletop](../cards/genre/genre-tabletop.txt) · play engine web · Turns, calls and scoring as rules; thousands of hands played by bots.
- [genre-tactics-strategy](../cards/genre/genre-tactics-strategy.txt) · world3d play3d engine web · Rules, fog and AI tested AI against AI; a board picked by ray, names by atlas.
- [genre-action-3d](../cards/genre/genre-action-3d.txt) · world3d play3d · Fixed-step combat rules, tells and feel; programs prepared while loading.
- [genre-driving](../cards/genre/genre-driving.txt) · world3d play3d · Handling, track and rivals stepped in Node; scenery drawn by distance.
