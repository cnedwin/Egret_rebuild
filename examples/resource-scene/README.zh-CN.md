# 资源场景

[English](README.md) | 简体中文

两名角色共享真实 PNG 动画图集，同时保持独立的服装、播放状态和资源所有权。场景通过白鹭公共 API 组合显示变换、显式命中区域、鼠标选择、文字、异步加载和画面呈现。示例没有增加 SDK 接口或依赖。

完成仓库常规构建并启动静态服务后，打开本目录的 `index.html`。选择 **普通 Canvas** 使用二维呈现路径；选择 **实验性 WebGPU 场景**，在不透明三维背景上呈现纹理界面，浏览器需要支持该模式。不支持的模式会明确报错。两种模式的逻辑画布均为 192×128；普通 CSS 放大保留逻辑输入坐标。

点击角色图像或使用选择框选择角色，再进行换装、前进 0.125 秒、单独暂停、切换图集、裁剪、旋转、移除和重进。白色外框标识所选业务身份。移除所选角色后保留该身份，重进时创建新的显示实例。切换图集只让对应角色从动画首帧重新播放。

诊断面板可延迟下一张图像已经验证的字节交付，也可交付这些字节，或以 Error、`undefined` 拒绝交付。较新的换装请求等待、失败、取消或过期时，保留此前已经生效的服装。取消 SDK 需求不表示原生 fetch 或解码一定被中断。场景最多允许两项延迟交付、既有的四个 PNG 源任务、一份外部预热租约和 256 条活动记录。达到活动录入上限后仍可关闭。

两个角色分别获取独立租约，指向同一图集 Texture。每个身体借用自己的当前图集租约，并拥有独立的序列播放控制。服装使用单独的 Bitmap 资源槽：初始借用由应用所有，后续新租约由槽所有。图集切换成功时，显式更换完整租约和播放控制，再关闭旧所有者；另一角色的存活资源保持可用。规则遵循既有的[资源替换契约](../../knowledge-base/Cns/docs/位图资源槽规格.md)和[播放契约](../../knowledge-base/Cns/docs/时钟驱动序列动画契约.md)。

资源就绪、画面呈现完成和交互就绪是不同阶段。冻结的示例本地对象 `globalThis.egretResourceScene` 提供这些阶段、有限操作、当前真实场景视图、有界观察和最近一份完整原始 RGBA 回读。换装和图集操作返回真实请求 Promise；逻辑提交不等于 GPU 已完成。WebGPU 在提交前请求原始回读，并等待该回读及 Host 空闲；Canvas 在同步绘制后读取像素。

**回放保存的初始帧**要求场景没有等待工作。它先关闭原 Session、provider、字体和 Host，再在同一浏览器 realm 中用新的原始 Host 渲染保留的真实帧和场景。回放 Host 关闭后，示例进入挂起状态。**重建场景**进一步创建新的画布、Host、Engine、provider、字体、缓存和显示实例。封闭的版本 1 业务快照保留选择、在场状态、已生效服装、图集和暂停策略；播放相位从零开始。这是显式重建，不提供设备丢失恢复或跨进程存档格式。

红绿徽标和六张 PNG 均记录原始字节与来源。Ahem 用于指定的 `X X`/`XX` 场景。本地提供的 Noto Sans SC normal-400 发布者子集只用于 `左侧 已选择` 和 `右侧 已选择`。原始字体和许可证字节保持不变。`tools/resource-scene/reference/` 中的独立 Canvas 参考没有使用应用或白鹭文字 provider 生成；有限验收仅适用于记录的字体、浏览器和 Windows 环境。通用中文排版、字体回退、输入法、移动设备行为及性能保持开放。

源码收集器先校验十四个原始 import-map 别名，再按原字节提供 HTML。它锁定有限的应用、公共 SDK 源码及实际编译产物和声明闭包、固定资源与参考，以及声明依赖 robust-predicates 3.0.3 的物理所有者。Canvas 静态依赖排除可选 GPU 场景。错误映射、资源身份和模块权限会被拒绝，不会自动修正。

专项 CPU 与编码检查覆盖所有权、取消、最新请求生效、动画和真实场景组合。实际浏览器呈现、固定字体比较、错误对照和最终交付各自验收。[集成记录](../../knowledge-base/Cns/docs/resource-scene-integration.md)记录已接受的环境与结果。完整 UI、导入或带动画的三维角色、完整 Spine 支持、目标设备性能和生产宿主仍须完成各自的验收。
