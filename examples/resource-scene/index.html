Resource scene / 资源场景

Two pilots share an animated atlas and change outfits independently. Select a pilot in the scene or use the controls below.
两名角色共享动画图集，可独立换装。点击场景中的角色，或使用下方控件选择。

Canvas 2D / 普通 Canvas Experimental WebGPU scene / 实验性 WebGPU 场景

Canvas presents the 2D scene. The experimental WebGPU profile adds a fixed opaque 3D background with the same screen UI; it requires a supported browser.
Canvas 呈现二维场景。实验性 WebGPU 模式在同一屏幕 UI 后加入固定的不透明三维背景，需要浏览器支持。

Preview / 场景预览

The selected pilot has a white surround. Selection stays with that pilot when it is removed, and returns with it on re-entry.
被选角色带白色外框。移除后保留其选择身份，重新进入时恢复选择。

Pilot and outfit / 角色与服装

The committed outfit stays visible while a change is pending, fails or is cancelled.
换装等待、失败或取消时，保留此前已生效的服装。

Animation and view / 动画与视图
Atlas and presence / 图集与角色进出

Changing the atlas starts that pilot's animation from the first frame. The other pilot keeps its own playback.
更换图集后，该角色从首帧开始播放；另一角色保持独立播放。

Scene session / 场景会话

Rebuild is available when the scene has no pending work. It retains the committed choices and restarts animation from the first frame.
无等待工作时可重建场景，保留已生效的选择，并从动画首帧重新开始。

Resource delivery diagnostics / 资源交付诊断
Pending delivery / 等待交付

These controls delay or fail delivery of fetched image bytes. Cancelling an outfit change does not promise that the underlying image work stops.
这些控件延迟或拒绝已获取图像字节的交付。取消换装不表示底层图像工作一定停止。
