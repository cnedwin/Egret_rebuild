# Explicit Canvas text example

English | [简体中文](README.zh-CN.md)

This small application connects the public WC1 Canvas text provider to the public TF1 TextField and existing CanvasHost. Ahem is a geometric test font: `X` becomes a square block, spaces remain blank, and the readable source remains ordinary DOM text. On 2026-10-11, an actual default desktop Edge smoke check completed initial rendering, replacement, blank text and explicit closing, with zero browser errors and no remaining owned font or Canvas. This interaction check provides no independent pixel-oracle, mobile or performance acceptance.

From the repository root, install the existing locked dependencies with `pnpm install --frozen-lockfile --ignore-scripts`, then run `node tools/build.mjs`. The checkout must already contain the adopted WC1 `@egret/engine/web/text` entry; an older build cannot run this example. Start the existing `node tools/serve-canvas.mjs` server, keep its printed host/port, and replace the URL path with `/examples/canvas-text/index.html`. Stop the server with Ctrl+C. Serve over loopback HTTP or HTTPS; do not open the HTML as a file. No new dependency, download installer, browser flag or server tool is introduced.

The import map resolves the built public engine entries and their existing package dependencies. Its existing internal frame-state mapping supports the host's package implementation; application code imports only public engine entries. The opted-in text graph is explicit. Opening an ordinary default engine entry alone does not import this example or its font provider.

The application fetches its local, retained Ahem asset, checks the exact SHA-256, constructs a uniquely named FontFace from those bytes, awaits `face.load()`, and adds only that face to `document.fonts`. It then checks that `document.fonts.load()` selects exactly its owned face, that the face is loaded and a member of the set, and that readiness succeeds. The UI accepts only documented Ahem `X`, space and explicit line breaks, at most 12 columns and four lines. These are example layout choices below existing limits. Empty text is allowed. The textarea follows ordinary browser newline handling; it is not the native LF/CRLF byte-equivalence test.

This selected-face check is stronger than `document.fonts.check()` alone, which can succeed for fallback. It is still a bounded application selection check for the retained font/subset, not a universal no-fallback, glyph-coverage or pixel-accuracy promise. The provider never owns or loads fonts. The application keeps this font environment stable during pending work. If extending the example to change fonts, first settle outstanding work, change only owned faces, call `cache.invalidate()`, and explicitly prepare again. No automatic generation observer is installed here.

After font selection, the application creates CanvasHost/Engine, an Engine-owned Scope, the cache with `createCanvasTextRasterProvider()`, and `createTextField(engine, scope, cache)`. It sets the complete request, awaits `field.prepare()`, attaches the field, and explicitly calls `engine.renderFrame()`. The fixed style is normal 400, size20, lineHeight24, density1, English locale, ltr, blue fill. The field is positioned at (24,24) on a 320×160 surface. No pixels are read by this example and no expected image is synthesized.

Edit the text and press **Prepare and render** to perform one replacement. Only one request is pending at a time; repeated clicks while busy are ignored, with no queue or retry. The previous committed source and pixels remain while the next preparation is pending. A failed operation closes the session and reports the retained first cause. DOM status, source text and controls remain the teaching interface; the Canvas is labelled as a geometric image.

Press **Close and await cleanup** before leaving. The `finally` path waits for the active operation, disposes the field, Scope and cache, really awaits `cache.whenIdle()` and `engine.dispose()`, deletes only its FontFace, removes only its listeners, resets the owned Canvas and removes it. Every cleanup is attempted; later errors do not replace the first failure, including an original thrown `undefined`. Success is displayed only after these waits. Native font loading has no AbortSignal and a close during that load waits for its settlement. `pagehide` requests the same cleanup, but the browser cannot be forced to await it during navigation; use the explicit button to observe completion. Reload the page to start another session.

This is an application example, not an independent native oracle or acceptance receipt. Current WC1 native Canvas/textured-WebGPU verification belongs to separate fixtures and collectors. Historical T1/TF1 CPU results, the old Font B3 slice and five renderer regression routes do not prove this current field/provider path. No CJK, phone, performance, physical reclamation, full T2, general UI, Spine or publication claim follows from this source.
