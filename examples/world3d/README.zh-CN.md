# World3D 示例

[English](README.md) | 简体中文

本示例用 `@egret/engine/world3d` 构建保留式 3D 场景，并用 WebGL2 或 WebGPU 渲染器绘制。显式 Engine 时钟通过 `createWorld3DView` 驱动动画和渲染。

## 运行

使用 Node.js 26.7.0 和 pnpm 11.25.0，在仓库根目录运行：

    pnpm setup:dev
    pnpm example:browser

打开 `http://127.0.0.1:4173/examples/world3d/index.html`。添加 `?backend=webgpu` 或使用页眉中的链接切换后端。

## 展示内容

- 平行光、聚光灯和点光源下的标准、Phong、Lambert 和无光照材质，程序化天空同时用作背景和环境。
- 平行光和聚光灯的阴影。
- 400 个带逐实例颜色的实例化立柱。
- 一根绑定四块骨骼并由剪辑驱动的立柱，以及一个带变形目标的球。
- 一个粒子发射器和一个精灵。
- 第二台相机渲染到渲染目标，并显示在场景中的屏幕上。
- 用鼠标或触摸环绕、平移和缩放。点击物体可高亮。

页眉按钮切换阴影、粒子和线框。状态行显示绘制调用数、三角形数和存活粒子数。

## 功能展示

打开 `http://127.0.0.1:4173/examples/world3d/features.html`（或点击页眉中的链接），可在一个场景里查看较新的功能。页眉按钮让相机在三个区域之间切换：

- **表面**：薄玻璃、实心玻璃和磨砂玻璃会偏折并染色后方的棋盘墙；另有丝绒光泽、清漆、卡通着色、使用第二套 UV 的光照贴图、一次绘制的 240 个合批石子、一条宽线和挤出文字。“Font / 字体”可加载任意 TrueType 文件，“Text / 文字”用它重写标题，支持中日韩字体。
- **物理**：箱子金字塔、凸包岩石、一串重物组成的绳索、带限位和马达的铰链门、能带着箱子移动的平台，以及一面薄玻璃墙。“Shoot / 发射”从相机位置发射开启连续碰撞的高速弹丸。
- **编辑**：点击物体即可选中，物体会被描边并出现变换操纵器。“Move / 移动”“Turn / 旋转”“Size / 缩放”切换手柄，“World / 世界”切换手柄朝向。

“Post / 后处理”“SSAO”“Depth of field / 景深”和“Shadows / 阴影”开关对应效果。功能展示页已在使用软件渲染的无头 Chromium 中以 WebGL2 运行，并用真实指针事件拖动过手柄；尚未在真实 GPU 上运行，也未经 WebGPU 画布呈现和真人操作验证。

## 限制

本示例展示渲染与交互。桌面 Edge 和 Android 真机 Chrome 均已检查两个后端的可见输出、阴影开关与释放行为。性能、真人手势与更广泛的设备覆盖仍待验收。范围和待完成事项见 [World3D 契约](../../knowledge-base/Cns/docs/world3d.md)。
