Bitmap buttons
位图按钮

Press either red button with the primary mouse button. Blue means pressed; gray means disabled.
用鼠标主键按下任一红色按钮。蓝色表示按下，灰色表示禁用。

Changing the renderer starts a fresh session. WebGPU requires browser support.
切换渲染器将启动新会话。WebGPU 需要浏览器支持。

Starting / 启动中

Release inside to activate once; release outside or move focus away from the browser window to cancel. Both buttons share one input and one original atlas. Disposing the first leaves the second usable.
在按钮内松开可激活一次；在外部松开或使浏览器窗口失去焦点可取消。 两个按钮共享同一输入和同一原创图集。释放第一个后，第二个仍可使用。

Saved-up replay presents the original captured frame without changing live controls. Show live returns to their current state. This is a desktop mouse example, not a complete UI or layout system.
重放抬起帧会显示原始捕获画面，不改变当前按钮。点击“显示当前状态”可返回当前画面。 这是桌面鼠标示例，不代表完整 UI 或布局系统。
