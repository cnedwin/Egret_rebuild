Prepared display subtree / 候选显示子树

Prepare uploads a detached green Mesh and cyan Bitmap. The red scene remains visible. Commit changes the CPU tree; Submit presents the staged frame.
准备会上传离线的绿色网格与青色位图，红色场景仍然可见。提交只替换 CPU 显示树；呈现才提交已上传的帧。



Use WebGPU or WebGL2. This example does not promise atomic CPU/GPU publication, submission-failure rollback, device recovery, or Spine state preservation.
本例不承诺 CPU/GPU 原子发布、提交失败回滚、设备恢复或 Spine 状态保留。
