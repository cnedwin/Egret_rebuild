# 可展开和收起的树

[English](README.md) | 简体中文

一个门派有四个堂口，每个堂口两队，每队五名成员：共五十二个项目，其中只有所有祖先都已展开的项目才会显示。显示出来的部分是一个托管列表，所以只有显示出来的部分才有对应的行。按下可以展开或收起堂口和队伍，并选中被按下的项目；方向键在项目之间移动，也可以进入和退出项目。对辅助技术来说，它是一个标题之下的一棵树。

## 运行

构建各个包，以仓库根目录提供服务，然后打开页面：

```text
node tools/build.mjs
node tools/serve-canvas.mjs
```

记下服务器输出的主机和端口，在那里打开 `/examples/ui-tree/index.html`。浏览器支持 WebGPU 时页面用 WebGPU 绘制；加上 `?backend=webgl2` 则使用 WebGL2。

## 可以尝试

- 按 **乙队 / Second squad**。它展开：五名成员出现在它下面，它同时被选中。再按一次就收起。下面还有项目的项目带有一个标记：展开时是一条横线，收起时是一个十字。
- 按下一名成员。他被选中；他下面没有可以展开的内容。
- 按 **丹房 / Alchemy**。这个堂口连同下面的一切一起收起。再次展开时，其中原先展开的队伍仍然是展开的。
- 点一下画布，然后只用键盘。Tab 移到树上。上下键、Page Up、Page Down、Home 和 End 在显示出来的项目之间移动。右键展开已收起的项目，或移到已展开项目的第一个子项目。左键收起已展开的项目，或从其他项目移到它的上一级。空格或回车选中。
- 展开几个堂口：树比它的窗口长，可以用滚轮和滚动条移动。

## 工作方式

| 部分 | 来源 |
| --- | --- |
| 门派 | 应用中一个包含五十二个项目的映射，每个项目有名称、深度、上一级项目和下一级项目，另有一个记录哪些项目已展开的集合 |
| 显示的部分 | 所有祖先都已展开的项目，按顺序作为 `createUiRoot` 虚拟列表的记录。展开或收起一个项目就给列表一个新的数据源；列表会让顶部的那一行留在视野内 |
| 一行 | 为它的项目只绑定一次。项目是否展开是绘制出来的，而不是绑定进去的；它排在第几位，在按键需要时从顺序中读取 |
| 按下 | 绑定的 `context.target`，加上 `createHoverControl` 和 `createActionControl` |
| 按键 | 每一行一个 `'action'` 类型的 `createControlKeys`，用于空格和回车；方向键等其他按键由页面从行的按键事件中读取。`keyboard.tabStop` 让整棵树成为一个停靠点 |
| 把焦点所在位置收起来的项目 | 接过焦点：原先持有焦点的行已经不在了，这个项目在提交之后被显示并获得焦点 |
| 滚动条 | `createScrollControl`，每次提交之后用 `setLengths` 告知显示部分的新长度 |
| 语义 | `createUiListSemantics`，使用 `role: 'tree'`：`describeRow` 给出每个项目的 `level`、有子项目时的 `expanded`、`selected`，以及它在同一父项目之下的 `position`。标题是一级 `heading` |

**每个项目都直接位于树的内部。**项目的深度由它的级别说明，而不是靠嵌套，这正是列表的行可以成为树的项目的原因。

**它的位置是在同级之中的位置。**某个堂口的第二队是两队中的第二队，无论它在列表的第几行。

参见[语义](../../knowledge-base/Cns/docs/ui-semantics.md#树)、[托管列表](../../knowledge-base/Cns/docs/ui-data-panel.md)和[控件状态](../../knowledge-base/Cns/docs/ui-controls.md)的指南。

## 检查

```text
node examples/ui-tree/verify.mjs <Playwright index.mjs 的绝对路径> <新的输出目录的绝对路径> [software]
```

省略第三个参数时启动已安装的 Edge（有界面）。使用 `software` 时由 Playwright 自带的浏览器以无头方式和软件渲染运行。六个场景各写出一张截图和 `report.json`：开始时浏览器计算出的标题和树，包括每个项目的深度、是否展开和所在位置，以及从屏幕读取的初始状态；按下展开、收起和选中，包括把一个下面有已展开内容的堂口收起；只用键盘，包括进入和退出项目的每一个按键，以及 Tab 离开画布；用指针把焦点所在位置收起来的项目，以及树比窗口长之后的滚动；辅助技术的请求；以及手机配置。它们在无头 Chromium 的软件 WebGL2 上通过。

输入是通过自动化协议注入的。没有运行真人操作、实体鼠标、手指或键盘、读屏软件或其他辅助技术、硬件 GPU、WebGPU、Edge、Safari、Firefox 和真实手机。按下一个有子项目的项目总是会展开或收起它：没有单独可按的标记。不能同时选中多个项目，不能通过键入首字母找到项目，手指也不能平移各行。
