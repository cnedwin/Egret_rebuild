# UI 数据面板示例

[English](README.md) | 简体中文

这个有限桌面示例使用已构建的公开 `@egret/engine`、`@egret/engine/ui`、文字、浏览器指针以及共享 WebGPU/WebGL2 入口。30 行使用稳定键，行高按 24/40/64 循环，包含原创纯色、已校验位图和 Ahem X/空格显式文字行。Engine 负责渲染、裁剪和行命中；DOM 按钮只是调用公开设置方法的示例控件。

逻辑场景为 960×640。面板 A 初始位置 (24,32)，尺寸 420×360、密度 1；调整后为 600×480、密度 2，再移动至 (48,64)。滚动 92 对应 row-02 内偏移 28；滚动 640 触发行回收，再返回 92。延迟替换期间保留完整旧行，点击完成后发布高 80 的洋红色 row-02。面板 A 初始与调整尺寸时均明确指定列表宽高，并保留当前数据源身份。面板 B 是位于 (700,12)、尺寸 200×148 的 Engine 纵向容器：顶部高 20 的横向工具栏由宽 96 的蓝色和宽 104 的棕色纯色叶节点组成，下方 200×128 列表仍从全局 y=32 开始。工具栏是装饰节点，不产生行命中；既有列表行位置保持不变，B 持续独立可用。关闭会释放两个根、输入、文字缓存、字体和 Engine。

执行 `pnpm setup:dev` 和 `pnpm example:browser`，然后打开 `http://127.0.0.1:4173/examples/ui-data-panel/index.html?backend=webgpu`，或将后端改为 `webgl2`。现有示例服务和有限验证器将精确 import map 解析到已安装的固定依赖。公共示例与验证器均不直接导入 SDK 私有文件。

构建冻结并完成审阅后执行：

```text
node examples/ui-data-panel/verify.mjs --playwright <已安装的-playwright-1.62.1-包绝对路径> --output <仓库外全新绝对输出目录>
```

示例内验证器在浏览器启动前冻结字面夹具、源码/声明/配置、已构建模块的字面导入闭包、原始资产和来源记录，随后以默认配置启动无额外参数的无头 Edge。两个后端分别检查纯色内部及裁剪像素、真实鼠标命中、滚动/尺寸/位置/回收、延迟旧完整帧、保留帧重放和清理，保存全帧 RGBA、截图、源码哈希、命中序列及清理状态。以输出 `result.json` 为准：实现或夹具测试不等于浏览器验收；不可用后端保持 OPEN。

精确像素域排除每行局部 x 40..64、y 4..16 的文字抗锯齿区域，不据此声明通用字体/后端容差。文字仅使用 TF1 显式行。此示例不建立段落、塑形、键盘/原生输入、焦点/IME、移动端/实体触摸/笔、自动滚轮策略、完整控件/无障碍、物理内存、时序或容量验收。见[来源记录](PROVENANCE.zh-CN.md)。
