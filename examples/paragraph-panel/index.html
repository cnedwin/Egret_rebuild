Paragraphs inside Engine UI / Engine UI 中的真实段落

The left column and right virtual list use the same readonly paragraph SDK. Wrapping and font metrics determine their heights. Narrow the column, enlarge the type or increase minimum line height to observe committed layout changes.
左侧普通布局与右侧虚拟列表使用同一个只读段落 SDK。换行与字体度量决定实际高度，可调整宽度、字号和最小行高。

Loading the optional paragraph backend and explicit fonts / 加载可选段落后端与指定字体

Uses bundled, identified Noto Latin, Arabic and CJK fonts. The backend and these fonts are optional example resources, not a default engine download. Final-line bidi reset and ordering use the native line API. Full script/font coverage, native IME, physical touch devices and performance acceptance remain open. DOM buttons are example controls.
示例携带具有明确身份的 Noto 拉丁、阿拉伯与中日韩字体，后端与字体属于可选示例资源，并非引擎默认下载。最终行双向文本重置与排序已接入原生行接口；完整文字和字体覆盖、原生输入法、实体触屏及性能验收仍未完成。DOM 按钮仅用于驱动示例。
