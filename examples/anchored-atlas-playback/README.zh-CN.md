# 锚点图集播放示例

[English](README.md) | 简体中文

工程预览 0.53.0 · S107 / V058。本示例将一份真实资源租约、具名 SpriteSheet 裁剪、Engine 时钟和 Bitmap 显式枢轴串联起来，不新增 Engine API、运行时依赖或自动定时器。

使用仓库固定 Node 构建（`node tools/build.mjs`），通过普通本地 HTTP 静态服务器提供仓库根目录，然后打开 `/examples/anchored-atlas-playback/`。显式 import map 解析已构建的公开包入口。默认使用 Canvas；可通过选择器或 `?backend=webgpu` 选择 WebGPU，后者需要兼容浏览器及 localhost 等安全上下文。后端不可用时会明确显示；切换后端会重新加载并创建新会话。

## 操作场景

| 控件 | 结果 |
| --- | --- |
| Step 0.125 s／前进 | 绝对游戏源时间增加 0.125，并显示当前帧。 |
| Pause／暂停 | 暂停播放，不推进时间、不渲染。 |
| Resume／恢复 | 恢复播放，不消耗暂停间隔、不渲染。 |
| Replay baseline／重放首帧 | 显示精确保存的首个红帧；当前动画和时间不变。 |
| Show live／显示当前帧 | 捕获并显示当前状态，不推进时间。 |
| Close／关闭 | 立即拒绝新操作，并等待实际清理。 |

普通 192×192 预览将 Bitmap 放在 (96,96)，枢轴为 (4,3)，缩放为 (8,8)，因此可见矩形为 (64,72,64,48)。`?preset=verification` 使用 24×24、DPR 1、位置 (12,12)、枢轴 (4,3)、单位缩放及透明黑清屏，矩形为 (8,9,8,6)。复现指定后端时，可显式加入 `backend=canvas` 或 `backend=webgpu`。

就绪时，源时间 0 显示红色；前进至 0.125 显示蓝色。暂停后前进至 0.25，蓝色仍暂停；恢复后前进至 0.375 显示红色，再前进至 0.5 显示蓝色。重放显示保存的红色，而当前状态仍为 0.5 的蓝色；显示当前帧则恢复蓝色呈现。只有“前进”推进时间。

## 资源与退役

原创 16×6 RGBA 图集中，第 0–7 列为不透明红色，第 8–15 列为不透明蓝色。这是第一方 Apache-2.0 数据，不使用外部美术、字体、编解码器或网络资源。提供器创建自己的 Texture；资源 Scope 按顺序采用唯一真实租约、sheet 和 Bitmap，动画 Scope 拥有控制器。sheet 与播放均借用同一原始租约，不额外获取租约。

关闭先退役动画，再退役资源，等待所有实际启动的准备任务，然后等待 Engine／宿主关闭。重复关闭共享同一个 Promise。准备仍挂起时，只有原始任务完成后才能认定安全完成；若取消发生于 Texture 创建前，则没有需要销毁的 Texture。不安全的宿主关闭仍是失败。活包装对象退役后，保存帧继续保留不可变的原始图像像素。页面退出清理仅作尽力处理。
