# 行囊

[English](README.md) | 简体中文

二十四个格子，四行六列，其中一些放着一叠物品。行囊是一个键盘停靠点，带有可以沿两个方向移动的光标。旁边显示光标所在的物品是什么，以及三个按钮；下面的一行说明刚才发生了什么。对辅助技术来说，行囊是一个由行和单元格组成的网格。

## 运行

构建各个包，以仓库根目录提供服务，然后打开页面：

```text
node tools/build.mjs
node tools/serve-canvas.mjs
```

记下服务器输出的主机和端口，在那里打开 `/examples/ui-inventory/index.html`。浏览器支持 WebGPU 时页面用 WebGPU 绘制；加上 `?backend=webgl2` 则使用 WebGL2。

## 可以尝试

- 按下一个格子。光标移到那里，行囊旁边的面板说明里面放着什么。
- 点一下画布，然后只用键盘。Tab 移到行囊。方向键移动光标，到边缘为止；Home 和 End 到这一行的两端，加上 Control 则到第一个和最后一个格子；Page Up 和 Page Down 到这一列的顶端和底端。
- 回车或空格使用一份光标所在的物品。用掉最后一份后格子变空。精铁和灵石不能使用：行囊下面的一行会说明，其他都不变。
- **使用 / Use**、**丢弃 / Drop** 和 **整理 / Sort** 分别使用一份、丢弃整叠、把空隙收拢。无事可做的按钮会被禁用并离开 Tab 顺序；如果它正持有焦点，焦点交给行囊。

## 工作方式

| 部分 | 来源 |
| --- | --- |
| 行囊 | 应用中的一个二十四格数组和光标的下标。没有控件拥有它们 |
| 键盘停靠点 | 在容纳所有格子的显示对象上调用一次 `keyboard.registerTarget`。页面从它的按键事件中读取方向键、Home、End、Page Up 和 Page Down 并移动光标；在边缘时也接管这些键，所以页面不会滚动 |
| 回车和空格 | 同一个显示对象上的 `'action'` 类型 `createControlKeys` |
| 指针下的格子 | 各有一个 `createHoverControl` 和一个 `createActionControl`。按下时移动光标，并把焦点交给行囊，不显示焦点环 |
| 光标 | 格子后面的一个边框：键盘显示焦点位置时是亮色，其他时候是暗色 |
| 会变化的文字 | 每个图标字、数量和每一行各一个文本对象；一行文字在准备期间再次变化时，会按最后的内容再准备一次 |
| 语义 | 一个带 `extent` 的 `grid`，四个带 `position` 的 `row` 节点，以及二十四个说明 `selected` 和所在列的 `gridcell` 节点。行囊持有焦点时，光标所在的单元格是持有焦点的节点。面板是包含 `text` 的 `group`，那一行文字是 `status`，按钮是 `button` 节点 |

**一个停靠点，而不是二十四个。**Tab 在行囊和按钮之间移动。在行囊内部由方向键移动，这正是网格对键盘的含义。投射把光标所在的单元格指明为画布的活动后代。

**空格子也是单元格。**它有一个说明自己为空的名称，光标也可以停在上面，所以行囊的形状对每一位使用者都相同。

参见[语义](../../knowledge-base/Cns/docs/ui-semantics.md#网格)、[控件状态](../../knowledge-base/Cns/docs/ui-controls.md)和[键盘](../../knowledge-base/Cns/docs/keyboard-focus-input.md)的指南。

## 检查

```text
node examples/ui-inventory/verify.mjs <Playwright index.mjs 的绝对路径> <新的输出目录的绝对路径> [software]
```

省略第三个参数时启动已安装的 Edge（有界面）。使用 `software` 时由 Playwright 自带的浏览器以无头方式和软件渲染运行。六个场景各写出一张截图和 `report.json`：开始时浏览器计算出的网格及其行列数和序号，以及从屏幕读取的初始状态颜色；按下移动光标，以及按钮的使用、丢弃和整理；只用键盘，包括光标在边缘和不在边缘时的每一个按键、不能使用的物品、按钮进入和离开 Tab 顺序、页面没有滚动，以及过了最后一个停靠点后 Tab 离开画布；在页面中观察那一行 status，文字在原有的元素内部变化；辅助技术对单元格和按钮的请求；以及手机配置。它们在无头 Chromium 的软件 WebGL2 上通过。

输入是通过自动化协议注入的。没有运行真人操作、实体鼠标、手指或键盘、读屏软件或其他辅助技术、硬件 GPU、WebGPU、Edge、Safari、Firefox 和真实手机。物品不能从一个格子拖到另一个格子，叠放不能拆分或合并，行囊也不滚动：它有多少行就显示多少行。
