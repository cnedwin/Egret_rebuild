# WebGL2 等距地图示例

[English](README.md)

示例通过白鹭浏览器公共接口绘制一块等距网格、一座高障碍和一个可移动角色。贴图由示例生成，无需外部素材或额外依赖。

## 运行

在仓库根目录运行 `pnpm setup:dev` 和 `pnpm example:browser`。在命令输出的本地服务器上打开 `/examples/isometric-map/index.html`。点击画布后，用方向键移动。

从初始格按一次上键，角色会走到障碍前面。再按上键会被挡住。依次按右、上、上、左，角色会走到障碍后面。用 **关闭** 释放场景与资源。

## 复用

- 移动基于整数格。将 `(列, 行)` 投影为 `((列 - 行) × 半宽, (列 + 行) × 半高)`。先绘制地面，再按物体脚底深度排序，同深度用固定规则决定顺序。
- 障碍和角色都以脚底为锚点。角色从障碍前面走到后面时，沿用同一绘制顺序规则。通行由格子占用单独决定。
- 移动由输入更新，绘制单独安排在动画帧。`host.getStatus().pendingFrames` 非零时保留待绘制状态，上一帧完成后再提交最新画面。此示例只保留一个进行中的提交。宿主契约说明可用容量和背压行为。 [WebGL2 执行器契约](../../knowledge-base/Cns/docs/webgl2-executor-contract.md)
