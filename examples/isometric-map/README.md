# Isometric map with WebGL2

[简体中文](README.zh-CN.md)

This example draws a small isometric grid, one tall obstacle and a movable character with Egret's public browser APIs. The textures are generated by the example. It needs no external art or additional dependencies.

## Run

From the repository root, run `pnpm setup:dev` and `pnpm example:browser`. Open `/examples/isometric-map/index.html` on the printed local server. Click the canvas and use the arrow keys.

From the starting cell, press Up once to stand in front of the obstacle. Another Up is blocked. Go Right, Up, Up, Left to stand behind it. Use **Close** to release the scene and its resources.

## Reuse

- Keep movement on an integer grid. Project `(column, row)` to `((column - row) × halfWidth, (column + row) × halfHeight)`. Draw the ground first, then sort objects by their ground-contact depth, breaking ties consistently.
- Anchor the obstacle and actor at their feet. The same draw order works as the actor moves from in front of the obstacle to behind it. Grid occupancy determines passability separately.
- Schedule drawing on animation frames independently of movement input. Retain a dirty scene while `host.getStatus().pendingFrames` is nonzero and submit the newest state when the previous submission drains. This example deliberately allows one in-flight submission. The host contract describes the available capacity and backpressure behavior. [WebGL2 executor contract](../../knowledge-base/en/docs/webgl2-executor-contract.md)
