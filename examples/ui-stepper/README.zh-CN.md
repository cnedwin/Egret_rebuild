# 按步分配数量

[English](README.md) | 简体中文

一百枚灵石分给四个堂口。每个数量是一个数值调节框：一个键盘停靠点，接管范围的按键，两侧各有一个给指针用的按钮。堂口下面的一行说明还剩多少灵石，另一行说明某个数量为什么没有增加。对辅助技术来说，这两行分别是一条 status 消息和一条 alert。

## 运行

构建各个包，以仓库根目录提供服务，然后打开页面：

```text
node tools/build.mjs
node tools/serve-canvas.mjs
```

记下服务器输出的主机和端口，在那里打开 `/examples/ui-stepper/index.html`。浏览器支持 WebGPU 时页面用 WebGPU 绘制；加上 `?backend=webgl2` 则使用 WebGL2。

## 可以尝试

- 按堂口旁边的 **+** 和 **−**。每按一次是一步，一步为五。无事可做的按钮会变暗：数量为零时的 **−**，数量为一百时的 **+**。
- 点一下画布，然后只用键盘。Tab 在各个数量之间移动。上下方向键是一步，Page Up 和 Page Down 是四步，Home 把数量清零，End 把剩下的全部给它。
- 把灵石全部分完，再尝试增加某个数量。数量不变，第二行说明灵石不足。下一次成功的修改会把这一行清掉。
- **均分 / Even** 让每个堂口得到相同的数量。**重置 / Reset** 全部收回。无事可做的按钮会被禁用并离开 Tab 顺序；如果它正持有焦点，焦点交给第一个数量。

## 工作方式

| 部分 | 来源 |
| --- | --- |
| 数量 | 应用中的一个数字。没有控件拥有它：由一个函数修改它，把它限制在零和剩余量之间，并返回它是否改变 |
| 它的按键 | `'range'` 类型的 `createControlKeys`，使用 `orientation: 'vertical'` 和 `page: 4`，绑定到应用自己的一个带有 `enabled`、`stepBy`、`toMin` 和 `toMax` 的对象 |
| 它的按钮 | 各有一个 `createActionControl` 和一个 `createHoverControl`。按下时把焦点交给这个数量，不显示焦点环 |
| 离开 Tab 顺序的按钮 | 对它的键盘停靠点调用 `registration.update({ disabled })`，放在微任务里执行，因为停靠点不能在按键处理过程中修改 |
| 会变化的文字 | 每行一个文本对象；一行文字在准备期间再次变化时，会按最后的内容再准备一次 |
| 语义 | 每个数量是带有 `range` 的 `spinbutton`，两侧的按钮是 `button` 节点，供只能激活、没有按键的辅助技术使用。剩余量是 `status`，拒绝原因是 `alert` |

**两条消息从一开始就在树中。**读屏软件在它已经知道的节点的文字发生变化时朗读消息。alert 在没有发生拒绝时以空名称发布，并在下一次成功的修改时再次清空，所以同样的拒绝下次发生时会再次朗读。

**数量的上限是剩余量。**End 以及会超过它的翻页步进都停在那里。只有要求的数量超过现有数量时，才会给出说明。

参见[语义](../../knowledge-base/Cns/docs/ui-semantics.md#消息)、[控件状态](../../knowledge-base/Cns/docs/ui-controls.md#范围内的一个值)和[键盘](../../knowledge-base/Cns/docs/keyboard-focus-input.md)的指南。

## 检查

```text
node examples/ui-stepper/verify.mjs <Playwright index.mjs 的绝对路径> <新的输出目录的绝对路径> [software]
```

省略第三个参数时启动已安装的 Edge（有界面）。使用 `software` 时由 Playwright 自带的浏览器以无头方式和软件渲染运行。六个场景各写出一张截图和 `report.json`：开始时浏览器计算出的树，包括每个数值调节框的数值和上下限，以及作为页面元素的两条消息；指针操作按钮，颜色从屏幕读取，包括均分、一次拒绝和重置；只用键盘，包括数量的每一个按键、两个按钮离开 Tab 顺序，以及页面没有滚动；在页面中观察两条消息，文字在原有的元素内部变化，同样的拒绝连续两次不会再改变文字；辅助技术的请求；以及手机配置。它们在无头 Chromium 的软件 WebGL2 上通过。

输入是通过自动化协议注入的。没有运行真人操作、实体鼠标、手指或键盘、读屏软件或其他辅助技术、硬件 GPU、WebGPU、Edge、Safari、Firefox 和真实手机。检查了消息的文字在页面中发生变化；没有实际听到读屏软件朗读它。按住按钮不会连续步进，数量也不能直接键入。
