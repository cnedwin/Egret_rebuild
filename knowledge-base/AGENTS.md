# 白鹭公开协作约定

[English](AGENTS.en.md) | 简体中文

本项目从开发初期采用公开协作。贡献前阅读[公开表达规范](docs/开源协作与公开表达规范.md)、[贡献指南](CONTRIBUTING.md)、[实现与依赖规范](docs/独立实现与第三方依赖规范.md)及[当前版本](当前版本.json)。

- 以白鹭的目标场景、独立设计、明确接口和可复现结果说明变更。
- 保留参考出处与鸣谢，区分机制研究、实验依赖、产品依赖和开发工具；实际第三方能力保持原有归属。
- 使用专业、客观、友善的措辞。技术比较对应资料版本和测试条件，性能目标与实测结论分别记录。
- 设计过程用问题、选项、依据、反例及结论形成可审查记录。AI辅助贡献注明范围并复核来源、行为与验证。
- 公开材料保护私人信息、商业信息、原始未授权工程、凭据与私有配置；工作台调度和未经整理的聊天不进入发行内容。
- 编辑证据只整理表达和公开范围，保持数据、结果、来源身份、失败及修订记录；公开副本注明投影关系。
- 沿用白鹭领域命名，模块边界、API与代码风格遵循现有候选规范；实际接受状态以登记册和验证记录为准。
- 本文件适用于代码、文档、注释、Issue和PR。它不授予账号权限或扩大任何外部发布、消息发送和资产使用授权。

每次推送前执行[双语文档与推送前检查](docs/双语文档与推送前检查.md)，同步中英文阅读版本、共同登记状态与关键代码英文注释。

当前0.12.0的V011仅限显示/帧与桌面Canvas矩形原型；完整产品验收仍独立。渲染变更除默认prepush外，另按示例执行真实浏览器门禁。
