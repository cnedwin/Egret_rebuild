# Knowledge-base contribution guide

English | [简体中文](../Cns/CONTRIBUTING.md)

The knowledge base is part of Egret's engineering work. Contributions should make the product easier to understand, implement and verify. The [repository contribution guide](https://github.com/cnedwin/Egret_rebuild/blob/main/CONTRIBUTING.md) defines the shared review and verification flow.

## Contributions you can make now

Improve product reasoning, API examples, technical explanations, translations and source records. Supply reproducible observations and authorized samples where evidence is missing. Keep one current explanation for each topic and link to detailed evidence instead of duplicating it.

## Submission and review

Explain the reader's problem, the affected document and any changed technical meaning. Preserve requirement IDs, API identities, verification conditions and unresolved obligations. A design change should explain its constraints and alternatives. A factual correction should cite its source.

## Sources, AI, and public content

Use a neutral project voice. Product documents explain goals and design reasoning; verification documents describe results and limits. Keep conversational prompts, respondent roles and routine drafting exchanges out of the reading narrative. Source attribution and AI-assisted contributions remain accurately declared.

## Bilingual checks and push hook

Update both readings, relative links and current identities. Chinese registries and their English views share IDs and status. Run the knowledge-base structural check with -CheckOnly and the full repository prepush before delivery. See [maintenance](docs/knowledge-base-maintenance.md), [layout](docs/documentation-layout.md) and [bilingual checks](docs/bilingual-documentation-and-prepush-checks.md).

Use the [RFC](templates/rfc-proposal.md), [ADR](templates/adr-decision-record.md), [experiment](templates/experiment-and-acceptance.md) and [origin](templates/implementation-origin-record.md) templates as appropriate. Original evidence, upstream licenses and sealed source retain their identities.
