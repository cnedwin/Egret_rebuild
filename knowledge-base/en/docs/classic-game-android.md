# Migrate a classic game to the Android player

English | [简体中文](../../Cns/docs/classic-game-android.md)

A commercial migration has three separate results: an inventory of the original client, editable code for the new engine, and evidence that the delivered binary plays correctly. Keep the original source read-only until it has been compared with a build from the delivery folder.

| Step | What to preserve | How to check it |
| --- | --- | --- |
| Inspect | Manifest script order, both RES manifests, theme declarations, external channels | Read the missing-file and adapter lists, including entries loaded by server configuration at runtime. |
| Compile | The project's trusted TypeScript compiler, reflection metadata and namespace order | Record compiler and source digests. Compare each emitted script with a second clean run. Diagnostics identify the original file and position. |
| Convert | EXML rules, timeline labels, image pieces, endian order and text styles | Compare actual component construction, an interaction, packet bytes and animation pixels using an authored test scene. Keep unresolved skin entries in the migration report. |
| Run on Android | Game scope, script groups, bounded local assets, external callbacks and save namespace | Open, cancel and reopen the same scene. Background and resume during a packet, text edit or music playback. Exercise sign-in and payments with the operator's test service. |
| Deliver | Editable inputs, native Activity, channel libraries, tool versions and instructions | Move the delivery to a fresh directory, type-check a changed game and produce signed APK and AAB files with an external test key. |

Use the CLI's `inspect` and `compile-classic` commands from the migration guide. Games within the supported Web conversion profile can also use `convert`, edit the output, run `rebuild`, and compare a saved playthrough with `verify`. The emitted `api-usage.json` lists direct references to `egret`, `eui`, `RES` and `dragonBones`, sorted by frequency and linked to locations in the generated JavaScript. Pass it to `checkLegacyBindings(bindings, entries)` from `@egret/legacy/coverage` after installing the adapters. Inspect missing names and dynamic lookups. Pass trusted, ordinary adapter objects. A present descriptor establishes the name only. Aliases, destructured imports, instance methods and handler semantics need a playthrough. Compilation of business scripts alone leaves their engine and host dependencies to be linked. [Egret Migrate commands](https://github.com/cnedwin/Egret_rebuild/tree/main/tools/egret-migrate)

The optional `@egret/legacy` package supplies the classic packet API and scene helpers. Add `--legacy` when preparing the portable kit for these imports. Use an existing game scope to acquire visible map cells and character parts. Parts that finish loading after a change of scene must release their leases. The converter can tile an oversized MovieClip atlas and preserve frame labels, offsets and transparent pixels across tile boundaries. [Compatibility reference](https://github.com/cnedwin/Egret_rebuild/tree/main/tools/egret-migrate/compat) · [Windows pixel sample](https://github.com/cnedwin/Egret_rebuild/blob/main/docs/evidence/migrate-paged-movie-edge.json)

Use `services.host.call` for named operations implemented by the Activity. Grant network access through an explicit origin profile. A callback that arrives after close cannot reattach the old game. Use `editText` for confirmed or canceled editing, `waitForBack` for a modal and `music` for streamed packaged audio. A Fold7 running Android 17 returned the 12-byte little-endian test packet carrying “起航” across two WSS sessions. System sound quality, human IME composition and operator SDK callbacks require their own acceptance. The archive includes the original engine license and notices. Install the resulting `.tgz` from an empty consumer project. ### Select the adapters a game actually uses

Compare `api-usage.json` with `sdk-surface.json` from the same compiler run. The second file describes the supplied SDK declarations, including type-only names, internals and instance members. Use the project's `provideBindings` hook for project-owned extensions and inspect dynamic calls separately. A declared name and a successful build each answer a different question from an actual game interaction.

Start with one screen that changes state. The layout sample opens a two-column board, scrolls and reads packaged text, bytes and an icon. Classic RES requests share pending reads and honor the scope's loading limit. Calling `RES.destroyRes(group, false)` preserves assets still held by another loaded group. Closing the game discards queued work and late callbacks. Run the same business script on both hosts when checking coordinates, button activation, resource bytes and close counts. [Runnable board](https://github.com/cnedwin/Egret_rebuild/tree/main/runtime-sdk/examples/legacy-layout) · [Classic HTTP, WebSocket and channel callbacks](https://github.com/cnedwin/Egret_rebuild/blob/main/tools/egret-migrate/compat/transport.md)

On the Fold7 the board showed both colors of its Chinese caption. Tapping the ordinary text and the link produced one `open:gate` event. Closing the view released all three uploads and both text rasters. The underlying layout, resource and networking runs have separate measurements. ## Editing a commercial-scale classic project

Run `compile-classic` with the matching compiler, rebuild the editable EXML through `compile-theme`, then pass the generated directory back with `--compiled-theme`. Regeneration records the actual bootstrap files and business class sources that the original SDK consumed. Changes to a recorded dependency, a changed skin, or a missing skin that has arrived require a new theme build. One 5.3.10 source set produced 1,633 scripts and 929 factories. Six of its 935 declared skins had no editable source. The compiler also found four methods registered by the game itself.

Review `project-methods.json` before enabling a candidate. Pass selected `{namespace,name}` records through the `projectMethods` option to the browser or Android classic adapter. A game can assign its own function to that slot at startup. Closing the game clears the slot. Declared SDK members and existing host bindings cannot be replaced this way. Supply a host service separately through `provideBindings` when an extension calls a private SDK operation.

The device sample covers bitmap labels, redrawn text-atlas slices, native text edits, and loading or replacing scoped images. An 8 × 5 bitmap caption kept the same bounds on the original browser, Edge and Fold7, disappeared on release and returned on reload. The Windows comparison of a separate dynamic text slice showed a one-pixel difference in vertical placement. Screens that use large blur radii, isolated subtree filters or private render nodes still need visual comparison in their target host. [Measured results](https://github.com/cnedwin/Egret_rebuild/blob/main/runtime-sdk/measurements/november-classic-content.json)

For content edits on Android, use the debug revision command in the build kit. The Fold7 run transferred two changed assets totaling 2,474 bytes and reused five. Repeating the revision transferred zero asset bytes. Switching back to the packaged game retained its save. [Android build kit](https://github.com/cnedwin/Egret_rebuild/blob/main/knowledge-base/en/docs/android-migration-build-kit.md)

The direct-reference inventory contains 183 distinct paths and 3,893 uses. A browser probe found 158 paths on the adapter and resolved four more through a live stage. The remaining entries are 17 internal SDK paths and four methods defined by the business scripts. Review private dependencies inside those methods before opting them in. A one-second music fixture also reported exactly one natural completion in the old browser, modern Edge and the Fold7 native player. Stop and replacement produced no completion.

A classic game port can use the shared Android subtree effects on a player that advertises them. The release still rejects the original 10 × 10 blur and 35 × 35 glow in the comparison scene. The original 5.3.10 WebGL output also differs at translucent overlaps. See [supported effects, pixel comparison and device recovery](android-project-player.md#isolating-a-2d-subtree-on-android).
