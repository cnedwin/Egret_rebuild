# Scope private ownership

Engineering preview **0.35.0** preserves the public Scope API while moving four internal members—values, controller, onClosed and validateAcceptance—to JavaScript private fields/methods. Explicit old-name properties are allowed but no longer affect those internal paths.

Scope registration still deduplicates one owner, preserves owner and Engine affinity, and cancels before cleaning values in reverse acquisition order. Cleanup failures retain their diagnostics and late-cleanup errors. Closed Scopes still leave genuine Engine shutdown tracking. The original public signal remains the cancellation signal. No exports, factories, dependencies, host access or DOM/Node globals are added.

The independently authored public tests use built `@egret/engine`. On unchanged Scope, an ordinary baseline passed and the six-test correctness run produced **1 pass / 5 assigned failures**. The repaired run passed **6/6**. Retained lifecycle tests passed **183/183**, and build, strict type and production boundary checks passed. Five observed TS2740-to-TS2739 changes update only diagnostic markers and exact tables; fixture instructions and strict matching rules remain unchanged. Source-only independent specification and implementation reviews each have zero open findings.
