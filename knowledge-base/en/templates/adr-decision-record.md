# ADR: 〈Decision title〉

English | [简体中文](../../Cns/templates/ADR决策记录.md)

> Records confirmed tradeoffs; creating a template does not imply approval. The [decisions registry](../registry/decisions.json) governs status.

- Decision ID: D-NEW (assigned by a maintainer)
- Date / version / confirmer: to be completed
- Status: awaiting confirmation
- Related RFC / sources / hypotheses / requirements / deliverables: to be completed

## Context and choice

Problem, constraints, candidates, final choice, and reasons: to be completed. State honestly when no confirmer has been appointed.

## Evidence and boundaries

Which conclusions have direct evidence? Which remain hypotheses? Record evidence dates, applicable conditions, objections, and unknowns.

## Effects and fallback

Interface, compatibility, migration, cost, and task effects: to be completed. Explain fallback methods, review triggers, and replacement-decision relationships.

## Verification status

Record acceptance-evidence links or “not yet verified.” Adopting an approach does not mean implementation is complete. When new evidence changes a conclusion, retain this record and append replacement relationships.
