# Pending proposals

English | [简体中文](README.md)

Copy RFCs, draft ADRs, or experiment plans here and name them `YYYY-MM-DD-主题.md`. Explain related requirements, problems, sources, alternatives, and verification methods. Mark unknown IDs as “pending linkage”; do not take existing IDs.

Register file links, topics, authors' chosen attribution, and status in the table below. All initial statuses are “pending review.” Arrange reviews after maintenance responsibilities are appointed. When a proposal is accepted, assign a formal ID, update corresponding registries, and retain the original proposal. Storing a file here does not automatically create an effective decision.
