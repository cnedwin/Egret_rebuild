## 十项固定辅助函数见证

| 见证 | 检查行为 |
|---|---|
| D01 / D02 | `rgba8unorm` / `bgra8unorm` 的准确描述器、回调顺序、共享着色器模块和原 Promise |
| D03 | 独立编写的准确 WGSL 文本、MVP/RGB ABI 及无额外转换/除法操作 |
| D04 | shader 同步失败，且不调用 pipeline 回调 |
| D05 | pipeline 同步失败保留原值 |
| D06 | 返回原 Promise，并保留准确拒绝值 |
| D07 | 非空 pass 有序调用、真实接收者、所给资源及参数 |
| D08 | 空编码不读取任何 pass 属性 |
| D09 | 每个 pass 方法的准确失败前缀及不变抛出值 |
| D10 | 不同逐绘制绑定按所给顺序保留 |

样例覆盖 undefined、null、有符号零、NaN、BigInt、symbol 和对象等任意值，不替换失败身份。测试立即附加 Promise 观察。所给模拟资源标记证明辅助函数顺序，不认证场景/几何、分配 uniform、验证设备或编译 WGSL。描述器比较检查准确的字段有无，包括 24 字节坐标/RGB stride、uint32 索引、反向 `greater`/write 深度、无 blend/stencil/条带字段及单采样策略。
