## 从历史经验到今天的命题

下列历史经验归于S002历史说明，并与公开档案的静态机制核查分别记录；历史市场成效与新产品实测不能互相替代。

| S002历史说明 | 可继承的设计方法 | 当代验证边界 |
| --- | --- | --- |
| AS3 相近的显示列表、事件及 TypeScript 降低了 Flash 到 H5 的迁移门槛 | 承接已有知识、资源和工程，降低转换成本 | 不能据此认定 AI 新创作者需要 AS3 心智；旧新语义要逐项验证 |
| 围绕 Web/native 做小包加载、渲染与功耗优化，适应复杂 2D UI 品类 | 选择工作负载与终端，让资源、运行时和工具协同优化 | 历史优势不证明新引擎的包体、帧时或能耗优势 |
| 历史Runtime宿主接入及Wing、EUI、RES、DragonBones与发布工具整合经验 | 把制作、运行、诊断与交付接成闭环 | 历史经验不证明当前SDK权限或部署条件；新项目宿主接入需独立验证 |

## 用户与竞争承诺

首批优先服务主要依靠 AI 制作游戏的新创作者，同时帮助已有手游开发者进入 AI 创作并迁移旧工程。两组共享可运行、可编辑、可恢复的工程结果，但分别验证：前者首次做成及独立修改，后者迁移、维护和生产效率。保留分组结果，不能合并平均值，也不能静默排除已有开发者。

首期是复杂 UI 2D 与轻量 3D，包括混合工程；轻量 3D 的场景、角色、特效、画质和设备包络待共同样本确定。竞争命题是从意图到可运行、可修改、可发布作品的成功率、时间与总成本。接入聊天、MCP 或 Skills 本身不足以证明效率优势；竞品的已有工具探索也不代表其闭环成熟程度相同。当前无速度排名或领先倍数。

## 七项假设及证伪方式

| 编号 | 待验证优势 | 共同任务与指标 | 失败信号 |
| --- | --- | --- | --- |
| H001 | 轻量包与首交互 | 同等资产/功能的冷启动；下载总量、首屏与首可交互时间，区分缓存和分包 | 省初始包却推迟交互，或首场景需补载大量资源 |
| H002 | 复杂 UI 持续帧时 | 长列表、动态文本/输入、嵌套遮罩、主题/页面变化；CPU/GPU 时间、P50/P95/P99、卡顿和内存 | 平均 FPS 好但尾部帧时、GC 或交互延迟恶化 |
| H003 | 功耗与发热 | 相同设备/亮度/画质/帧率，20–30 分钟持续任务；能量、温升、降频及帧时 | 仅短跑快；持续运行降频或能耗收益消失 |
| H004 | 2D/3D 混合效率与正确性 | 3D 角色/场景/透明特效叠加复杂 UI、骨骼与序列帧；帧时、带宽/上传、视觉及事件一致性 | 换来错误层级、遮罩、骨骼绘制顺序或额外内存 |
| H005 | AI 创作成功且可继续编辑 | 分组完成完整玩法、目标设备发布，再改布局/资源/数值并撤回错误；成功率、人工接手、费用/耗时 | 只能生成演示，第二轮对象或引用丢失，只能重建 |
| H006 | 迁移少干预与一致性 | R008 固定真实工程与版本矩阵；全流程成功率、人工次数/分钟、AI 修复费用、旧新差异 | 仅编译成功、隐藏人工代修、删除未知模块或退化为演示 |
| H007 | 稳定接口降低迭代成本 | 同一工程跨引擎/工具/资源协议版本更新并重复修改；迁移耗时、回归缺陷、恢复成功率、兼容维护成本 | 后端替换或接口升级持续破坏工程与 Agent 定位 |

功耗优先使用直接测量；宿主无法提供数据时标明估算代理及局限，不能把温度或 FPS 当作功耗实测。所有假设先登记样本、设备/宿主与版本、成功条件和容差，再采集结果；证据不足保持未验证。

## 公平比较与交付证据

V001 固定共同样本、输入回放、资产质量、画质、功能、模型及修复预算，记录网络、缓存、构建模式、温度/电量、设备与宿主版本。比较使用合理优化的发布构建，区分可见/总节点，记录重复次数及分布；不可确定网络/随机/SDK 条件按迁移文档控制。性能优势与正确性、质量和人工/AI 总成本一起评估，不能靠降低画质或减少功能取得结论。

V002 提供 H001–H004 的渲染运行时原型；V003 提供 H005/H007 的工程操作、诊断和恢复接口；V004 验证资源与动画管线；V005 验证创作工作台与平台运行/发布；V006 完成 H006 的迁移工具和真实工程对照；V007 保存证据、版本、失败原因与复验方法。旧工程既是迁移样本，也是新引擎核心升级回归资产。

先从共同样本判断哪项优势成立、适用于哪些条件，再决定扩展工作负载与平台。负责人、预算、日期、量化阈值及首批版本/设备尚待确定；2–3 年持续优势是迭代目标，稳定接口与可替换后端只能降低变更成本，不能保证领先。

## 编译调试等待

R013与H008新增持续修改反馈目标；TS7官方构建数据不代替白鹭测量。按固定工程、设备与缓存分别记录冷预览、热修改到画面、类型诊断、资源shader转换、原生发布与错误定位。Rust/WebGPU/GPUAI收益仍分别属于对应作品/宿主对照，不由选型名称成立。
