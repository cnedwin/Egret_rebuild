# 复现有限的 B1 WebGPU 检查

[English](b1-browser-verifier.en.md) · [B1 Host 契约](b1-host-contract.zh-CN.md)

`tools/verify-webgpu-b1.mjs` 是首方编写的实验性浏览器验证器，用于当前 B1 网格主机。它执行真实 WebGPU 编译和原始像素读回，测试场景与独立字面量判定器位于 `tools/b1-webgpu/`。运行无需私有执行辅助程序或操作系统 Job 包装器。所选内部 B1／几何模块仍未纳入稳定的包导出。

## 运行命令

使用不附加执行参数的 Node.js **v24.19.0**、仓库的 **pnpm 11.25.0／TypeScript 7.0.2** 配置，以及已安装的 **Playwright 1.62.1／playwright-core 1.62.1** 配套包。另行安装 Microsoft Edge，以使用 **msedge** 通道。这些版本是当前复现配置，不表示推荐采用最新版本。工具不会安装依赖。

先通过现有 `node tools/build.mjs` 构建仓库，再在仓库根目录运行：

```text
node tools/verify-webgpu-b1.mjs --playwright "<absolute-installed-playwright-package-directory>" --channel msedge --output "<absolute-new-output-directory-outside-repository>"
```

把两个占位符替换为自己的绝对路径。`--playwright` 指向包含 `package.json` 和 `index.mjs` 的已安装包目录；相应核心包从该位置解析，支持嵌套或同级安装布局。必须恰好提供这三个选项／值对，顺序不限；没有用例选择、附加浏览器参数或隐式安装。浏览器以无界面模式启动，创建全新上下文，DPR 为 1。

输出应为仓库外尚不存在的子目录。父目录必须已存在；路径与所有已有祖先目录必须规范且不经过符号链接或目录联接。已有输出文件／目录会被拒绝。命令行、路径和安装元数据准入先于输出创建与 Playwright 导入。调用者信任所选安装工具的代码；准入检查不是敌意模块沙箱。验证器不会覆盖或删除调用者文件。

## 检查内容

固定场景为 **64×64**、不透明、单采样。规范化 RGBA 字节与独立编写的字面量预期逐项比较，不使用截图或 PNG 解码器。

| 正例 | 预期行为 |
| --- | --- |
| F1–F2 | 两种绘制顺序下，反向深度仍产生正确遮挡。 |
| F3 | 两个 MVP 变换共享几何，但保持不同位置。 |
| F4–F5 | 矩形和图片 UI 在场景上方保持画家顺序。 |
| F6 | 后续帧重置为黑色。 |
| F7 | 相机后方几何被齐次裁剪。 |

五项反例只修改一次性构建模块副本，保留原件：N1 反转深度比较，N2 复用首个 MVP，N3 反转 UI 顺序，N4 提供非法网格 WGSL，N5 对 clip-w 取绝对值。N1／N2／N3／N5 必须触发指定真实读回断言失败，并匹配准确的错误颜色字面量。**N4 必须观察到实际 WGSL 编译错误、异步验证拒绝与 Host 启动失败，提交帧数为零。** 仅匹配的控制台错误诊断属于预期；页面错误、请求失败和 HTTP 错误仍算失败。

完整浏览器 PASS 要求 **7 帧正例、5 项预期反例、11 次绘制和 8214 项正例字面量 RGBA 比较**。缩减序列、重试或动画循环不能计为成功。有限的特定源码模块扫描通过选定回环路由服务已捕获的构建字节：最多 128 个模块，每个最多 1 MiB，总计最多 4 MiB。它不是通用 JavaScript 解析器，也不保证其他浏览器／打包器的加载行为。

## 阅读结果

相应阶段完成后，输出记录包括 `result.json`、`inputs.json`、`requests.json`、原始 `.rgba` 帧和模块副本变异回执。紧急退出可能只留下 `hard-abort.json` 和不完整产物；缺失证据不能计为 PASS。报告记录实际 `browser.version()`、安装的 Playwright 元数据，以及源码、工具和构建产物的运行前后哈希。本地报告可能包含安装／输出路径，分享前应检查并删去敏感信息。

| 退出状态 | 含义 |
| --- | --- |
| 0／PASS | 完整的选定检查与已观察的协作 API 清理成功。 |
| 2／UNSUPPORTED | 实际观察到所需能力不可用，且清理完成。 |
| 1 | 准备拒绝，或准入后的 FAIL／INCOMPLETE：检查失败、证据无法保存，或执行／清理未完成。 |

测试场景拥有真实 GPU device，并将其借给 Host。它观察原生 Promise，先关闭并排空 Host，再销毁 device，最后观察预期设备丢失。CLI 观察页面、上下文、浏览器和服务器清理，记录未结算操作。超时不会取消工作，也不证明退场；清理失败禁止 PASS 或正常的 UNSUPPORTED 结果。

**内部预算从准备准入及排他创建输出目录之后开始。** 操作截止为 70 秒，协作关闭截止为 85 秒，第 89 秒预留紧急直接退出，均位于声明的 90 秒预算内。这不构成准备加执行的端到端时间保证。

通道解析后的浏览器可执行文件身份和操作系统后代退场仍为 **UNBOUND**。实际浏览器版本与 API 清理不证明准确浏览器二进制文件、完整进程血缘、硬件加速或性能。

## 当前证据

截至 **2026-10-10**，`tests/b1-webgpu-verifier.test.mjs` 在私有候选布局和已采纳的公开仓库中均通过 **30/30** 项检查。其中包括 18 项命令行拒绝检查和 12 项独立字面量判定器检查；两次运行都未启动浏览器，也未验证 GPU 像素。

已采纳的公开命令随后在 Microsoft Edge **154.0.4258.62** 中记录 **PASS**：**7 帧正例、5 项反例、11 次绘制、8214 项字面量比较**。全部 **6 个 Host** 安全返回，各项待结算账本为零；原始帧、源码绑定记录和运行前后身份已保存。独立保存产物复核记录 **PASS_SAVED_PUBLIC_B1_ARTIFACT_INTEGRITY**，没有可执行的 P1/P2 问题；该有界保存结果已接受。见[公开运行精简记录](../evidence/b1-public-browser.json)。

原采集器更早的已接受桌面结果保持历史身份，不替代本次新公开入口运行。独立 CLI 的通道二进制文件身份与操作系统后代退场仍为 **UNBOUND**。此次实际运行另有外部进程拥有者，其 Job 达到 active-zero 并关闭；这一观察只属于本次尝试，不是独立工具的要求或普遍承诺。时间是执行保护，不是性能测量。本证据整理不包含后继完整 prepush，推送前必须另行通过新检查。

本验证器不建立手机覆盖、Native App／SDK、实体显示输出、设备性能、A2 透明纹理完成、字体、DragonBones、完整迁移或整个引擎验收结论。默认推送前检查仍不启动浏览器。
