# 术语表

[English](术语表.en.md) | 简体中文

| 术语 | 本项目中的含义 |
| --- | --- |
| AI 新创作者 | 主要依靠 AI 制作游戏的人；是否有既有开发经验需分别观察 |
| 轻量 3D | 首期已确认方向，规模、画质、玩法和预算待标杆定义 |
| 复杂 UI | 多功能、多层级、动态布局、文字、遮罩、动画与交互组合 |
| 运行时 | 游戏执行所需的场景、资源、输入、动画、调度、图形及宿主服务体系 |
| 图形后端 | WebGPU、WebGL 或原生图形 API 的具体实现，不等于平台发布适配 |
| 宿主 | 浏览器或承载游戏的平台运行环境；同一平台不同客户端也需分别测试 |
| 能力配置 | 某宿主/设备实测的功能和限制，以及对应资源、画质与降级规则 |
| 帧图 | 描述渲染步骤及资源依赖、寿命和读写用途的执行规划 |
| 脏更新 | 只更新失效的 CPU 数据；不代表 GPU 能只重绘局部屏幕 |
| 首次可交互 | 冷启动后玩家能完成定义的第一项有效操作，不等于加载页出现 |
| 持续性能 | 长时间运行后的帧时间、输入、内存、功耗及热状态表现 |
| P95 / P99 | 采样帧时间的第95/99百分位；口径须说明卡顿、后台与加载是否计入 |
| 迁移完美运行 | 用户最终目标；在声明支持范围内完成约定的行为、视觉、状态和平台对照验收 |
| RFC | 可讨论的需求或方案提案，不表示已接受 |
| ADR | 技术决策及理由的版本记录，包含状态、替代方案与验证依据 |
| Skills / MCP | 任务知识与工具接入方式；实际工程语义和验证由引擎工具承担 |
| 公开候选 | 为未来公开协作整理的本地文档，尚未完成公开发布及适用授权确认 |
