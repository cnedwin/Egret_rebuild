## Implemented scope

Three packages have actual responsibilities: contracts defines cancellation, cleanup, diagnostics, and headless host ports; runtime implements Scope, the display tree, and synchronous events; engine assembles instances, the stage, and shutdown. Other candidate packages do not yet exist. The public consumer entry point is the unreleased workspace package `@egret/engine`; no npm identity has been reserved or published.

- Cancellation: a minimal cross-host signal, one-time notification, listener changes and reentrancy, and exception isolation.
- Scope: deduplicated ownership, rejection of foreign owners, late work while closing, reverse-order cleanup, and error diagnostics.
- Display tree: DisplayObject/DisplayObjectContainer/Stage, parent-child relationships, ordering/reparenting, atomic rejection of cycles and cross-Engine attachment, and separation of detach from termination.
- Events: typed descriptors, propagation-path and all-phase snapshots, priority, once under reentrancy, two stop modes, unsubscribe, and state restoration after errors.
- Engine: headless host assembly, surface reservation during asynchronous startup, one shared close Promise, rejection of new work while closing, bounded host shutdown, and retention of primary/cleanup errors.

This slice has no GPU frames, Texture/resource loading, Sprite.graphics, TextField/EUI layout, transforms/hit testing, skeletons, animation, native VM, editor/MCP, or migrator. Familiar class names do not establish complete legacy compatibility. The complete public API example includes an asset service and is not a compiled example in this slice.

## Actual validation

Fixed development environment: Node v24.19.0, pnpm 11.25.0, TypeScript 7.0.2. The core uses ES2022 without DOM/Node environment types; development tools and tests use Node mjs. The compiler is an explicit Apache-2.0 third-party development dependency with locked version and integrity. The core has no third-party runtime dependencies.

The final artifact reran `node tools/verify.mjs`: strict build, positive/negative type cases, actual package-boundary checks, 44 headless behavior tests, and the example passed, with zero failures. See [execution evidence](../evidence/core-framework-verification.json) for actual output and per-file hashes. These cases establish only the listed CPU/simulated-host behavior; their count is not completeness or a performance score.

Tests preceded implementation. The initially loadable baseline failed 28 real behavioral assertions, rather than merely lacking modules. The initial author phase is in the [implementation report](../evidence/core-framework-implementation.json); five independently reviewed issues, six counterexamples, and fixes are in the [correction record](../evidence/core-framework-corrections.json). Independent code review and required revisions are recorded in the [initial review](../evidence/core-framework-code-review-initial.json) and [final review](../evidence/core-framework-code-review-final.json). Code hashes bound to the final rerun match the final review.

There was no browser, mini-game, native execution, CI, or performance benchmark. Headless host.close is not an actual GPU completion fence. A surface is returned only after host.close succeeds. Failed shutdown keeps it isolated; after timeout, it awaits late success, with no forced release or recovery interface. A failed host therefore cannot restart on the same surface. Real borrowed devices, threads, VMs, and in-flight GPU safety still require host validation. The build is small; its compile time cannot establish faster compilation of complex projects.

## Next slice and evidence gaps

The recommended next slice connects these instances and the tree to versioned/generational resource lifecycles, dirty updates, and frame extraction lists, then adds a minimal 2D drawing backend while retaining complex UI painter order. The first slice has no per-frame scheduling or graphics-recovery logic.

In parallel, address the [evidence gaps and research checklist](核心框架证据缺口与研究清单.en.md): executable legacy golden projects; text indexing/shaping/line-breaking contracts; dual-backend formats/recovery rules; the first SDK host; sustained AI editing tasks; and real-device correctness/cost. Mature text and graphics foundations should first be studied through standards and pinned source; Egret scene/resource/execution contracts should be written independently.
