# Display and Frame Execution Contract

English | [简体中文](显示与帧执行合同.md)

Version: candidate 0.12.0. This is the independent implementation specification; acceptance will follow actual evidence. Existing Apache-2.0 licensing, Egret naming, strict TypeScript, and the absence of an implicit global Stage remain binding.

This work package renders two-dimensional rectangle scenes with the independent core. Complete text, textures, skeletons, filters, 3D, GPU backends, general input hit testing, and complete migration remain required project deliverables; this package does not replace their acceptance. Canvas is the first backend executing this contract. Later WebGPU/WebGL backends consume the same bounded protocol; Canvas experiments do not establish GPU or phone performance.

## Components and Interfaces

- contracts adds `Matrix2D` (a, b, c, d, tx, ty), `Rectangle2D` (x, y, width, height), `ClipRectangle2D` (matrix, rect), `RectangleCommand2D` (kind=`rect`, matrix, rect, color, alpha, clips), `FrameOptions2D` (width, height, optional clearColor and clearAlpha), `RenderFrame2D` (frameId, width, height, clearColor, clearAlpha, commands), and `RenderHostAdapter extends HostAdapter`. Its `renderFrame(frame: RenderFrame2D): undefined` submits synchronously; the single host.close contract still proves completion of pending device work.
- runtime adds DisplayObject x and y (default0), scaleX and scaleY (default1), rotation (degrees, default0), alpha (default1), visible (defaulttrue), and clipRect (defaultundefined). It adds `Sprite extends DisplayObjectContainer` and its Graphics. `Graphics.beginFill(color: number, alpha?: number): this`, `drawRect(x, y, width, height): this`, `endFill(): this`, and `clear(): void` form the current drawing subset.
- engine adds `captureFrame(options: FrameOptions2D): RenderFrame2D` and `renderFrame(options: FrameOptions2D): RenderFrame2D`. The former only captures a snapshot; the latter also invokes the host renderFrame function and its original receiver, captured during engine creation. Basic HostAdapter still supports every existing headless API. Without a rendering port, renderFrame throws `RENDERER_REQUIRED`.
- `@egret/engine/web` provides `createCanvasHost(options: CanvasHostOptions): CanvasHost`. options must include an HTMLCanvasElement `canvas` and may include pixelRatio (default1) and maxBackingPixels (default16,777,216). CanvasHost satisfies RenderHostAdapter. It compiles separately with ES2022+DOM; the root still compiles with ES2022 and types=[].

Matrix2D maps points as X=a*x+c*y+tx and Y=b*x+d*y+ty. The local matrix applies scale, then rotation, then translation; the world matrix is parent multiplied by local. Only the executor applies pixel ratio; logical world matrices exclude it. Stage follows the same visual-property rules.

## Data and Display Semantics

Every numeric value must be a finite number primitive. alpha, fill alpha, and clearAlpha belong to the closed interval[0,1]; color and clearColor are integers in[0,0xffffff]. Rectangle positions may be negative, and width/height are nonnegative; frame width/height must be positive. Scale may be negative or zero. visible must be boolean. Invalid assignments preserve prior state; zero-area rectangles and fully transparent primitives produce no drawing commands. Omitted or undefined clearColor defaults to0x000000 and clearAlpha to0 independently; null is invalid. A color without clearAlpha remains transparent.

beginFill defaults alpha to1. drawRect without an active fill throws `GRAPHICS_FILL_REQUIRED`. endFill stops subsequent fill drawing without deleting existing primitives; clear removes primitives and resets the fill. drawRect copies the current fill when called, so later fill changes do not alter existing rectangles.

clipRect is a pure clip rectangle in local coordinates and does not include a scroll offset. Its input is copied and frozen; this bounded property does not establish full compatibility with legacy scrollRect semantics. It applies to the node's own primitives and all descendants. Rotated clips retain their full matrices and must not silently become axis-aligned scissor rectangles.

Painter order follows the display tree: a node's own primitives in drawing order, then children in increasing child index; higher indices paint later/on top. Effective alpha multiplies ancestors, the node, and the fill. An invisible or alpha0 node suppresses its entire subtree. Traversal reads authoritative internal tree, transform, and drawing state, never overridable public getters or user drawing hooks. Iterative traversal avoids dependence on the call stack for deep trees. Each Sprite owns one stable readonly Graphics facade; sharing or rebinding it is unsupported.

Runtime visual-property, public structural and Graphics mutations first verify a live object and an open bound engine. Detached but bound objects retain shutdown restrictions. Internal disposal still uses callback-free detach/terminate operations while closing; terminal dispose remains available. Reading external clipRect fields can execute user code, so capture a copy, revalidate liveness/engine state, then commit atomically. Visual-property overrides must not obstruct shutdown or disposal.

A frame is a complete, deeply immutable value snapshot: matrices, rectangles, clip chains, command arrays, and the header are copied and frozen. It contains no DisplayObject, Graphics, Scope, lease, or host references. Overflow in world matrices or derived values fails the entire frame; no partial frame reaches a backend. frameId is the successful capture sequence of each engine, starts at1, and is a positive safe integer. It is neither a persistent project ID, resource generation, nor device epoch. Rendering failure may consume the frameId of an already successful capture.

## Reentry, Failure, and Shutdown

captureFrame/renderFrame set the busy state before reading external options. Capturing or rendering again while busy throws `FRAME_REENTRANT`. External field reads or backend callbacks may request dispose. The engine immediately enters closing and rejects further mutations and submissions, but Scope/Stage/assets cleanup, host.stop, and host.close all wait for the current frame call to unwind. finally releases the busy state and frame-idle barrier, whether parameters, construction, or the backend fail.

The host is read once from options and fixed during creation. Its renderFrame method is read and fixed before surface reservation; invalid types or a failing getter occur before reservation. Invocation uses the original function and receiver without relying on overridable function.call. Replacing the host property later does not replace this engine's port. Recheck open state after external frame getters and before frame-ID commitment/submission. A precommit close consumes no frame ID. The core root reads no DOM and starts no scheduler.

Error codes: `DISPLAY_VALUE_INVALID`, `GRAPHICS_VALUE_INVALID`, `GRAPHICS_FILL_REQUIRED`, `INVALID_FRAME_OPTIONS`, `FRAME_TRANSFORM_INVALID`, `FRAME_ID_EXHAUSTED`, `FRAME_REENTRANT`, `RENDERER_REQUIRED`, `INVALID_RENDERER`, and `FRAME_RENDER_FAILED`. Existing OBJECT_DISPOSED, ENGINE_CLOSED, and shutdown-failure contracts remain. Backend exceptions emit phase=`graphics`, code=`FRAME_RENDER_FAILED`, retaining the original cause. Diagnostic-callback failures follow existing isolation rules. A rendering-port return other than undefined is a failure; the host must still complete its pending work during close. This error does not prove work has stopped.

## Canvas Executor

Creation and imports do not draw. start obtains the2D context; failure uses existing startup rollback. surface is exactly the supplied canvas, fixed at construction, so separate hosts cannot evade Engine exclusivity. stop synchronously closes the drawing gate. close is idempotent, terminal, and waits for this host's active drawing to unwind; start after stop/close is rejected. Borrowed canvas elements are not removed; the host acquires no shutdown authority over external DOM events or devices. While active it exclusively controls the canvas bitmap and2D context state.

An active start is idempotent; stop before start is terminal. Rendering before start rejects CANVAS_HOST_NOT_STARTED, and after stop/close rejects CANVAS_HOST_CLOSED. Adapter-specific errors are CANVAS_HOST_INVALID, CANVAS_FRAME_INVALID, CANVAS_FRAME_REENTRANT, CANVAS_BACKING_LIMIT, CANVAS_CONTEXT_UNAVAILABLE, CANVAS_CONTEXT_LOST and CANVAS_RENDER_FAILED. Engine submission wraps adapter failure in FRAME_RENDER_FAILED and keeps the cause. Adapter close never destroys the borrowed element/context or claims to release externally owned events.

Acquire the drawing busy guard before reading external frame fields. Validate and copy every field and command into stable values, then recheck active state before changing canvas dimensions or context state. Backing dimensions are ceil(width*pixelRatio) and ceil(height*pixelRatio); both must be positive safe integers at most4294967295, and their product cannot exceed maxBackingPixels. Also reject nonfinite rectangle endpoints, transformed corners and pixel-ratio-scaled matrices. Check actual assigned dimensions and context loss where available rather than claiming successful allocation. This is an adapter configuration budget, not a hardware limit. pixelRatio and maxBackingPixels are fixed during creation; the former is finite and positive, the latter a positive safe integer. Invalid inputs and budget failures occur before canvas mutation.

After complete validation, reassign the validated backing width/height on every accepted frame, including unchanged sizes, resetting the bitmap, clip, current path and state stack. Establish identity transform, source-over, globalAlpha=1, transparent shadow, zero shadow blur/offsets and filter=none where available; clear the entire backing bitmap and draw the background. Each rectangle has independent save/restore. For each clip, set its world matrix multiplied by pixelRatio, beginPath/rect/clip; then set the primitive matrix, fillStyle, and globalAlpha and fill the rectangle. Clear the current path after commands. Visible overlap retains submission order. External state/path/pixels are not preserved. Direct host close during validation rejects before mutation; close during drawing stops later commands at safe boundaries. Exceptions and close reentry release the busy barrier through finally.

## Verification and Provenance Boundaries

CPU oracles use literal coordinates and order, rather than copying the production matrix function. Example: parent(x=10,y=20,scaleX=2,scaleY=1), child(x=3,y=4,rotation=90), produces a child world matrix approximately(0,1,-2,0,16,24). Rectangle(1,2,3,4) has corners approximately(12,25), (12,28), (4,28), (4,25). Floating comparison tolerance is1e-10.

Real browser pixel checks cover alpha overlap, ancestor alpha, transforms, rotated clips, sibling clip isolation, DPR, clear, validation before mutation, and post-close rejection. On opaque black, draw half-transparent red followed by half-transparent blue; an interior overlap point is approximately(64,0,128,255), channel tolerance2, away from antialiased edges. Automation must actually read pixels and operate the example; a no-op backend cannot pass. Observe pageerror and unexpected console/network failures, and serve favicon rather than ignoring404. Record browser and automation versions; renderer strings do not establish hardware coverage.

New code is independently authored from this specification. Established two-dimensional mathematics and Web platform APIs are implementation references. Normative sources: [Canvas state](https://html.spec.whatwg.org/multipage/canvas.html#the-canvas-state), [Canvas transformations](https://html.spec.whatwg.org/multipage/canvas.html#transformations), and [WebGPU scissor](https://gpuweb.github.io/gpuweb/#dom-gpurenderpassencoder-setscissorrect).
