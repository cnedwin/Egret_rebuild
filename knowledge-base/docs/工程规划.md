## 输入输出合同

工程、场景、组件、资源及逻辑文件是持久化权威；运行逻辑拥有状态、时钟与事件；执行镜像可重建。候选合同定义类型和状态转换，暂不冻结 ABI 或具体函数签名：

- **工程合同：** schemaVersion、稳定 objectID、资源引用、输入工程版本、修改来源和差异；创建、引用检查、保存、重载与版本迁移须有可判定结果。
- **桥接合同：** packet 的协议版本、objectID/generation、frame/sequence、资源就绪依赖及缓冲所有权；在指定帧边界提交，确认后才复用缓冲。序号缺口、协议冲突或设备丢失进入停止提交与快照恢复状态。
- **执行合同：** UI/2D 保序列表与 3D 列表分开；失效区分布局、测量、变换、绘制与命中。可覆盖状态允许合并，销毁后的旧代际结果丢弃。玩法事件留在逻辑权威层；跨界事件独立定义ID、未确认outbox、连续消费水位、ACK身份与重发去重，图形epoch不可清空事件状态。第二轮仅验证单一仍存活实例中effects与水位同步更新，在公平重试条件下的有序单次内存消费；未实现持久事务，不具crash-safe exactly-once，同一Node进程中新建消费实例的状态重置反例可重复副作用，未实际模拟OS进程崩溃。
- **资源与宿主合同：** CPU 数据、解码结果、GPU 句柄和租约分开，独立区分`resourceGeneration`、`leaseId`、`taskId`和`deviceEpoch`；每次获取独立租约，CPU任务与GPU上传任务分开。fence必须显式携带提交/注册时捕获的设备epoch，迟到回调不得读取当前epoch补填；设备恢复本身不产生GPU驻留。取消、就绪、失败、释放完成显式可见。第二轮只执行手动交错回调及注入fence，未证明真实解码、上传、驱动释放或线程安全。profile 声明能力与降级，必要效果不支持时导出阻断，不静默改变玩法。
- **工具合同：** 构建、Agent、编辑器及迁移消费同一工程版本和诊断来源；事务输出新版本或恢复结果，同时留下规则/模型版本、费用和未解决项。

本轮候选目录权威为[工程技术架构与项目结构](工程技术架构与项目结构.md)：packages内contracts/runtime/graphics/hosts/engine/project/toolchain/cli/legacy九个职责包，对外先提供engine/project/cli三公共身份；editor/mcp-server/preview在apps，样本在tests/fixtures，原生crate按实际职责创建。早期runtime-core/renderer等职责名由此细化，不再作为并行当前目录方案。contracts/runtime/engine三包已按[首段计划](核心框架首段实现计划.md)建立在独立核心原型产物中，其余包尚未创建；各后续工作包继续形成路径、类型、命令及独立验收明确的短任务单。

## 并行边界、估算与风险

V001 的授权/样本盘点、宿主探索可并行；合同形成后 UI 与 3D 原型、资源语义参考、AI 事务和迁移盘点可并行。共享合同变更由单一版本合入，消费方按版本联调；不得各自实现同名不同义的对象、事件或资源状态。V006 的转换原型从早期并行，最终验收等待 V005 工作台与真实发布闭环，始终属于项目必交范围。

先由各包估算探索、实现、测试、联调及失败返工的低/中/高工作量；前提包括样本数及差异、宿主/设备矩阵、许可可用性、人员能力、选型结果和复用程度。对照与真实平台测试单独计入；AI 调用、工具运行、人工有效时间与等待分记。依赖最长路径决定日历周期，不能把可并行工作直接相加；Q006 未确定前只报告估算依据与区间，不承诺人月、成本或日期。

| 审计高风险 | 触发条件与处置 |
| --- | --- |
| 失败恢复失真 | 丢包、OOM、设备丢失、后台恢复出现重复事件/旧句柄；优先阻断优化，用故障注入和恢复回放定位状态权威。 |
| CPU 对照被弱化 | 仅用全树扫描或逐属性跨桥作对手，遗漏合理优化；补同质量成熟实现，并计桥接、准备、转码等总成本。 |
| GPU/宿主能力被误推 | API 存在或浏览器成功被写成跨宿主支持/功耗优势；限制结论环境，要求真实发布、设备和测量证据。 |
| 源码授权缺口 | 历史目录存在即被视为可复用/公开；按文件及依赖核查权利，未清楚部分只保留研究线索，替代实现纳入估算。 |
| AI 静默改语义 | 删除效果、吞掉事件、隐藏人工修复后报告迁移成功；要求差异、预算、回滚与固定新旧回放，失败项进入报告分母。 |

工程规划持续随验证更新；接受、拒绝或替代 D001–D016 需留下证据、适用范围与回退路径。研究结论可推进下一轮验证，正式结项须同时具备产品产物、验收证据以及 V006 完整迁移闭环。
