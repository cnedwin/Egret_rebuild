# ADR：〈决策标题〉

[English](ADR决策记录.en.md) | 简体中文

> 用于记录经过确认的取舍；新建模板不表示已批准。状态权威在 [决策登记册](../registry/决策.json)。

- 决策编号：D-NEW（由维护者分配）
- 日期 / 版本 / 确认人：待填
- 状态：待确认
- 关联 RFC / 来源 / 假设 / 需求 / 交付：待填

## 背景与选择

问题、约束、候选方案、最终选择及理由：待填。确认人未任命时如实注明。

## 证据与边界

哪些结论有直接证据？哪些仍是假设？记录证据日期、适用条件、反对意见与未知事项。

## 影响与回退

接口、兼容性、迁移、成本和任务影响：待填。说明回退方式、复审触发条件和替代决策关系。

## 验证状态

记录验收证据链接或“尚未验证”。采用某方案不等于实现完成；新证据改变结论时保留本记录并追加替代关系。
