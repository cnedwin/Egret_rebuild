# RFC：〈提案标题〉

[English](RFC提案.en.md) | 简体中文

> 复制本模板提交本地提案；仓库启用后可作为 Issue / PR 附件。此文件不等于批准决策。

- 提案编号：RFC-NEW
- 作者 / 日期 / 版本：待填
- 状态：提议，尚未批准
- 关联需求 / 假设 / 来源：待填；未知时注明待关联
- 涉及范围：运行时 / 迁移 / 知识库 / 其他

## 问题与证据

谁遇到什么问题？列来源、日期、观察范围，区分事实、假设和推断。

## 方案与替代方案

写清接口、输入输出、兼容边界、依赖和失败行为；比较成本、风险与可回滚性。

## 验证与决策请求

给出样本权限、基线、测量条件、验收阈值、停止条件及待验证事项。需要确认哪项范围或取舍？

## 评审记录

意见、异议、修改与结论：待填。获批准后关联 D-NEW，由维护者分配正式编号并写入决策登记册；未批准方案继续保留提案身份。

## 实现来源

涉及代码或依赖时附[实现来源记录](实现来源记录.md)，区分独立核心、公共依赖与研究对照；执行[独立实现规范](../docs/独立实现与第三方依赖规范.md)，不以改名、换语言或AI改写证明原创。
