## 必要修正

1. **R1 / P2：缺少待启动示例的所有权。** `experiments/asset-reference-probe/probe.js:12` 在等待创建完成后才赋值 `demoChain`。完成前点击两次会分别启动 renderer 和帧循环；第二个 owner 覆盖第一个却没有销毁，两条循环也会覆盖同一个 `raf` ID。停止仅取消一条循环，另一条可能读取空 owner。第 13 行的 `pagehide` 在加载期间同样无法销毁或使迟到结果失效。增加待启动保护、abort/generation 所有权，销毁过期结果，将唯一帧循环绑定到活动 owner，并在失败时恢复按钮。用延迟真实加载、重复启动和完成前 pagehide 测试实际示例 handler。
2. **R2 / P2：初始化失败没有撤销适配层资源。** `reference-chain.mjs:27` 在解析并创建 renderer 后调用 `createUIPass`，此时尚无清理路径。UI 编译、链接或初始文字失败会拒绝创建，同时留下 renderer 及 canvas 监听，也没有返回可供销毁的 chain。`ui-pass.mjs:6`、`:15`、`:37` 同样没有对部分 shader/program/VAO/texture 的回滚。围绕初始化增加有界的异常安全所有权清理，保留原错误，删除部分 UI 分配，并销毁已完整创建的 renderer 和已解析 bundle。验证真实解析和渲染分配后的受控 UI 失败，以及 shader 失败清理。本要求针对适配层已获取资源的清理，不要求穷尽上游失败框架。

## 接受的行为与边界

真实 loader/clone/mixer/renderer 链、共享 bundle 生命周期、实例独立姿态、显式 UI/renderer 交接、原文 epoch 缓存以及实际 context-loss 恢复得到代码与相应判定条件支持。恢复除了逐像素相等，还要求非空 3D 像素和明亮原生文字像素；空白画面无法满足这些断言。丢失上下文时的 geometry/skeleton dispose 使 GPU 分配失效，同时保留 CPU bundle 与共享所有权；最终 `releaseShared` 是另一操作。没有宣称 heap/GC 证明。

本机服务器采用精确白名单、随机写入 token、固定报告路径及请求大小上限。runner 保留逐次运行报告并记录来源 hash。一项不阻塞的证据问题是：JSON 在示例启动前写入，因此后续示例错误会影响进程退出，却没有再次序列化到该 JSON。R1 回归证据应明确覆盖示例。

`requiredProfile` 说明已配置的 allowlist，不代表已测试的扩展兼容性；实际执行资产没有 required 扩展。字体缓存不能证明字体覆盖。当前恢复证据涉及无纹理测试资产和小型 Canvas UI。手机、帧时/功耗、完整 UI、2D 骨骼、KTX2、字体/IME 验收及完整迁移仍不在范围内。本审阅不能推导 Gate D/H 或产品完成。
