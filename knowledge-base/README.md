## 0.12.0 显示与帧候选范围

后续工作包按[显示与帧合同](docs/显示与帧执行合同.md)及[实现计划](docs/显示与帧执行实现计划.md)推进：显示变换、继承可见性/透明度与本地矩形裁剪、Sprite 所属 Graphics 的矩形填充，以及不可变 CPU 帧捕获/提交。首个已实现执行适配器为独立 @egret/engine/web 入口的 Canvas，核心根入口保留无 DOM 边界。限定实现检查已通过：97/97核心行为测试、25项负类型诊断及真实桌面Canvas像素/指针交互。跨realm拒绝修正后有限独立审阅通过；远端发布另行记录。最终限定结果由[实现记录](docs/显示与帧执行实现记录.md)和[验证](evidence/display-frame-verification.json)承载。

本包不验收完整文本/纹理/动画/UI/3D 执行、GPU 或 Native 支持、目标设备性能、编辑器、Agent 服务或完整迁移。此前 headless、CPU 资源与第三方研究记录保留原版本、数量、hash 和范围，不转为新显示帧验收。

新白鹭面向主要依靠 AI 制作游戏的新创作者，首期兼顾复杂 UI 的 2D 游戏与轻量 3D 游戏。渲染引擎和运行时是核心；旧白鹭工程一键导入、Agent 自动转换、尽量少人工干预并实现移植后完美运行，是正式交付要求。

版本：0.12.0 候选 · 更新日期：2026年10月9日 · 阶段：公开协作与开发预览准备。技术白皮书、PRD与工程规划各自为0.7候选版。

白鹭从开发初期采用公开协作，本目录提供持续维护的设计、来源、决策与验证记录。此前已运行独立合同模型与本地浏览器图形研究程序，完整引擎、工作台、生产宿主、性能及迁移尚未验收，V002已有局部自主headless核心，V003—V006产品实现未开始。局部研究结果不代表产品可用或性能领先。本地公开仓库候选包含核心源码与知识库；项目仓库为[cnedwin/Egret_rebuild](https://github.com/cnedwin/Egret_rebuild)，沿用既有Apache-2.0配置；本候选的提交与审阅状态见发行记录，维护职责逐步明确。历史材料按各自权限保存，公开副本保留版本与来源身份。第三轮按R012以明确第三方研究依赖使用Three r186，加载真实glTF蒙皮圆柱并接入Canvas文字UI；当前17/17主检查通过。已有研究代码，完整产品实现与验收状态仍分开；既有实验覆盖不扩大。


当前 CPU 资源核心单独登记为 V010，见[合同](docs/资源核心合同.md)与[实现记录](docs/资源核心实现记录.md)。它接在 V009 已验证的生命周期切片上；V002/V004 完整验收、生产宿主、性能与 R008/V006 迁移仍待完成。

## 如何判断一条记录的效力

项目目标进入需求登记册，R017要求开始核心实现与核查证据缺口；R011要求研究、验证设计与自审，R012要求优先研究成熟原理，R015要求核心独立实现和公共依赖明确归属；技术方案进入决策登记册，当前 D001 至 D016 全部为 proposed。H001 至 H008 仍为 untested，局部实验没有将优势假设升级为结论。交付登记册记录实现与验收状态；文档写完不意味着产品完成。

V001 的研究部分为 in_progress，共同产品样本、设备和性能基线尚待建立；V002已有局部自主headless核心，V003—V006产品实现未开始。V007 为本地知识库基础，V008 是技术白皮书、PRD 和工程规划候选文档包。R008 始终属于首个完整发布目标，V006 最终依赖 V001—V005，不能用文档或局部研究替代完整迁移验收。

稳定编号连接讨论与交付：R 表示需求，D 表示技术决策，H 表示待验证假设，V 表示交付项，S 表示来源。文字解释可以改进，编号不复用。撤回或替代的记录保留，并注明替代关系。

[当前版本](当前版本.json)指向权威登记册与当前文档。[核验记录](核验记录.json)只证明登记册引用、文档链接和发布候选边界的结构检查；它不证明引擎功能、性能或许可证合规。

两轮合同与图形审阅均发现过问题；当前四CPU64项和本地WebGL7项主检查通过，限定范围、失败历史与修正见[第二轮验证记录](docs/第二轮验证记录.md)和[第二轮审计](docs/第二轮审计.md)。数量不是性能或完整性评分。官方研究的来源日期冲突及未重验项查阅[第一轮研究核查](docs/第一轮研究核查.md)，不以一条汇总日期替代不同来源口径。

## 第一批需要共同解决的问题

本次按R016重新制定候选工程结构、公共API/命名、生命周期和代码质量门禁，历史八个条目只做静态核查。先保留熟悉领域名，再现代化模块与所有权；首段已创建自主源码产物并完成限定编译与headless验证；没有CI、GPU/原生或性能验收。完整范围见[核心实现记录](docs/核心框架实现记录.md)。Shaders/Playground来源研究继续作为组件与创作流程参照。原生Rust、VM、WebGPU与GPU AI均为候选，未验收。首条真实资产参考链已执行。下一步把2D旧骨骼语义金样、生产代表性的复杂UI与完整3D角色纳入同一作品；明确恢复就绪阶段并精简目标包体，继续补旧语义回归。标杆、首批宿主与设备同步收敛。设备到位后测对应性能，随后扩展AI创作、发布与完整迁移闭环。首批宿主顺序、团队、工期、数字性能预算与商业模式均未获用户确认。
