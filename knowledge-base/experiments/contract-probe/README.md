# 第一轮架构合同研究原型

[English](README.en.md) | 简体中文

这组程序验证局部布局、绘制顺序、镜像协议和资源生命周期的可执行合同。它是研究代码，不是白鹭产品实现，也不代表实际跨语言桥接或 GPU 性能。

在本目录运行 `node run.mjs`。结果保存到 `../../evidence/contract-probe-results.json`，包含种子、环境、案例及源码摘要。布局采用独立全量计算；相邻批次展开后用同一个逐命令CPU合成器验证保序，尚无独立批次状态消费者。包含故意错误策略的反例；处理节点数仅为算法工作量，不是 FPS 或速度倍数。

固定实验参数为8个独立布局区域，每区128个对象，200轮种子变更；命令队列容量为3。它们用于复现，不是最终引擎规模、ABI、队列或性能承诺。

初版17项通过后，独立审计发现遗漏。第一组新增7项先失败，修正后24项通过；第二组租约新增2项先失败，最终26项通过。初版、第一组失败、中间修正、第二组失败源码分别在 `history/initial/`、`history/audit-red/`、`history/audit-green-1/`、`history/audit-red-2/`；对应JSON在知识库根目录的 `evidence/`，见[验证记录](../../docs/技术验证记录.md)。复现历史时把两份源码置入同样的临时目录结构，避免其相对输出覆盖当前结果。

镜像中的event只代表已消费图形通知，没有必达事件恢复；资源complete模拟合并加载/上传回调，owner是集合，尚无完整逐租约计数、独立解码和真实GPU异步重建。当前通过只针对报告列明的模型行为。
