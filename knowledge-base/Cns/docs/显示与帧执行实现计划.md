# 显示与帧执行实现计划

简体中文 | [English](../../en/docs/display-and-frame-implementation-plan.md)

候选版本 0.12.0。依据：[显示与帧执行合同](显示与帧执行合同.md)。本计划将自主 CPU 核心推进为有明确边界的矩形渲染器，不据此验收 GPU 性能、完整 UI、3D 或移植能力。

## 全局约束

- 延续 Apache-2.0 归属与独立实现规则。原始私有代码和竞品实现不作为本次代码输入。
- 依赖图保持 contracts → 无，runtime → contracts，engine → contracts/runtime。核心根入口采用严格 ES2022、types=[]，没有 DOM/Node 环境全局依赖。
- 公开行为测试和示例使用构建后的 `@egret/engine`；浏览器测试可以使用 `@egret/engine/web`。内部工厂和帧收集器不由门面重新导出。
- 保留已有行为检查，使用独立的几何与像素字面量判据、先失败测试和明确的生命周期反例。
- 公开文档始终提供完整中英文版本；关键代码使用英文注释。实际证据包括代码身份、环境、限制、失败与修订。
- 发布须完成记录中的检查及单独仓库审阅；本阶段不包含main合并或npm发行。

## 步骤 1：显示状态与 CPU 帧生命周期

文件：contracts/src/RenderFrame2D.ts 及 index.ts；runtime/src/DisplayObject.ts、Sprite.ts、Graphics.ts、displayVisualState.ts、frameCapture.ts、index.ts；engine/src/Engine.ts、createEngine.ts、index.ts；相关诊断类型；顶层 tests/frame.test.mjs 及类型用例。

按合同实现类型、显示默认值、校验、不可变裁剪副本、Graphics 填充快照与 Sprite 所属关系。每个 DisplayObject 注册一次内部 WeakMap 状态；Graphics 使用其 Sprite 的存活与所属引擎检查。内部 `collectFrameCommands(stage: Stage): readonly RectangleCommand2D[]` 按父节点优先迭代遍历，复制并冻结几何，派生溢出产生 FRAME_TRANSFORM_INVALID。它只在 runtime 中作为跨包实现端口导出，不出现在 engine 门面中。

实现 Engine.captureFrame 与 renderFrame。默认 clearColor=0x000000、clearAlpha=0。在读取外部 getter 前设置忙状态；渲染方法在画布占用前固定，以 Reflect.apply 调用。没有渲染端口时仍可 captureFrame，但 renderFrame 拒绝。无效方法类型或 getter 产生 INVALID_RENDERER，且不占用画布。外部读取后再次检查引擎开放状态。帧 ID 为从 1 开始的正安全整数；捕获失败不消耗 ID，后端失败可以消耗已捕获帧的 ID。完整 DTO 冻结。关闭立即进入 closing，但在清理场景或宿主之前等待当前帧退出。所有退出路径通过 finally 释放忙状态及等待屏障。后端返回非 undefined 时拒绝，并观察原生 Promise 的拒绝，不接受异步渲染。保留已有关闭权限与隔离行为。

先失败用例：合同的世界矩阵与四个顶点字面量；绘制顺序、clear/endFill/填充快照；祖先可见性及透明度；裁剪继承及后续修改不影响旧帧；零面积省略；有限数、原始类型、范围拒绝和原状态保留；脱离树但绑定引擎的对象在 closing 后拒绝修改；不读取恶意公开 getter；深树迭代；options getter 重入和关闭；后端中关闭等待渲染退出；后端抛错/非法返回及诊断隔离；原接收者、恶意 function.call 与替换方法；占用前 getter 失败；派生溢出不调用后端；缺少渲染器仍可捕获。补充有意义的只读 DTO 和非法异步端口类型检查。构建并运行相关测试，再运行已有核心检查。

保留可归属作者的代码与测试版本。原始红绿日志保存在公开源码树外；公开整理后的结果与身份回执，记录命令、数量、失败/修正、源码修订及未解决问题。

## 步骤 2：Canvas Web 适配与真实浏览器验收

文件：engine/web/CanvasHost.ts 和 index.ts、独立 engine/tsconfig.web.json、engine exports 及根工程引用；tools/check-boundaries.mjs；tests/canvas-host.test.mjs 和类型用例；examples/canvas-scene/*；tools/verify-canvas.mjs 及范围明确的浏览器检查工具。

浏览器代码单独使用 ES2022+DOM 编译到 dist/web，并引用 contracts/runtime 工程。根 tsconfig 排除 web，根出口不导入或重新导出 web。只允许这一明确 web 子树使用 DOM，仍拒绝 Node 导入/全局、未批准依赖及内部端口泄漏。补充无 DOM 消费端检查和导入无副作用检查。

实现 createCanvasHost，pixelRatio=1，maxBackingPixels=16777216；稳定复制参数，明确生命周期状态、同步渲染门禁与关闭等待屏障。surface 固定为传入 canvas 本身。完整 DTO、变换端点/角点、缩放矩阵与尺寸校验/复制完毕前不改动画布/上下文，getter 后再检查 active。底层尺寸用 ceil、unsigned-long 上限 4294967295 和安全预算运算。校验后每帧重新赋值尺寸，重置位图/裁剪/路径/状态。规范阴影、滤镜、混合和透明度，并按合同实现绘制顺序、变换、裁剪、透明度及命令 save/restore。宿主存活期间独占画布绘制，不承诺保留外部状态/路径/像素。借用的 DOM 元素归外部所有。补充传入裁剪/阴影/滤镜反例；绘制中关闭在安全边界停止后续命令。一个宿主不能由两个引擎共享。

通过 import map 提供使用自主核心及 web 适配器的可运行示例；指针交互改变场景并重新绘制，不据此宣称完整输入系统。提供 favicon。复用已安装 Edge 与固定的捆绑 Playwright 执行真实浏览器验证，不新增产品依赖。验收覆盖：重叠像素 (64,0,128,255)、容差 2；祖先透明度；平移/旋转/缩放；旋转裁剪与同级隔离；DPR 尺寸和像素；逐帧清除；非法帧在画布修改前拒绝；关闭后拒绝；可见示例指针交互；异常页面/控制台/网络失败。包含不执行绘制的反例，证明像素检查会失败。记录浏览器/自动化版本与适配条件，不作实体设备、GPU 或性能结论。

浏览器检查后执行完整核心检查，保留实现及证据脚本，并按步骤1的限定范围记录结果。

## 步骤 3：公开证据、双语发布与远端校验

文件：README/架构/实现/证据双语文档及知识库索引/登记册；localization.json；source-origin.json；验证身份与关键英文注释索引；发行元数据/清单及交付状态。保留历史证据和封存的 0.11.0 候选。

准确记录实际验收、回归和独立评审边界。登记新规格/证据 ID，不改历史身份 hash，不虚报尚未实现的 UI/字体/骨骼/3D/移植。通过可检查工具更新独立文件集合、现行双语文档和注释 hash。复核公开措辞、来源、翻译一致性、依赖/许可证归属，排除私有工作资料及凭据。

在最终代码身份运行 tools/prepush.mjs、公开工具回归和真实浏览器检查。在 outputs 创建带完整清单/归档/报告的 0.12.0 候选。通过后向已有草稿 PR 分支快进提交，并按最终范围更新双语说明。独立获取并比较远端提交/树/文件字节/权限与候选，确认 main 未改动。GitHub 问题及时报告并记录，继续独立的本地开发。

本阶段后进入另行制定的工程事务模型及后续渲染/资源工作，本计划不结束整个引擎重构。
