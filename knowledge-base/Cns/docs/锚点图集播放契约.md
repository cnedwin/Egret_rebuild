# 锚点图集播放 — 契约

[English](../../en/docs/anchored-atlas-playback-contract.md) | 简体中文

工程预览 0.53.0 · S107 / V058。本示例组合现有已构建公开 Engine API 与可选 Canvas／WebGPU 宿主，不新增产品 API、包入口、依赖、宿主协议或自动时钟驱动。当前源码和 CPU／代码限定范围另见[证据](锚点图集播放证据.md)。

## 原创内容与显示

第一方 16×6 不透明 RGBA 图集的每一行中，第 0–7 列是红色 (255,0,0,255)，第 8–15 列是蓝色 (0,0,255,255)，共六行。sheet 具名裁剪为 red=(0,0,8,6)、blue=(8,0,8,6)。一个循环 clip 使用这两块裁剪，各持续 0.125 秒。提供器创建并最终销毁精确的原始 Texture；外部回调不能替换图像或提供伪造租约。

预览为 192×192：Bitmap 位置 (96,96)、anchorOffset (4,3)、缩放 (8,8)、旋转 0，内容出现在 (64,72,64,48)。验证使用 24×24、DPR 1、位置 (12,12)、同一枢轴、单位缩放及透明黑清屏，内容为 (8,9,8,6)。Bitmap.getBounds() 测量接收者局部内容 (0,0,8,6)，Stage.getBounds() 测量唯一已变换子节点；不新增目标空间 getBounds 重载。

## 示例本地会话

`createAnchoredAtlasSession({host, preset='preview', prepareAtlas?})` 是 `examples/anchored-atlas-playback/session.mjs` 的同步导出，不属于 Engine 包导出。preset 仅为 preview 或 verification。可选异步 prepareAtlas 回调只是提供器准备屏障；返回值被忽略，原创图集保持固定。

返回的冻结 handle 暴露：

- ready：真实获取、准入及 N1 呈现完成后，兑现为冻结就绪快照的 Promise。
- step()、pause()、resume()、replayBaseline()、showLive()：同步操作并返回快照。
- inspect()：同步、无副作用的冻结快照。
- close()：普通函数，重复或重入调用均返回同一个缓存 Promise<void>。
- scene：真实 engine、resourceScope、animationScope、lease、sheet、bitmap、playback、savedFrame、texture handle 的冻结视图。获取前字段可为 undefined；关闭后保留以便进行公开观察。视图不冻结活对象，也不转移所有权。

快照字段为 state（starting／ready／closing／closed）、sourceSeconds、clockElapsedSeconds、playbackState、frameIndex（数字或 null）、liveColor／presentedColor（red／blue 或 null）、loads、disposals、pendingTasks、primaryOccurred、primaryCause、initializationCause 及 cleanupErrors 的冻结副本。已销毁播放对象的观察遵循其真实公开 API；会话不伪造仍存活的采样记录。

## 时间与保存呈现

初始化调用 engine.advanceTime(0)，启动现有播放，并保存精确的首个红帧。只有“前进”将绝对源时间增加 0.125 并推进 Engine。暂停／恢复只操作控制器，不捕获、不渲染。重放将精确 N1 对象交给同一活宿主，不捕获、不推进；显示当前帧则捕获／呈现当前状态，不推进时间。

| 视图 | 源时间秒数 | 当前裁剪／控制器 | 呈现 |
| --- | --- | --- | --- |
| N1 就绪 | 0 | 红／运行 | 红，保存为基线 |
| N2 前进 | 0.125 | 蓝／运行 | 蓝 |
| N3 暂停后前进 | 0.25 | 蓝／暂停 | 蓝 |
| N4 恢复后前进 | 0.375 | 红／运行 | 红 |
| N5 前进 | 0.5 | 蓝／运行 | 蓝 |
| N6 重放首帧 | 0.5 | 蓝／运行 | 精确保存的 N1 红帧 |
| N7 显示当前帧 | 0.5 | 蓝／运行 | 当前蓝帧 |

这是契约序列，不是实际 Native 数量。捕获、重放和呈现不推进时间。advanceTime 成功后，即使后续渲染失败，sourceSeconds 也已提交；不承诺回滚公开时钟。

## 所有权、拒绝与关闭

一个真实资源 Scope 按 lease → sheet → Bitmap 顺序采用对象；一个动画 Scope 拥有 playback。sheet、Bitmap 和 playback 借用原始租约，不获取第二份租约。对象挂到同一 Engine Stage。传入 HostAdapter 保留既有 surface／start／stop／close／timer 契约和安全归还义务。

就绪前操作抛出示例专用 EXAMPLE_NOT_READY；关闭中／已关闭操作抛出 EXAMPLE_CLOSED，不建立新的 Egret 错误族。关闭立即拒绝新操作，先取消／退役动画再处理资源，等待原始初始化及全部实际提供器准备任务，之后等待 Engine 销毁与原始宿主链。准备挂起时，取消后会在创建 Texture 前再次检查；若未创建，销毁数量保持零。每个实际获得的结果须恰好退役一次。

初始化失败仅在清理后，才以原始外层初始化原因拒绝 ready，并保留为 primaryCause／initializationCause。启动时主动关闭则用 EXAMPLE_CLOSED 拒绝 ready，将原始中止原因保存在 initializationCause，primaryOccurred 保持 false。操作失败记录并重新抛出精确原始原因，页面随后请求关闭。close 单独报告清理失败（单个原始失败，或多失败 AggregateError），同时保留首要原因与冻结 cleanupErrors。宿主关闭拒绝或超时，不证明表面已安全归还。

重复关闭不改变加载／销毁数量；活包装对象退役后，保存帧／图像值继续保留不可变原始像素。页面退出仅作尽力处理，不证明进程退役。完整 EUI／布局、输入路由、自动调度、完整 Spine R020/V020、迁移 R008/V006 和平台／性能限定均属于单独工作。
