# 位图按钮工程计划

[English](../../en/docs/bitmap-button-implementation-plan.md) | 简体中文

0.54.0 在真实显示、资源、Scope 和共享输入 API 上构建一个可复用二维控件。本次不代表完整 EUI 或整个 UI 产品完成。

## 已完成代码工作

- 明确所有权、选项读取顺序、皮肤校验、原生来源手势、最终激活命中复查和终态清理。
- 实现前建立真实缺失工厂基线；独立审阅五个产品文件与七个公开消费者用例，保留外来 Scope 发现及有限修复。
- 实现原创双按钮 Canvas/WebGPU 示例和独立严格类型工具，保留全部既有输入回归及完整未抑制诊断。
- 运行九个正常代码阶段；当前本地运行核心3218/3218、保留 Spine 源码160/160，独立结果验收在核验文档另行记录。

- 独立审阅当前浏览器验证器、完整画面字面像素标准和显式导入图，并在执行前闭合真实报告字段兼容发现。

- 从原始保存结果核验 Canvas/WebGPU 交互、保存/实时画面、共享路由、独立负对照和完整退役。

## 本工作包剩余验收

- 审阅成对公开文档、来源与英文注释，运行正常仓库、发布、推送前门禁及必需 Git 钩子。
- 沿已授权仓库流程提交、推送、创建可审查 PR 并合并；各阶段分别取得实际结果，不推断远程 CI 通过。

## 后续产品工作

局部布局与更丰富 UI 组合、触摸/键盘/焦点/无障碍、文字/IME 与目标设备字体、完整 Spine R020/V020、迁移 R008/V006、高级3D、原生 SDK 和 AI 工具属于独立规格与验收包。桌面不透明像素不能证明手机、物理 GPU、性能、能耗或垃圾回收结论。参阅[契约](位图按钮契约.md)及[核验](位图按钮核验.md)。
