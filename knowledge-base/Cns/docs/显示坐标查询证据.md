# 显示坐标查询：有界证据

公共根入口提供只读 Point2D、CoordinateQueryOptions 类型，以及 DisplayObject 继承的 localToGlobal/globalToLocal 方法。查询沿实际祖先路径纳入 Stage 和脱离后的根节点，采用逻辑坐标，并限定私有权威、生命周期及遍历预算。前向组合保持现有 binary64 运算；逆向查询对已完成存储矩阵的精确有理数解执行正确舍入。这不保证近奇异情况下的真实层级精度或前向／逆向往返。候选工程标签为 **0.21.0**，私有包仍为 **0.0.0**，协议固定为 **1.0**。

## 已记录执行 — 2026-10-10

产品实现前，未改动基线构建成功，**49 个已登记坐标回调全部失败**。真实 DisplayObject 的方法可用性断言得到 undefined，而非 function。这证明 API 能力缺失，不表示独立到达了49个几何反例。通过的后继专项运行包含坐标及已有帧、显示树、纹理捕获套件：**92/92 通过**，其中含49个坐标回调，失败、取消、跳过及待办均为零。审阅随后发现夹具辅助函数的缺口：可选cause比较把显式传入undefined当成省略。以剩余参数是否存在修正预期检查后，新专项后继再次 **92/92 通过**，含精确undefined原因检查。早先通过运行仍单独绑定。

严格类型门禁通过 **101 项预期负向诊断：68 根入口 + 5 web + 28 project**，包含14个坐标新增负例。完整可调用类型相等、只读公开结构、结构化选项及无 DOM 消费者检查通过。首轮类型尝试保留两个 Parameters 相等断言的 TS2344 失败：提取后的可选函数参数元素包含 undefined，而原编写可选元组在 exactOptionalPropertyTypes 下未显式写入该联合类型。预期元组改为 number|undefined／CoordinateQueryOptions|undefined；完整可调用断言、产品签名与负例均保留。契约自有的可选 maxNodes 字段仍不允许类型化字面量显式存入 undefined。

单独记录的核心验证器及 headless 示例均零退出。验证器通过 **1045/1045 测试**、300 个源码／构建／声明文件边界检查及同一严格类型门禁。这些套件相互覆盖，不得与92或49相加成为新总数。结果属于绑定版本的回归观察，不是完整引擎验收。

## 公共捕获中的消去证明

C37 通过公开 Sprite 构造父子层级，两者旋转45度，父节点 scaleY=2^-120，子节点绘制 Graphics 矩形。公共 captureFrame 在检查输出前，断言已完成矩阵的精确系数为 (a,b,c,d,tx,ty)=(1/2+u,1/2,-1/2,-1/2+u,0,0)，u=2^-53。普通 binary64 的 a*d-b*c 为零；独立推导 (1/2+u)*(-1/2+u)-(1/2)*(-1/2)=u^2=2^-106。全局 (0,2^-106) 得到局部 (1/2,1/2+u)，也检查负向镜像。因此日志中的 C37 通过包含真实系数门禁，而非假设三角恒等式、私有矩阵注入、静默跳过或往返预期。其他字面量案例覆盖极端指数、平移差值丢失、次正规／正规进位、最近偶数舍入及有限输出溢出边界。
