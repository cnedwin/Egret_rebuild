## 修复内容

取消实际英文组合输入时，原生会话已经退役，readonly／blur 仍可能同步触发组合结束回调。原 busy 检查把它当成重入并关闭桥接器，导致无法再次编辑。现在仅在会话令牌已经退役时忽略输入／组合回调；活动会话的重入继续拒绝。复现中组合开始／更新／input 为 trusted=true，终止 compositionend 为 trusted=false，分别保留其事实。不改变 API、声明或触摸路由。

默认表单按可用 CSS 宽度显示，启动 DPR 上限为 3。真实宽度改变时结束原生所有权，仅重建既有界面适配器，保留 Engine、字段模型、文本选区、可见稳定行锚点、段落缓存及字体。每次界面使用独立 Scope，在替换时释放，避免已关闭的注册项积累在长生命周期模型 Scope 中。键盘导致的纯高度变化保持原生编辑会话。DPR 在 Host 创建时采样，实际 DPR 改变后需重新打开预览。preset=verification 固定档保留 800×480、比例／密度 1。

任务使用独立测试页、共享手机租约和临时路由。每个用例保留原目标、前台应用、准确旋转值及继承的 USB 唤醒设置。截图、序列号、目标编号、无关 URL 及键盘上下文保持私有。已取得的解码响应与捕获文件哈希一致；无法取得的响应行及缺失解码源覆盖分别记录，同时保留自有服务器快照。
