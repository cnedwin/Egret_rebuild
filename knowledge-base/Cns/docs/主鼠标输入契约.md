# 主鼠标输入

[English](../../en/docs/primary-mouse-input-contract.md) | 简体中文

MI1 将既有显示树命中、类型化事件分发和显式渲染连接为 Scope 所有的浏览器输入适配器，为交互式 2D UI 提供小型基础。完整 UI 组件、触摸与笔输入、Spine、原生平台及目标设备性能仍是单独工程需求。实现为独立编写的第一方白鹭代码，采用 Apache-2.0，不新增第三方依赖。

## 可选入口与使用

`@egret/engine/web/input` 仅导出函数 `createMouseInput` 和六个类型：`MouseInputOptions`、`MouseInput`、`MouseInputState`、`MouseInputEvents`、`MouseInputPayload`、`MouseInputCancelReason`。默认 Engine、Canvas 和 WebGPU 入口不导出该 API。导入可选入口不会获取浏览器资源或安排任务。

使用已成功启动的真实 Engine 及其真实、开放的 Scope。适配器使用 Engine 装配时捕获的原始 Host surface 和 Stage。固定逻辑宽高必须有限且大于零。`maxNodes` 默认 `4096`，允许 `1` 至 `65536` 的整数；既有命中预算约束完整显示树。

交互对象须先挂接到真实 Engine Stage，并显式设置自定义局部 `hitArea`。HT1 不从 Graphics 边界或绘制像素自动推导命中区域；视觉上可见并不等于可拾取。

```ts
import { createMouseInput } from '@egret/engine/web/input';

// engine and button are existing genuine Engine and display objects.
// button is attached to engine.stage; HT1 requires an authored local hit area.
button.hitArea = { x: 0, y: 0, width: 40, height: 24 };
const scope = engine.createScope();
const input = createMouseInput({ engine, scope, width: 160, height: 100 });
button.on(input.events.activate, event => {
  selectAt(event.payload.globalX, event.payload.globalY);
  engine.renderFrame({ width: 160, height: 100 });
}, { signal: scope.signal });
```

游戏时间和重绘由应用决定。输入分发不会启动时钟、自动渲染或改变浏览器的原生默认行为。

## 事件与释放顺序

冻结句柄提供 `state`、`events` 和同步 `dispose()`。状态为 `idle`、`pressed`、`closed`。每个适配器拥有独立的 `begin`、`end`、`activate`、`cancel` 描述符，均沿当前真实显示路径冒泡。`begin`、`end` 可取消，真实分发结果决定是否激活。阻止任一默认行为会否决激活；仅停止传播不会否决。

冻结载荷包括 `pointerId`、`globalX`、`globalY`、`pointerType: 'mouse'`、`button: 0`。取消额外包含原因 `pointercancel`、`blur` 或 `pagehide`。每次分发创建新的真实 Event。

| 输入 | 可观察行为 |
| --- | --- |
| idle 时主鼠标左键按下 | 一次命中查询。命中时保存原目标和按下位置，进入 `pressed`，再分发 `begin`；未命中保持 idle。 |
| 匹配鼠标释放 | 一次捕获逻辑位置并查询 Q1。先清除按下记录并进入 `idle`，再向仍挂接的原目标分发 `end`，即使释放未命中或选中了兄弟节点。 |
| 满足条件的成功 end | 回调后在同一捕获位置查询 Q2。仅当 Q1、Q2 均为原目标、两次默认行为均允许且所有权／挂接仍有效时激活。 |
| 匹配 pointer cancel 或 blur | 先清除按下记录，再最多向可用原目标取消一次，使用缓存的按下位置。Blur 保持适配器开放且 idle。 |
| Pagehide | 按条件取消，随后关闭；回调或清理失败也必须关闭。 |
| 适配器、Scope 或 Engine 关闭 | 同步封闭输入、丢弃按下记录并清理，不发送游戏取消事件。 |

Q2 使 end 回调对可见性、变换、裁剪、子节点交互和顺序的修改在激活前生效。释放不会为 `end` 更换目标。被忽略的指针和状态不会读取坐标或检查布局。原生回调重入会关闭适配器；普通嵌套类型化分发保留既有事件语义。

## 支持的浏览器布局

surface 为当前 document／window 中的真实 Canvas。普通 Element 祖先链必须在 64 个元素以内到达该 document，不经过 Shadow 或外部文档边界。Canvas 及祖先不使用 CSS transform、perspective、translate、rotate、scale，zoom 为 `normal` 或 `1`。Canvas 的 padding 和 border 宽度为零，`object-fit` 为 `fill`。

相关按下和匹配释放读取新的原生边界矩形，将客户端坐标换算到固定逻辑宽高。换算不乘设备像素比、不取整、不钳制坐标。在此范围内支持通过矩形体现的 CSS 尺寸缩放。这是限定桌面鼠标范围，不代表任意变换布局、移动端输入、指针捕获、移动或手势支持。

## 所有权与错误

同一捕获 surface 只能有一个获取中或存活的适配器。它注册 Canvas `pointerdown`（不捕获），Window `pointerup`、`pointercancel`（捕获），Window `blur`、`pagehide`（不捕获），以及原始 Scope 上一个稳定回调、冻结 `once: true` 参数的 abort 监听。

关闭先发布 closed 状态并仅释放自身输入令牌，再执行可能调用外部代码的清理。按逆序尝试移除每个已获取或尝试获取的原生监听，随后移除 abort 监听。同步 add 尚未结束时立即封闭输入，待 add 收束后再移除该监听。移除失败仍是失败；逻辑关闭不能证明物理清理成功。适配器不释放 Host 保留权、不移除借用的 Canvas，也不清理其他所有者。

显式清理失败仅抛出一次 `MOUSE_INPUT_CLEANUP_FAILED`，保留首因和后续清理错误。获取失败抛出 `MOUSE_INPUT_SETUP_FAILED`。原生读取、命中、回调或重入失败关闭适配器，并通过受保护的诊断端口报告 `MOUSE_INPUT_CALLBACK_FAILED`。包括 `undefined` 在内的假值原因与“未失败”保持可区分。同一已报告原因／wrapper 不在退栈时重复报告；后续确实不同的源异常仍可观察。正常回调关闭静默抑制后续输入；关闭后又抛出异常的回调保留源异常。

取消依赖在调用 once 订阅前通过自身状态退休该订阅。替换原始 signal 的公开移除方法不能绕过 Scope 所有的清理。此保证不覆盖任意私有字段修改或被破坏的内建对象／浏览器环境。

## 验证与后续工作

行为测试使用真实公共 SDK 对象及受控浏览器端口，证明状态、顺序和故障处理，不证明真实 DOM 行为。真实 Canvas 收集器使用已安装的默认无界面 Edge、实际鼠标输入、固定逻辑位置、渲染 RGBA 依据，以及精确的原生／abort 注册和移除观察。声明的设备缩放因子 `2` 用于区分错误 DPR 换算，不是手机或性能基准。

六个独立源码反例分别省略 begin、改换 end 目标、省略 Q2、仅检查 Canvas CSS、将坐标乘以 DPR、或省略一次物理移除。每个反例必须到达真实基线，再因指定观察项失败。构建／导入／设置失败不算成功反例。共享 Engine 和分发器的变化还需要七项保留原生门禁、严格类型、包边界、双语／来源审阅和强制推送前检查。结果及交付在验证记录中分别记录。
