验证区分接口、规划行为、类型、结构策略和交付。合成策略夹具只证明检查器的拒绝与解析行为。公共行为夹具使用构建后的公共入口，以及独立编写的字面名称、坐标、数值和诊断位置。反例先通过真实基线，再只修改一个拥有的副本并触发指定见证；setup 失败单独记录。因预算重叠而无法成功的拟议上限见证会明确分类。

官方[图集文档](https://esotericsoftware.com/spine-atlas-format)和固定 [4.3.13 源码](https://github.com/EsotericSoftware/spine-runtimes/tree/b7beb2ccbbce667a12c02f44d070644f59b04968/spine-ts/spine-core)提供格式与实现参考，不验证白鹭代码。规划器不添加官方运行库依赖、第三方素材或 Editor 导出。发行物完整性、声明闭包及适用上游条款属于独立运行库集成证据。已接纳计划中的来源声明与 SHA-256 文本仍是未验证声明。

动画语义、完整特征清单、获得许可的真实 Editor 导出、Spine 二进制接纳、图像解码、暗色 tint/混合/采样一致性、运行库版本矩阵、实际渲染帧、Native SDK、手机、物理 GPU/OS 回收及性能/电耗，均为独立交付义务。浏览器与原生门禁不在此纯规划切片的执行范围内，不能改标 PASS。官方运行库动画/渲染集成独立推进。
