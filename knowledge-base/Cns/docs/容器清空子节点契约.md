# 显示容器批量分离契约

[English](../../en/docs/container-remove-children-contract.md) | 简体中文

**0.49.0 · S103 / V054。** `DisplayObjectContainer.removeChildren(): void` 清空显示层，同时保留节点、后代、资源及清理所有者。它认证真实接收者，空容器也先检查 Engine 再检查接收者生命周期，在全部直接边校验后无调用者 hook 提交；Sprite 和 Stage 继承方法，根值／类型、规格、依赖和协议不变。

~~~ts
container.removeChildren(); // 返回 void；分离全部当前直接子节点。
~~~

方法无参数，不提供索引区间或公开 children 数组；严格类型拒绝参数，普通 JavaScript 忽略多余实参。叶节点／代理／原型仿制接收者以 INVALID_DISPLAY_CONTAINER 拒绝，不读取公开 getter 判断身份。身份之后，所属 Engine 关闭为 ENGINE_CLOSED；Engine 开启或未绑定的已销毁接收者为 OBJECT_DISPOSED。空／重复调用同样保留生命周期检查。

私有已捕获 WeakMap 操作先检查全部直接边与 parent 一致；不一致以 DISPLAY_TREE_INVARIANT 拒绝，原列表／parent 不变。这一不变量和分配失败原子性属于源码义务，不声称执行过私有故障或物理 OOM。同步提交只删除各直接 parent 并将自有列表长度归零；不调用可覆盖的 removeChild、getChildAt、numChildren、assertUsable 或 child.dispose，不新增事件、诊断或时钟操作。

保留各子节点精确身份、自身后代顺序、监听、hitArea、图形、Scope owner、租约与永久 Engine 归属；不 dispose、release、克隆或转移 owner。同 Engine 可重新加入，异 Engine 仍按既有规则拒绝。接收者自己的 Graphics／变换／裁剪／parent 不变。调用者保留的引用数组及旧浅快照不被就地清空；已保存自有帧不变，新 bounds／hit／capture 依当前剩余树。既定事件路径保持原派发语义。

~~~ts
scope.use(layer);
layer.addChild(first);
layer.addChild(second);
layer.removeChildren();
layer.addChild(first); // 同一真实对象；资源与原清理所有者仍存活。
~~~

示例假设真实存活、同 Engine 的对象已按各自所有者注册；清理继续由原 Scope／Engine 完成。独立第一方实现仅修改 Container 与私有显示树两个产品文件，复用既有显示树／Scope／资源／帧契约，Apache-2.0；AI 协助实现、测试及双语材料，独立评审只接受其记录范围。
