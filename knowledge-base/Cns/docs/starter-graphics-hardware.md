## 启动器

Windows 11 使用 Edge 157.0.4341.46 和 RTX 5090 Laptop GPU。Galaxy Z Fold7 使用 Chrome 157.0.8103.78 和 Adreno 830。两台设备上的 WebGPU 均选用了硬件适配器。每台设备覆盖自动选择 WebGPU、受控无适配器时回退 WebGL2，以及双后端各四种适配模式。检查覆盖容器实时缩放后的裁切和输入坐标、`480 × 270` 逻辑画布、1.5 倍比例下的 `720 × 405` 后备缓冲、变换后的显示对象命中、角色移动并拾取金币、标签输出，以及 PNG 加载、去重和释放。桌面使用浏览器鼠标输入，手机通过 Chrome DevTools 协议在真机提交触摸事件。

Windows 原有的 `cover` 检查要求中心坐标精确相等，浏览器报告 `240.000034`，预期为 240。修订后检查偏心位置，容差为一个 CSS 像素投影到逻辑空间后的距离，并保留金币拾取检查。Fold7 首轮 WebGPU 用例取样时，移动角色恰好遮住圆环孔洞。把取样提前到角色开始移动前即可单独验证孔洞。两轮原始记录均保留。

每台设备的 10 个启动及适配用例全部通过，Fold7 包含一次单项补测。各强制后端和适配模式从导航到观察到首帧完成的时间为 Windows WebGL2 156.1–164.8 ms、Windows WebGPU 294.1–316.7 ms、Fold7 WebGL2 1,320.9–1,368.0 ms、Fold7 WebGPU 1,312.9–1,421.5 ms。各模式仅采样一次，浏览器进程已启动。

启动器压力用例在 80 个浏览器帧回调间隔中移动 1,200 个矩形，另串行采集 20 次 CPU 渲染与提交时间，以及随后独立的 API 空闲等待时间。单位为 ms。

| 设备 | 后端 | 回调间隔 p95 | 渲染与提交 p95 | 空闲等待 p95 |
| --- | --- | ---: | ---: | ---: |
| Windows | WebGL2 | 4.2 | 2.5 | 6.2 |
| Windows | WebGPU | 4.3 | 2.1 | 3.4 |
| Fold7 | WebGL2 | 16.6 | 13.1 | 5.2 |
| Fold7 | WebGPU | 16.6 | 10.9 | 8.0 |

## Graphics

每台设备的每个后端均通过 32 个后备缓冲像素检查，覆盖轮廓覆盖率、内部像素保持、线性渐变色标、孔洞、重绘后回放。共享几何检查确认相同绘图复用几何，不同半径和颜色各自独立，恢复原绘图时再次复用。径向渐变颜色由压力用例单独检查。

修复前，启用边缘平滑后，Windows 两个后端的半透明三色标径向渐变各有 4,182 个深内部像素偏差超过 2 个通道值，共比较 96,224 个像素，最大通道偏差为 200。渐变自适应细分在相邻区域留下了细分程度不同的边，平滑逻辑随即把内部边误判为轮廓。修复在每次切分中传递原始轮廓标记，仅在轮廓边生成淡出带。修复后，两台设备的两个后端均有零个内部像素超出容差。`GS05` 同时覆盖无需图形设备的轮廓回归。

首轮 16 个互不相同的径向渐变图形在 Windows 两个后端均被预算拒绝。WebGL2 报出 `WEBGL2_GEOMETRY_RANGE`，底层在裁剪时用尽元组比较预算，WebGPU 返回 `WEBGPU_FRAME_BUDGET`。测试保留默认预算。正式采样使用 6 个径向渐变图形，首个捕获帧含 15,398 个源三角形和 879,712 字节的逻辑几何数据。四种设备与后端组合在 40 次仅变换的捕获中保持几何身份，12 次交替换色重绘的复用和区分也符合预期。

40 个串行压力帧记录浏览器回调间隔、CPU 捕获、包含 Host 工作的提交，以及从 CPU 捕获到 API 完成的合计时间。冷绘制一栏单独采集 5 次，在新建图形上绘制半径 200 的径向渐变，计时结束后才捕获。单位为 ms。

| 设备 | 后端 | 回调间隔 p95 | 捕获 p95 | Host 提交 p95 | 合计 p95 | 冷绘制中位数 / 最大值 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| Windows | WebGL2 | 16.7 | 1.5 | 4.5 | 11.3 | 28.1 / 29.7 |
| Windows | WebGPU | 8.4 | 1.5 | 3.2 | 8.6 | 27.5 / 28.7 |
| Fold7 | WebGL2 | 24.9 | 7.0 | 8.5 | 19.9 | 34.5 / 52.6 |
| Fold7 | WebGPU | 33.2 | 11.6 | 8.8 | 23.2 | 34.4 / 45.6 |

大型径向渐变重绘仍有冷细分成本。串行负载每帧等待 API 完成，回调间隔包含该等待。

以上采样覆盖指定的短时浏览器负载。Chrome 触摸事件、CSS 实时缩放和固定后备缓冲比例检查的范围不含 Android 系统旋转、折叠切换及真人操作。提交与完成计时包含 CPU 和浏览器开销。本轮未测量 GPU 执行时间、呈现延迟、温控和功耗。[#55](https://github.com/cnedwin/Egret_rebuild/issues/55) 与 [#92](https://github.com/cnedwin/Egret_rebuild/issues/92) 的正式验收状态不变。
