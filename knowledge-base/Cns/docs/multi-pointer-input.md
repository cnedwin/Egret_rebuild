# 场景多触点输入

[English](../../en/docs/multi-pointer-input.md) | 简体中文

这是 M3.3 的首个实现切片。父工作包仍负责焦点、键盘和原生文字编辑，本切片不提供这些完整能力。Android/iPhone 真机验收保持 OPEN。

## 公共入口

应用提供逻辑输入流时，使用 `@egret/engine/input` 的 `createPointerInput`；符合浏览器 Canvas 配置时，使用 `@egret/engine/web/pointer` 的 `createBrowserPointerInput`。两者都要求已成功启动的真实 Engine、属于它的开放 Scope，以及固定的正数逻辑宽高。默认 Engine 和旧 `@egret/engine/web/input` 入口不增加导出，MI1 鼠标与按钮语义保持不变。

浏览器工厂通过私有装配绑定获取真实 Engine 画布。同一画布不要同时安装 MI1 和新桥接。运行时可选入口 `@egret/runtime/input` 提供无 DOM 的状态机；普通游戏代码使用保留 Stage/Scope 权限的 Engine 入口。

双区域示例（仓库中的 `examples/multi-pointer/index.html`） 使用显式命中区域与同时独立的触点。它是输入验证场景，不是可复用摇杆或手势识别器。

## 会话与路由

每次接受按下时返回不透明、不可变的会话，包含桥接代际、递增触点 ID 和宿主报告的指针 ID/类型。宿主指针 ID 可以在结束后复用，但旧会话不能更新新会话。鼠标、触摸和笔均可准入，不忽略非主手指。默认容量为 10，可显式设置为 5–32 的整数。超额抛出 `POINTER_INPUT_CAPACITY`，不替换已有触点；浏览器报告该拒绝并继续处理已有输入。

每份不可变触点快照包含会话、序号、观察时间戳、逻辑坐标、按钮状态和视口修订号。压力与接触尺寸是可选报告值，不代表物理精度保证。坐标须有限；接受观察的时间戳非负且不递减；按钮为 0–65535 的整数，压力为 0–1，尺寸非负。非法样本不产生部分状态修改；未知或过期会话在读取更新数据前返回 false。

按下按既有显式命中区域与裁剪规则查询当前已提交场景几何。未命中对象时仍为全局观察者接受会话。命中目标默认获得逻辑捕获，显式捕获与释放均按触点管理。释放捕获后按当前位置重新命中，但初始所属目标仍须有效。逻辑捕获独立于浏览器原生捕获和键盘焦点。重新挂接使用当前真实路由；移除、隐藏、禁用或祖先禁止子对象交互会取消所属触点。在提交场景/UI 修改后调用 `sync()`；输入分发也会在回调前后重新核查所有权。

`onContact` 在目标路由之前同步接收 begin/move/end/cancel。目标脱离或销毁后，观察者仍接收终止清理。目标事件使用既有捕获、目标、冒泡规则，触点数据位于 `event.payload`；cancel 还包含 `reason`。观察者中取消或关闭后，不会再向目标发送 begin/move。终止状态在回调前移除，因此 up 后的捕获丢失不会再次终止。原始输入层不合成 click、tap 或游戏激活行为。

拒绝重入 begin/move/end；允许回调内捕获、释放和取消。观察者或路由事件失败时关闭输入、取消剩余触点，并保留最先发生的失败和清理错误，不关闭 Engine 的其他子系统。消费者须将 cancel 视为释放持续游戏动作。公共事件不复用可变临时触点对象。

## 坐标、中断和生命周期

视口修订变化时，先按旧修订取消全部触点，再发布新映射，随后需要新的按下。`setInteractive(false)` 暂停准入并取消活动触点；`setInteractive(true)` 不重放输入。应用须将设备就绪状态连接到此开关：WebGL 上下文丢失会暂停浏览器桥接，应用仅在渲染宿主就绪后恢复。WebGPU 和其他宿主须显式连接真实丢失/就绪通知。

浏览器配置要求同一 realm 中已连接的 Canvas、无变换的普通祖先、正常 zoom、Canvas 零边框与内边距，以及 object-fit fill。正数 CSS 边界只映射一次到逻辑坐标，DPR 仅影响渲染。尺寸变化、滚动、方向和可视视口变化会在采用新映射前取消触点；拒绝不支持的 CSS 变换。适配器在触点开始前仅为 Canvas 设置 `touch-action: none`，清理时恢复原内联声明。只监听 Pointer Events，避免额外兼容鼠标通道重复激活。

窗口失焦、文档隐藏、pagehide、pointercancel 和活动原生捕获丢失会清除触点。Scope 销毁和 Engine 关闭会终止桥接并清理监听器；Engine 在等待宿主结束前启动该清理。重新交互需要新的按下。普通编辑焦点变化不等于窗口失焦。小游戏/原生适配器，以及浏览器悬停、滚轮、键盘和 IME 集成仍有各自 M3.3 验收项。

## 证据与剩余验收

定向测试覆盖运行时事件序列、真实 Engine 路由/生命周期及受控浏览器端口。受控浏览器测试不能证明 WebIDL/原生捕获或物理触摸。实际桌面浏览器采集须分别记录浏览器版本、源码身份、注入与物理事件差别、清理和结果。构建或 CI 成功不代表设备或性能验收。

定向回归通过 176 项：运行时 41 项、Engine 13 项、受控浏览器 24 项，以及既有鼠标／按钮 98 项。桌面原始记录（仓库中的 `examples/multi-pointer/browser-verification.json`）记录了 Windows x64、Node 26.7.0、Playwright 1.62.1 与无额外启动参数的 headless Edge 155.0.4283.62。十项检查通过，另有一项部分抬指观察；91 份服务文件和 105 条源码／工具／配置记录均与冻结字节匹配，上下文、浏览器和服务清理成功。原生捕获、移出区域、双触点独立操作、五个注入触点、取消、尺寸变化后的映射、Engine 关闭及原创区域像素属于独立的桌面证据范围。注入事件不能证明物理手指或手机支持。

较早采集尝试因部分抬指假设而失败，与修正后的执行分别保留。此 Edge 版本的非空 CDP touchEnd 移除指定 ID 的触点，采集器明确记录此版本限制。另一次入口尝试因原生 TypeScript 包不提供旧 AST API，在启动浏览器前停止。最终入口使用已有的有界字面量读取器，工具失败均不计为产品通过。

完整固定环境构建后，使用已安装的 Playwright 1.62.1 模块与本机 Microsoft Edge 复现。输出父目录须存在，输出本身须为仓库外全新的绝对目录：

~~~text
node tools/verify-multi-pointer.mjs --playwright <Playwright模块绝对目录> --output <全新输出绝对目录>
~~~

采集器在启动前冻结实际服务依赖，保存原始结果和截图；断言、清理或快照变化均使执行失败。其他浏览器版本属于新观察。完整仓库门禁、CI 与受保护合并独立于此记录。既有源码／类型检查仅准入此次精确评审的可选包入口和私有关闭端口修订，历史源码清单及编译器观察保持原样。

Android Chrome/iPhone Safari、真实笔输入、移动键盘/IME、手势仲裁、完整控件和 X-MTouch/1 保持 OPEN。M1.2 全脏 10.3 ms 对照 8 ms 目标的原有结果仍为 OPEN。本输入实现不改变这些结果，也不声明输入延迟预算已达标。

实现为原创 Apache-2.0 白鹭代码，由 AI 协助编写并接受独立评审。浏览器语义对照 [W3C Pointer Events Level 3](https://www.w3.org/TR/pointerevents3/) 核查，未复制上游实现源码。不增加运行时依赖。
