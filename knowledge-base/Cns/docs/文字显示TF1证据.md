## 公开夹具实际证明的范围

TF01 覆盖真实 Engine/Scope/缓存归属、不透明接收者、挂接及工厂专用构造。TF02 检查十标量有序读取、不可变采纳、短暂同字段守卫、原始 getter cause 和不隐式工作。TF03 覆盖有符号墨迹、栅格 guard/密度、直接变换角点和绘制顺序集成。TF04 覆盖精确显式行、空/空白布局及图像到空结果替换。

TF05 检查原子替换、替代、迟到结算和提供者失败保留。TF06 检查共享工作、独立真实调用者租约及调用者拥有的缓存存活。TF07 检查 abort/清理前的 Scope closing、公开同名状态遮蔽不能绕过 Engine closing、首个清理 cause、迟到栅格清理和保存帧生命。TF08 检查未改缓存容量、共享 64-image 记账、包含隐藏叶的 65536-node 准入、65536 authoring/output units 和 262144 clip references。八个 TF 组是分类，不是八个已执行测试。安全整数修订耗尽仍是限定源码/类型义务；未使用虚构运行时计数器。

## 保留失败与修正

初始 `red-r1` 创建真实 Engine/Scope/缓存并先准备缓存，随后缺失工厂断言失败。另一份历史 `constructor-r1` 到达真实字段后，预期结构化构造拒绝失败。其源码输入已有修正，但 emitted 叶仍为重新构建前版本；这是历史 RED，不是已修产品执行。更早的单独探针在 ESM 入口解析时失败，尚未观察构造；它既不是该真实 RED，也不证明绕过成功。

源码发现 TF1-CONSTRUCTION-001（P1）指出缺少私有创建权限。修正在构造工作之前验证私有 token，不改变公开导出或错误码。源码关闭与后续 `public-r3` 构造成功分别记录。原较广实现审阅仍属未完成历史；后续独立十四文件源码审阅是另一份完成记录，不重写原结论。

严格类型历史完整保留：`types-r1` 因正例 contracts 导入无法解析（TS2307）失败，改用既有公开 Engine 类型入口，不加别名或依赖。`types-r2` 已拒绝不完整请求，但实际 TS2740 与冻结预测 TS2345 不同。`types-r3` 已拒绝全部 import，其中三个相似名称实际诊断为 TS2724，而非 TS2305；仅修正预测 marker。`types-r4` 通过原 18 ordinary 和 12 import 对照。独立审阅随后发现两个 P2 覆盖缺口 TF1-TYPE-001/002：在具备全部字段方法时单独保护不可访问品牌，以及分别拒绝错误 Engine/Scope/缓存参数。新增四个补充案例。`types-r5` 正确拒绝这些参数，实际 TS2740 而非预测 TS2345；只修正三个 marker。`types-r6` 通过保留的表达式、数量和精确位置，不豁免任何拒绝。

`public-r1` 在 90 秒超时后未完成，同时有明确 TF03、TF07 失败 marker，不能称静默超时或 PASS。聚焦输出显示期望 +0 与真实 -0 矩阵分量不符、缺少必需宿主 timer，以及 remaining-cleanup 列表错误地再次包含主要 cause。夹具修正保留有符号零公式、提供实际宿主端口，并分离首个 cause 与剩余错误。容量测试在 5000 ms 后超时；双分支诊断显示，在旧真实租约仍存活、上限不变的情况下，需要显式 idle 基线。该诊断也使用重新构建前产物，不是当前产品验收。

`public-r2` 和 `allTimed-r1` 也在 90 秒超时，没有最终统计。后续选择的 `nonTree-r1` 通过 12/12，但排除了最后的大树组。一处夹具块把重复平铺 Stage 挂接改为自底向上组装 65534 个互异真实 Sprite，再一次挂接 Stage。独立源码审阅保留全部原 oracle：Stage 加隐藏 TextField 加 Sprite 共 65536 节点，新增节点达到 65537。该 setup 修正不改产品上限或遍历；源码复杂度分析不是实测性能声明。完成的 `public-r3` 随后通过完整选定夹具。

`legacy-r1` 是正常完成的失败：19/20 通过，raster 回调实际 2 次、期望 1 次。T1 要求空计划也调用 rasterize/release；图像请求加空请求因此需要两次回调，空图像必须为 undefined。修正保留该契约、原对照及私有边界。`legacy-r2` 通过 20/20。原失败收据、raw hash、夹具后继与审阅截止均保留在共享记录。

## 审阅、来源与验收限制

源码审阅在十四文件中未发现可行动问题。不同审阅分别关闭构造发现、两个类型覆盖发现、公开夹具修正、大树 setup 和 legacy collector 元数据/计数修正。独立保存 CPU 审计核对 24 份闭合收据和 48 份 raw stream，没有可行动发现。它排除了当时执行中的 `verify-r1`；后续完整结果有自己的收据，不追溯纳入该审计。这些评审者进行源码/保存结果审阅，不执行验证。

实现与本文档属于第一方、AI 辅助工作，组合既有 Egret 文字/资源/图像/所有权/显示契约。这是限定来源说明，不认证全球原创性或训练来源。代码和文档保持 [Apache-2.0](https://github.com/cnedwin/Egret_rebuild/blob/main/LICENSE)，既有第三方声明独立保留。本证据包未引入竞品实现或新依赖。

CPU 字面像素和完整 prototype 门禁不证明字体、原生 TextField、CJK 覆盖、性能、手机、Native SDK、Spine、3D、完整 UI 或迁移验收；这些要求保持开放。原生 TF1、当前公开 prepush 与远程交付需分别审阅实际后继；本截止不授予这些结果。

独立保存的 renderer freeze 审阅匹配 702 份输入及 548 份产物（274 份 JavaScript／声明加 274 份 map）、187 个选定图文件、88 个 JavaScript 模块、249 条导入边及 12 个精确对照逆向。其双入口 renderer 图不含显式文字入口、TextField 工厂或 runtime TextField 叶。这是用于既有渲染回归的有限保存源码／结果审阅，不是原生 TextField 验收或性能结果。在此后继截止点，五项既有原生 route 尚未运行；当前必要 prepush 与远程交付仍待完成。
