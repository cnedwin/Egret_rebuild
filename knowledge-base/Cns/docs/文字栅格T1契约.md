# 文字栅格 T1：Provider 与资源契约

[English](../../en/docs/text-raster-t1-contract.md) | 简体中文 · [已记录证据](文字栅格T1证据.md)

工程预览 **0.24.0** 引入首个文字资源编排切片。T1 定义不依赖 DOM 的 Provider 协议，将测量、有界栅格准备、真实 Texture 租约与清理连接起来。独立审阅在记录的最终源码中关闭六项核心问题；有界 CPU 行为、图像身份、私有单元及源码边界对照通过。严格类型及完整既有核心源码验证已在记录范围通过；最终 prepush 和交付由交付验证分别记录。本契约描述应有行为，不代表整个引擎验收；各项验证范围及保留失败见配对证据。

## 显式入口与 Provider

使用 `@egret/engine/text`，它转发不依赖 DOM 的 runtime 文字入口，唯一运行时值是 `createTextRasterCache`。普通 Engine 根入口、宿主接口与生命周期保持不变。应用提供 Provider；T1 不创建 Canvas、不加载字体、不做文字 shaping，也不加入 TextField。

```ts
import { createTextRasterCache } from '@egret/engine/text';
import type { TextRasterProvider, TextRasterRequestInput } from '@egret/engine/text';

const input: TextRasterRequestInput = {
  text: 'A', fontFamily: 'Test', fontSize: 16, fontWeight: 400,
  fontStyle: 'normal', lineHeight: 10, locale: 'und', direction: 'ltr',
  density: 1, fillColor: 0xffffff,
};
// engine and provider are supplied by the application.
const cache = createTextRasterCache(engine.assets, {
  provider: provider as TextRasterProvider, maxResidentEntries: 0,
});
const prepared = await cache.acquire(input);
if (prepared.kind === 'image') {
  const texture = prepared.lease.value;
  // Bitmap borrows this exact lease; the caller owns release.
  prepared.lease.release();
}
cache.dispose();
await cache.whenIdle();
```

这是接入示意，不是完整字体 Provider 或可运行示例。Provider 的 `identity` 必须符合 `[A-Za-z0-9._-]{1,64}`，`profile` 为 `canvas-explicit-lines-v1`。缓存快照保存 Provider 接收者及 `measure`、`rasterize`、`release` 函数；后续替换属性或修改回调自身的 `.call` 不能改变这些已捕获操作。

`measure(request, context)` 接收冻结的自有请求及本次调用专属的 `context.createPlan` 能力；该能力最多签发一个真实计划。`rasterize(plan, context)` 接收自有计划、取消信号及已准入的图像／scratch 字节预留，返回真实 `ImageData2D`，无墨迹计划则返回 undefined。`release(plan)` 在最后一次测量／栅格使用终结后、成功公开交付前只尝试一次。结构对象、Proxy、其他作业或重放的计划没有签发身份。

## 精确请求与有符号布局

键保留全部十个请求字段、Provider 身份／对象／profile、固定 straight-sRGB RGBA8 策略及显式 `fontGeneration`，不裁剪空白、不归一化，也不自动替换 density。`invalidate()` 推进字体代次并一起退休测量／栅格路由，不检测系统字体变化。

文本必须是完整 UTF-16，最多 8192 个代码单元及 64 个显式源行。LF、CRLF、CR 保留精确源范围，末尾分隔符增加最后一个空行。有界控制字符准入策略保留汉字、组合序列、阿拉伯文、ZWJ／ZWNJ 与变体选择符，但不承诺字形覆盖或 shaping。字体族最多 256；locale 在记录的有限匹配规则下最多 64 个 ASCII 代码单元。

有符号墨迹与超出排版边界的部分，和逻辑空白边界分别保留。基线及每行 advance／墨迹指标定义自有 logical、ink、content 边界。栅格边沿按请求 density 取 floor／ceil，并增加 2 个栅格像素的 guard；每条边最多 4096，像素最多 1048576，字节最多 4194304。这些是分配上限与确定的留边策略，不是实测字体误差容忍度。

冻结的单行样本为 advance 8、基线 5、墨迹 (-1,-4,7,2)、行高 10。density 1 对应 12×10、图像字节 480、scratch 字节 960；density 1.5 对应 17×14、952、1904，放置为 (-8/3,-2/3,34/3,28/3)。这些期望值属于元数据算术，不是原生字形像素。无墨迹结果保留布局，图像／scratch 预留为零，仍调用 rasterize／release，并返回无租约的 `kind: 'empty'`。

## 固定路由与独立预算

一个已提交的缓存生命周期属于一个真实 AssetManager，在专属私有类型下只保留 32 个可复用 ref：`egret.text-raster.t1.slot.00` 至 `.31`。命名空间冲突以原始管理器 cause 拒绝创建，不能另分配前缀或重新开启已提交生命周期。ready 的 LRU 路由可退休，旧调用方租约仍有使用权；有活跃需求的 loading 路由不能被抢占。

| 选项 | 默认值及硬上限 | 最小值 |
| --- | ---: | ---: |
| `maxGenerations` | 64 | 1 |
| `maxPendingJobs` | 4 | 1 |
| `maxWaiters` | 128 | 1 |
| `maxCallerLeases` | 128 | 1 |
| `maxResidentEntries` | 32 | 0 |
| `maxMetadataBytes` | 2097152 | 4096 |
| `maxLogicalImageBytes` | 16777216 | 1 |
| `maxPendingRasterBytes` | 8388608 | 1 |

全部选项为安全整数；undefined 选择默认值，null 无效。保留代次包括 current 与 retired 记录；旧活跃调用方、晚到 actor 及隔离记录继续占用各自上限。逻辑元数据／图像／scratch 单位区别于实际 JS、字体、Canvas 或 GPU 内存测量。栅格准入先检查输出再检查 scratch，后续提案失败时不部分提交任一预留。取消不退款仍使用其记录的 actor；最多准入 8 个待完成 idle 观察者。

## 真实租约与如实终结清理

图像结果为每位成功调用方提供独立的真实 `AssetLease<Texture>`；共享工作可以共享实际 Texture，同时保留独立使用权。Bitmap 借用精确租约，Scope 可以负责释放。缓存驻留只在真实 ready 交付后开始，并加入精确管理器代次；移除驻留只释放缓存租约，不释放旧调用方租约。调用方释放后，已保存指标与自有 ImageData2D 仍可读取。直接 dispose 借用的 Texture 属于误用：既有 `TEXTURE_DISPOSED` 保持终态，后续缓存路由必须退休这份过期代次。

单个调用方取消只移除自身需求；最后一个取消先令本地路由／等待者失效，再 abort 或移除外部监听。晚到的测量／栅格终结只能清理。`dispose()` 同步、幂等地关闭缓存，故障后继续清理并释放自身驻留；真实调用方租约保留至自身释放或管理器／Engine 撤销。AssetManager 自动关闭先令自身全部 entry、租约及等待者失效，再调用受信任缓存关闭与外部清理；既有 Scope／Stage 顺序保持。

`getStatus()` 返回新的冻结标量快照，包括保留／隔离计数，关闭后仍可调用。`whenIdle()` 等待 current／retired actor 与监听清理，普通 ready 调用方／驻留不阻止 idle。Engine dispose 保留既有完成契约，不会无限等待任意文字 Provider；晚到文字 actor 的清理通过缓存 idle／诊断单独观察。

无法证明完成的清理进入隔离，不伪造退款或重试。release 故障阻止发布，保留主要错误并关联精确清理 cause；idle 只在 actor 实际终结后拒绝为 `TEXT_CACHE_CLEANUP_FAILED`。返回错误计划使用 `TEXT_PLAN_INVALID`，实际 measure 抛出／拒绝使用 `TEXT_MEASURE_FAILED` 并保留同一 cause。调用方抛出同名公共类／错误码、或重放旧故障，都不会取得本次第一方调用身份。准备交付但已被撤销的租约使用 `TEXT_RESOURCE_FAILED`，保留真实管理器 cause；不发布伪租约。

## 独立性与后续工作

这份第一方设计组合既有白鹭资源、图像、所有权及取消契约，实现由 AI 协助。该来源说明覆盖已标识的实现与所复用契约。代码与文档保留 Apache-2.0；既有第三方声明和研究素材权利分别保持。原生字体后端需要独立的设计、来源及验收。

T2 需要建立实际浏览器字体、栅格 surface／后台工作、TextField／布局与目标平台行为证据。Spine、完整 UI／3D、实体手机、Native SDK、shaping、性能及完整迁移保留已有开放需求。此前 0.23.0 Mesh2D／原生证据属于历史渲染证据，不能证明文字验收。
