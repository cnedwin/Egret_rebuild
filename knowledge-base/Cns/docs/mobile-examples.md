# 响应式交互示例

[English](../../en/docs/mobile-examples.md) | 简体中文

## 入口与范围

按照固定 Node 26.7.0／pnpm 11.25.0 完成环境准备后，运行 `pnpm example:browser`。终端显示的本地网址与根路径 `/` 进入 `/examples/mobile/index.html`，可选择角色、独立触点区域、UI 列表或多语言段落。UI／段落明确选择 WebGL2 或 WebGPU，角色／触点使用 Canvas。服务器仍仅监听本机并使用有限文件白名单；手机真机需要另行配置转发连接，本次不开放局域网服务。

新入口组装已有公开 SDK，不增加 Engine API、输入协议、渲染器或包依赖。角色页复用现有 resource-scene 会话、PNG 租约、字体身份和序列帧播放；面板复用有所有权的 UiRoot、文字／段落缓存与宿主生命周期。序列帧控件已使用原生 HTML click 控件，继续通过既有固定入口与内容生成说明访问。

## 布局与密度

外壳测量可用内容宽度，上限为 960 CSS 像素。UI 与段落在逻辑宽度低于 700 时单列，达到该阈值时双列；真实段落度量决定文章／列表位置和条目高度。控件可换行、保留明显的键盘焦点，并在画布交互之外提供原生按钮。只有画布禁用触摸滚动，页面其他区域仍可滚动。

面板／触点的逻辑坐标与 CSS 坐标一致。角色场景保留 192×128 世界及 3:2 比例，输入适配器仅做一次 CSS 到世界坐标的转换。有效密度限制为 [1,2]：面板／触点 Host 比例等于密度，角色 Host 比例等于 CSS 宽度／192×密度。因此 backing 尺寸按 CSS 尺寸×有效密度向上取整，不在输入坐标中重复乘 DPR，也不使用 CSS transform 或 zoom。

Host 比例和输入逻辑尺寸是构造参数。内容宽度或 DPR 变化时，外壳依次保存应用状态、取消旧触点、关闭旧所有者、挂载新视口。过期的初始化必须完成关闭，下一实例才能启动。角色选择、已提交服装和暂停状态保留，动画时间重新起算；面板保留选择、滚动及字号；触点不跨重建存活，暂停输入状态可保留。这是预览的简明生命周期，不是 Engine 热调整 API。

## 输入与所有权

画布只安装一个 BrowserPointerInput 桥，鼠标、触摸与笔拥有各自会话。角色点按要求完成且未被阻止的路由、移动不超过 12 CSS 像素，以及释放时重新命中的目标一致。列表选择检查二维移动、当前行绑定和真实重新命中；拖动、回收与取消不能把旧行当作点按。拖动滚动属于示例策略，同时保留按钮和原生滑块。多触点区域演示独立捕获及区域外释放。尺寸变化、滚动、失焦、取消和关闭按现有适配器契约终止按住的会话。

旧 MouseInput API，以及现有固定示例 HTML／模块、输入步骤、源码封存、尺寸、像素参考和采集器全部保留。验收应使用明确的固定入口，不把响应式页面接入旧像素采集器。固定资源场景的鼠标激活行为不变。UI 文字准备使用示例内的有界队列，遵守现有四任务缓存预算。

## 验证与边界

针对性 Node 检查覆盖几何／密度策略、所有者替换、初始化竞态、取消、异常后的清理和服务器访问。浏览器命令使用外部 Playwright 1.62.1，输出目标必须是仓库之外尚不存在的目录：

```text
node --test tests/mobile-examples.test.mjs tests/publication/m0-foundations.test.mjs
node examples/mobile/verify-browser.mjs <playwright-root> <new-output-directory>
node examples/mobile/verify-device.mjs <new-output-directory> [--adb <adb-prefix>] [--port 9222]
```

有限矩阵使用默认无头模式的真实 Microsoft Edge：四个 DPR 1 桌面鼠标上下文、四个 DPR 3（有效 2）的移动视口触摸上下文，以及 UI／段落的 WebGPU 移动上下文。检查输入、重排、横竖屏和小尺寸、运行中 DPR 变化、所有权清理、实际服务源码身份和面板 GPU 读回。截图与原始结果独立于固定采集器。桌面触摸模拟不能证明 Android／iPhone 真机、人类输入法、持续温度／功耗、GPU 耗时、独立字形正确性或 M4 验收；这些要求继续未完成。源码身份与 CI 不能替代这些结果。

设备命令只使用 Node 内置模块。它要求 `adb` 恰好可见一台设备且主机端口已反向转发到该设备，通过既有 DevTools 端点驱动四个场景，并记录就绪状态、有界有效密度、后备尺寸、画布触摸策略、每个场景一次实际路由的合成触摸、双触点页面上的逻辑焦点转移与按键焦点移动、两个按住触点的取消、纹理被阻断时的失败会话与其恢复，以及旋转与密度变化后的会话重建与选择保留。退出前恢复它改动过的每一项 Android 设置，输出 `summary.json` 与每场景一份记录。合成 DevTools 按键样本在 Android 上并不可靠——通道有时将其判为无效，有时延迟投递——因此按键焦点与激活只记录不断言，按键验收仍需实体键盘。面板场景还需要一次真实导航后才会接受合成触摸，命令中已包含该步骤。这是可复现的真机观察，不是硬件资格验证：原生输入法、笔输入、手掌误触、温度与功耗、持续运行与 iOS 仍未完成。

## 来源

新外壳与应用连接逻辑为独立编写的第一方 Apache-2.0 示例，使用已有白鹭公开入口和示例局部资源组装。已有 Ahem、Noto 字体、CanvasKit／Skia 分发及声明继续遵守登记许可证，本次不引入新的第三方源码或二进制。参见[段落 SDK](readonly-paragraph-sdk.md)、[多指针契约](multi-pointer-input.md)和 [UI 契约](ui-data-panel.md)。

运行中密度用例同时改变 DPR 和一个 CSS 像素的视口宽度。仅通过调试协议修改 DPR 可能改变读数却不发出尺寸或分辨率媒体事件；不宣称能通过事件检测这种无通知覆盖。预览在恢复可见时也会复查，不进行持续轮询。

2026-10-30 的本地记录使用 Node 26.7.0、Playwright 1.62.1 和默认无头配置的 Microsoft Edge 156.0.4314.50。十个独立上下文的 485 项检查全部通过，实际服务的 188 项源码身份保持一致；45 项针对性 Node／源码／夹具检查通过。另有十项角色状态检查通过，覆盖已提交服装／暂停的恢复、快速尺寸变化和字体清理。截图使用稳定视口，避免整页截图临时扩张视口；等待条件使用同步轮询。这些是有限桌面结果，不代表真机或性能验收。
