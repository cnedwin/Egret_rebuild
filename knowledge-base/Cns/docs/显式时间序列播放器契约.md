# 显式时间序列播放器

[English](../../en/docs/sequence-player-contract.md) | 简体中文

状态：已实现，下方记录有界 CPU／类型与桌面不透明浏览器验收，2026-10-10。本工作包将自有序列元数据连接至已有 Bitmap。

## 公共接口

根入口 `@egret/engine` 与 runtime 入口导出 `createSequenceClip`、`SequencePlayer`，以及类型 `SequenceClipInput`、`SequenceFrameInput`、`SequenceClip`、`SequenceRegion`、`SequenceSample`、`SequencePlaybackMode`。工厂接收 `unknown` 并执行校验；输入类型说明有效结构。

```ts
interface SequenceFrameInput {
  readonly x: number; readonly y: number;
  readonly width: number; readonly height: number;
  readonly durationSeconds: number;
}
interface SequenceClipInput {
  readonly atlasWidth: number; readonly atlasHeight: number;
  readonly frames: readonly SequenceFrameInput[];
}
type SequencePlaybackMode = "once" | "loop";
class SequencePlayer {
  constructor(bitmap: Bitmap, clip: SequenceClip, mode?: SequencePlaybackMode);
  applyAt(elapsedSeconds: number): SequenceSample;
  readonly lastSample: SequenceSample | undefined;
  readonly isDisposed: boolean;
  dispose(): void;
}
```

构造不改变 Bitmap 当前裁剪，默认模式为 `once`。`applyAt` 接收有限、非负的绝对秒数，允许向前或向后选择时刻；调用零时刻即重置。本包不增加隐式计时器、调度器、资源获取、增量时间累积或动画事件。底层采样器仍属内部实现。现有 clip 准入保留最多 1024 帧、binary64 累积时长校验、自有字段读取、真实身份与冻结自有数据。

## 绑定、所有权与提交

播放器借用真实且存活的 Bitmap 及其当前确切 AssetLease。仅接受完整图像的 Texture 视图：原点为零，视图尺寸等于不可变图像尺寸。clip 声明的图集尺寸必须匹配该图像。现有工厂在播放器绑定前已校验所有帧。使用完整图像 Texture、当前已裁剪的 Bitmap 可以绑定。

每次应用依次检查播放器身份与生命周期、Bitmap 身份与生命周期、Engine 开放状态，然后检查确切当前租约、租约与 Texture 权限，最后检查时间。更换或清空租约报告 `SEQ_BINDING_CHANGED`，即使新租约指向相同 Texture。重新赋值确切同一租约仍有效，下次应用会恢复采样裁剪。

绑定与图像事实读取权威私有状态，不依赖可被覆盖的公共访问器。播放器通过预先捕获的 Bitmap 原始裁剪 setter 应用不可变采样区域。裁剪与自然尺寸一起提交；只有裁剪成功后才提交 `lastSample`。失败调用保留原裁剪与采样状态；外部销毁副作用不回滚。采样及区域冻结，不保留图像、租约或调用方输入。

成功构造时，播放器绑定目标所属 Engine 的亲和性，其他 Engine 的 Scope 因此通过现有所有权规则拒绝收纳；销毁后亲和性仍保留。绑定不安装清理订阅，也不授予目标所有权。

`dispose` 幂等且终止播放器，丢弃 Bitmap、clip、租约引用，只保留最后的不可变采样。它不销毁 Bitmap、不释放租约、不恢复裁剪、不关闭 Engine。缓存观察值仍可读取。Scope 或 Engine 退出通过现有目标与租约生命周期规则阻止再次应用，不安装隐藏播放器订阅。

## 错误与边界

构造优先级：Bitmap 身份、对象生命周期、Engine 状态、必需绑定、存活租约与 Texture、模式、clip 身份、完整图像与图集匹配。现有错误保留代码，包括 `BITMAP_INVALID`、`OBJECT_DISPOSED`、`ENGINE_CLOSED`、`BITMAP_TEXTURE_REQUIRED`、`ASSET_LEASE_RELEASED`、`TEXTURE_DISPOSED` 及 clip 准入代码。无效模式报告 `SEQ_INPUT_INVALID`；非完整 Texture 或尺寸不匹配报告 `SEQ_ATLAS_MISMATCH`。

应用优先级：`SEQ_PLAYER_INVALID`、`SEQ_PLAYER_DISPOSED`、目标生命周期、`SEQ_BINDING_CHANGED`、资源权限、`SEQ_TIME_INVALID`。接收者通过私有身份检查。伪造接收者的查询或销毁报告 `SEQ_PLAYER_INVALID`。本包不新增公共错误类承诺，调用者检查 `code`。播放器返回的 `SequenceSample.stopped` 始终为 false；显式选择时间不等同停止控制器。once 在总时长及之后保持最后一帧并标记 `atEnd`；loop 在总时长精确回绕。保留原采样器 binary64 行为。

trim 偏移、旋转图集区域、帧标签与事件、自动播放、骨骼、Spine/DragonBones 运行时集成、插值及原 MovieClip 行为迁移属于后续工作。已接受的 Spine 与完整迁移需求不变。

## 已记录验收 — 2026-10-10

14 项公共根入口行为检查通过，覆盖显式 once／loop 边界与向后选帧、裁剪／采样提交、精确租约变更、伪造接收者、权威状态、资源失败、销毁缓存及 Engine 归属。类型门禁通过 54 项根入口、5 项 web、28 项工程预期负向诊断。产品实现前已观察到缺失能力的行为失败。保留的沙箱整仓尝试包含 18 项临时文件权限失败及 1 项真实 B1 源码闭包准入失败；仅选定生成除法表达式见证的修复解决了集成问题，未改变采样器或通用解析拒绝规则。随后实际原生 B1 驱动通过全部 13 个案例。这些记录不能替代新的完整推送前门禁。

独立绑定的原生公共播放器观察在 Canvas 与 WebGPU 上完成 **8 次捕获、256 个像素、零容差的 1024 次精确通道比较**。每个后端通过公共 API，在同一 Bitmap／精确图集租约上应用 0／0.125／0.375 秒。构造保留裁剪；返回采样不可变并已提交至目标。播放器销毁保留缓存的最后采样，Bitmap／租约仍有效。由调用方退出 Bitmap／租约／Texture／原 Engine 后，不同的兼容 Host 重放了不可变的保存红帧。保存产物的独立审阅未发现可操作 P1／P2 问题；浏览器／服务器／上下文关闭以及外部 Job／进程／EOF 记录相符。

选取的[公开证据投影](../../evidence/sequence-player-native.json)包含原始 RGBA 数组、当时源码身份、播放器证明与审阅／结果摘要。独立的[Bitmap 前置验证](bitmap-region-evidence.md)保留此前源码范围与不完整前序记录。本次播放器观察使用 Windows x64 上的 Node 24.19.0、Playwright 1.62.1、Edge 154.0.4258.62，固定 8×4 DPR1 帧与无额外标志的默认浏览器启动。精确 Canvas 读回 warning 保留为 1 条提示；其他 warning／error 仍致命。

交互示例通过源码／语法审阅，但尚未在浏览器中测试其 UI。不透明夹具不证明全部播放器生命周期案例的浏览器覆盖、部分透明度校准、完整 A2、硬件加速、手机、性能、完整 UI／骨骼／Spine 或完整旧工程迁移；这些义务保持独立。
