## 模块与产品边界

Native Node公共包根`@egret/project`和scanner/visitor命名导入无需VM flags，与随包CommonJS互操作。直接原生导入依赖随包ESM入口因内部无扩展名导入失败。VM linker/CJS桥是模拟集成证据；实际bundler/浏览器交付、worker/native SDK及tree shaking未接受。精确保留已知Experimental VM Modules警告，有成功路径意外stderr拒绝控制；运行带有警告限定，不是无警告。

未知kind/领域schema、文件内容/摘要/授权、认证历史、崩溃安全存储、实际文件系统别名/containment及Proxy副作用隔离仍未检查或不支持。本证据编写检查点的最终集成prepush仍待执行；结构哈希/链接/编译器/知识库检查不能替代人工双语含义或发行授权，不表示重跑浏览器。历史0.13 WebGPU身份/结果不变。V003/编辑器、手机/原生/3D/生产性能，以及完整R008/V006导入→独立可编辑工程→等价玩法→持续视觉/代码/AI编辑→真实目标发布/更新仍待完成。
