## 其他保留失败与严格类型后继

修正前，measure 后关闭为 1/2，交付／idle 为 0/2，构造回滚为 0/1，管理器 materialization 为 0/1，驻留记账为 0/2。之后的 release 后关闭对照为 1/2，错误地返回 `TEXT_RESOURCE_FAILED` 而非 `TEXT_CACHE_CLOSED`；准确后继通过 2/2。原始失败、fixture 及源码绑定继续保留。首次驻留诊断误调用 `status()` 属于 harness 故障，不是产品缺陷；修正诊断只测量引用，不改变缓存算法，也不证明 GC。

首次严格类型运行 types-r1 因 runtime/text 开发解析缺失而失败。环境链接修正后，types-r2 到达真实负例 consumer，但未满足其契约：19 条诊断而非 18 条，其中含附带 TS7006 及结构管理器预测不匹配。两次结果均未接受或豁免。经有界审阅的 fixture 后继保留原定对照，types-r3 已通过真实无 DOM 正例以及精确 18 条普通、9 条隔离逐项诊断；单独绑定的注释后继随后通过 types-r4。本次截止时完整既有核心源码验证已通过；最终 prepush、公开材料整理及远程结果在交付验证中分别记录，保持这些绑定源码的页面稳定。

fullVerify-r2 仍属于实际失败的整仓运行。源码审阅将 205 项失败追溯至旧合成策略 fixture 不完整的文字入口基线。三处替换的 fixture 后继保留全部注册测试体、mutation、预期原因及 checker；专项后继已通过 205/205。此 fixture 范围与真实 T02 复制图对照分别记录。之后完整的 fullVerify-r3 运行通过 2,037/2,037，failed／cancelled／skipped／todo 均为零，不替换或豁免此前失败。

## 真实 RED 与保留的修正

T1 实现前，公共基线创建真实 Engine／图像／Texture 资源，取得同代次的独立真实租约并捕获普通 Bitmap；之后显式文字入口才因 `ERR_PACKAGE_PATH_NOT_EXPORTED` 失败，精确保留为指定功能断言的 cause。这是单独的历史 T01 功能 RED；未改动的相同 fixture 后来通过，并取得真实文字 Texture 租约。

首次 38 组运行发现另一项产品缺陷：T22 期望 `TEXT_MEASURE_FAILED`，但 Provider 的 release 回调同步 dispose 缓存后，收到 `TEXT_CACHE_CLOSED`。实现改为先提交已终结的主要错误及相关等待者，再调用外部 release；未改动后继运行通过 38/38。原始失败输出与源码身份继续记录，没有放宽测试期望，也未增加故障容忍。

这些保留的初始观察保持原始源码绑定。上方当前有界后继具有自身已审阅源码及保存结果；后续源码变化不能在没有准确验证绑定时继承此前通过结果。

## 公共组实际覆盖的内容

独立定义的字面 Provider 使用 `literal.t1` 身份、显式行 profile、冻结源文本／样式指标及自有图像字节。行为组覆盖身份与 Engine 归属、顺序快照／读取 cause、生命周期／命名空间冲突、1024 次真实退休、共享延迟工作、精确 Unicode／源限制、density 1／1.5 有符号几何、空白布局、专属计划身份、预留／终结顺序、取消及移除监听重入、隔离、真实 Scope／Engine／缓存清理、代次复用、LRU 驻留及独立预算边界。

调用方结果是来自真实 AssetManager 的实际 `AssetLease<Texture>`，Bitmap 与已保存 CPU 帧使用真实自有图像。独立取消信号及晚到 Provider gate 区分逻辑取消与 actor 实际终结。图像字节重复一个字面测试颜色，不属于字体栅格化或原生渲染对比；逻辑计数也不属于实际内存或性能测量。

冻结规格包含 44 个控制组；公共 payload 覆盖 38 个指定组。T01 单独运行，T02 属于源码／类型范围，T18–T20 保留 descriptor／指标／图像身份义务，T44 为受影响旧回归／证据范围。公共／源码混合组中，状态及 churn 成功不能独自证明内部精确 ref 分配、无未记账历史表、标量序列耗尽或分配故障来源；这些私有／源码对照需要自己的证据。在待完成作业硬上限为四时，32 个同时 loading 路由不是可达公共样本；不把模拟私有状态写成真实公共行为。
