# 候选显示子树

[English](../../en/docs/prepared-display-subtree.md) | 中文

这项有限的 M2.4 前置能力将离线显示根放到已有容器的子节点位置，在不改变可见树的前提下捕获真实共享帧，并显式发布子节点替换。分层的 [Spine RESET 槽](spine-reset-slot.md)及[应用恢复流程](spine-recovery-integration.md)现已消费这项 CPU 基础能力。本项不提供跨版本保状态替换，也不代表 M2.4 完整验收。

## 公共契约

构建后的 `@egret/engine` 入口增加一个仅类型导出的 `DisplaySubtreeTicket` 和两个 Engine 方法：

~~~ts
const ticket = engine.prepareDisplaySubtree(ticketScope, target, candidate);
const frame = engine.capturePreparedDisplaySharedFrame(ticket, frameOptions);
ticket.commit(); // 只发布 CPU 显示树
ticket.dispose(); // 撤销尚未提交的票据，不处置借用节点
~~~

target 必须是附着于本 Engine Stage 的真实普通 DisplayObjectContainer。candidate 必须是真实离线 DisplayObject，保留自己的变换、裁剪与身份。两个根分别由同一 Engine 下真实且开放的 Scope 持有；它们的 Scope 与票据 Scope 可以不同。由生成器持有的 Mesh 后代保留真实所有权链。伪造外观、代理、其他 Engine、Stage 根、重叠、环、已处置节点、已关闭所有者或受禁止的托管 UI 边都会被拒绝。沿用现有 UI 边权限，不授予 UI 包装节点的新权限。

candidate 成为 target 的**唯一子节点**。target 自己的图形及位置保留；原子节点按原顺序脱离。不会把 candidate 的孩子偷偷移出它的根。候选捕获通过既有共享遍历应用父级变换、不透明度、可见性、继承材质、裁剪与兄弟绘制顺序。

一张票据只影响一个目标。每个 Engine 最多允许 32 个目标保留待提交票据。target 与 candidate 两棵子树合计最多 4,096 个节点（含两个根），各自深度最多 128；目标祖先链与所有权链分别限制为 128。Stage 其他部分沿用已有共享捕获限制。被拒绝的请求不会取代有效待处理意图；同目标的新请求只有通过准入后才使旧票据失效。嵌套或重叠的待处理目标／候选被拒绝。调用方应处置失效票据以归还名额。

## 校验与所有权

准备记录受影响子树的真实拓扑、所有者、变换、外观、几何／内容与绑定，同时记录继承祖先的变换／外观／绑定及子节点顺序修订。捕获与提交重新校验这些记录、资源使用资格和所有权链。先修改再恢复原值仍会改变修订，因此依旧失效。重新挂接、处置、页租约释放和 Mesh 绑定变化均不能发布候选。祖先子节点顺序变化会使票据失效；无关兄弟的内容变化可以继续。

返回的帧是不可变快照，其中兄弟动画姿态可能早于之后的当前场景。候选捕获仅在 target 到 candidate 的边上替换私有父子读取器，从不临时修改可见树，也不放宽普通捕获不变量。全部校验后，CPU 发布使用预先分配的子节点存储；该发布区段不调用应用回调、不再分配。帧捕获或时钟重入期间不能提交。

票据借用全部新旧节点、Scope、播放器、租约与资源。票据处置、被新意图取代和提交均不会处置或获取这些对象。提交只让旧孩子脱离，不关闭其 Scope、不停止时钟、不消费事件。调用方根据自己的呈现策略显式退休旧所有者。关闭票据 Scope 会撤销票据；关闭节点／资源所有者会使使用失效。旧所有者仍按自己的常规生命周期清理。沿用现有脱离／输入语义，不提供新的指针、键盘焦点或输入事务。

## Host 边界与 Spine 消费层

应用可把真实候选帧传给既有 Host 的 `stageSharedFrame`，等待 `upload.ready`，再分别提交 CPU 票据与调用 `upload.submit()`。只有 Host 拥有 GPU 就绪、设备代际、绘制完成和原生退休权限。上传就绪不会呈现；CPU 提交也不会呈现。Host submit 可能在原生绘制开始后失败，本 API 不回滚 CPU 状态，也不承诺跨域原子性。撤销 CPU 票据不会撤销独立的 Host 上传；放弃请求时应用须处置两者。已经捕获的帧在票据取消或提交后，仍可按普通 Host 规则重放。

先完成耗时的资源加载与语义准备，再捕获票据。旧目标的动画／内容变化会使快照失效，因此应采用有限的最终捕获／上传／提交窗口并明确应用时钟策略。SDK 不会偷偷暂停全局时钟。[RESET 槽](spine-reset-slot.md)已提供精确动画／皮肤验证、静默零时刻初始化、最新意图取消和自有参与者退休。[应用恢复流程](spine-recovery-integration.md)利用真实 Host 代际及票据重建设备资源，保留活动 CPU 玩家与事件游标，分别记录 CPU 发布、原生提交和结算；本 CPU 基础能力本身不增加 Host 原子性。跨版本保状态替换、更广恢复覆盖和 completeSpine 仍未完成。

## 验证与来源记录

[公共示例](https://github.com/cnedwin/Egret_rebuild/blob/main/examples/prepared-subtree/README.zh-CN.md)组合原创纹理 Mesh、Bitmap 及带裁剪和透明度的矩形。2026-11-04，针对性行为与相邻回归通过 139/139，其中包含 28 个新增 CPU 行为用例及一个严格类型套件。四项不抑制的 TypeScript 7.0.2 负例分别记录 TS2741（3:7）、TS2740（3:36）、TS2554（3:8）、TS2739（3:42），每项前均重新运行完整正例基线。包边界检查通过，新增私有装配边逐项列明；四包依赖方向与无 DOM 核心保持不变。

默认有界面 Edge 156.0.4314.58／Playwright 1.62.1／Node 26.7.0 下，WebGPU 与 WebGL2 均通过。每后端验证十次图像观察，每次六个固定像素点、24 个通道：上传、取消和仅 CPU 提交时保持旧像素；显式呈现；冲突；取消与提交后分别重放旧帧／候选帧。关闭时额外持有一个已就绪上传，最终待处理帧归零，恰好处置两张自有纹理。原始截图／读回和实际执行输入身份单独保留；[可移植摘要](https://github.com/cnedwin/Egret_rebuild/blob/main/examples/prepared-subtree/verification-summary.json)记录哈希与边界。

早期尝试保留失败状态：缺少导入映射别名导致未执行；CSS 小数坐标使截图变成 65 像素；初版参考错误地把逐绘制继承透明度当作离屏组透明度。修正后的独立合成计算为青色 alpha 0.5 叠在绿色 alpha 0.5 上，线性绿为 0.75、蓝为 0.5，并允许量化造成的单通道值误差 1。初版 CPU 夹具误将已由 binding 持有的 Mesh 节点交给 Scope；修复为 Scope 持有 binding，并认证真实所有权链。动态增加后代暴露了一处重叠漏洞，现已拒绝。初版类型预期使用通用 TS2345，现冻结实际诊断。前几轮边界检查正确拒绝未声明依赖边，随后仅准入精确审查过的新增边。

源码、针对性执行、浏览器观察、独立审查、完整受保护 CI 与合并交付各自独立。本记录不声称物理内存、手机／设备资格、性能改善、设备恢复、输入集成或 Spine 兼容完整性。M1.2 的 10.3 ms 观测与 8 ms 目标不变。一方实现、原创几何、测试与文档由 AI 辅助独立编写，采用 Apache-2.0；既有依赖声明与许可保持不变。

一次仅涉及采集器的中间修改在最终输入索引中残留未使用的锁文件键，导致证据封存失败，保留为不完整尝试。修正后的最终采集排除该未使用锁文件与生成报告，同一原生检查通过。

审查修复：在托管子节点辅助函数复制列表前，先用 O(1) 检查目标直接子节点配额（4,094 个孩子加目标／候选两个根可准入，4,095 个不可）。完成根与生命周期准入后，该配额检查先于托管子节点遍历。待处理受影响节点集合执行交集检查，因此新候选包含先前待处理候选时会被拒绝。祖先记录只保存有界修订与所有权链，不保存整份兄弟数组。

这个固定的已绑定对象 API 不重新派发子类 assertUsable、可附着／可绑定钩子，也不读取公共 parent／children getter。应用应在准备前执行自己的语义守卫；Scope 所有权只证明生命周期与所属 Engine，不代表这些守卫的许可。普通 addChild／addChildAt 行为保持不变。公共子类回归覆盖了这一区别。
