# 核心框架首段实现计划

[English](../../en/docs/core-framework-first-slice-plan.md) | 简体中文

版本：0.1 · 2026年10月8日 · 状态：首段执行计划；三个职责包已完成限定实现，实际结果见[核心框架实现记录](核心框架实现记录.md)。下述步骤保留原计划，不作为新增执行记录。

**Goal:** 将已写成合同的取消、Scope、显示树、事件及Engine生命周期实现为可编译、可运行、可审阅的自主TS核心小切片。

**Architecture:** 沿用已交付的工程/API候选规范，在独立产物目录建立contracts、runtime、engine三个实际职责包。没有职责的其余候选包暂不建立；以headless host端口运行，后续可接图形执行器。首段核心按候选规格独立编写，参考研究与第三方开发依赖保留来源。

**Tech Stack:** 项目固定TypeScript 7.0.2、ESM、pnpm工作区；Node 24内置测试器仅用于开发验证。没有第三方运行时依赖。编译器版本只确定本次原型验证工具，不代表D013工具链全面验收。

**Spec:** [工程结构](工程技术架构与项目结构.md)、[公共API](公共API设计与命名规范.md)、[代码规范](代码规范与质量门禁.md)。本计划是其中生命周期与显示树子集，不是全规范完成声明。

## Global Constraints

- 产物根目录为`outputs/白鹭引擎核心框架原型`，开发版本0.0.0；执行报告与失败链见[核心框架实现记录](核心框架实现记录.md)。项目从第一天按开源方式建设；本段交付是本地原型，公开仓库与发行包尚未发布，以文件hash追踪当前产物。
- 核心依据白鹭规格与标准独立实现，研究来源、第三方代码及开发工具分别登记归属；第三方编译器显式登记版本与许可证。
- 核心严格类型、noUncheckedIndexedAccess、exactOptionalPropertyTypes、verbatimModuleSyntax；lib仅ES2022、types为空，禁止DOM/Node隐式类型混入核心。Node测试/工具使用mjs。
- TypeScript类名PascalCase、成员camelCase、主类文件PascalCase，保留Event、DisplayObject、DisplayObjectContainer、Stage、Engine和Scope语言。
- 不写GPU、纹理加载、Sprite.graphics、布局、坐标变换、骨骼、原生VM、Agent服务或迁移实现；空白部分列明，不用占位接口宣称支持。
- 同步scope清理逆序、幂等并继续失败后的清理；不同scope不得接管相同值。取消先进入closing；关闭中登记本scope已有值拒绝且不提前清理，新无owner值清理后拒绝，foreign值拒绝不销毁。
- 对象在Scope登记或首次挂载时绑定Engine；detach保留绑定。跨Engine和显示树循环必须在改变父子关系前拒绝。递归清理携带发起根owner，不因无owner中间容器改变；foreign子树只detach并停止深入。
- 整次事件派发固定全部路径/阶段候选；新增下次、移除跳过、once调用前移除。捕获→目标capture→目标非capture→冒泡；priority有限整数降序及注册顺序。stopPropagation保留当前节点，stopImmediate终止当前；active同Event重入拒绝，异常后状态恢复。
- Engine关闭返回同一个Promise，拒绝新scope/挂载，先关闭scope与stage、停止host，再有界等待host.close。仅close成功resolve才确认宿主归还surface；普通或迟到reject保持隔离，首段没有解除隔离/重试接口。超时保留资源/呈现归属直到host成功完成，不误销毁borrowed设备；此段没有真实GPU，不据此证明GPU完成栅栏。
- 一个surface默认一个Engine，预留独占归属必须覆盖异步启动；启动失败也尝试清理。主错误及清理错误保留cause与cleanupErrors。

## Review Focus

1. 取消监听抛错/删除/新增/重入，仍只通知一次且完成后续清理；已经取消时新监听不补发。
2. Scope关闭中的重复登记与迟到结果，不能改变已登记资源的逆序顺序，也不能泄漏新结果或毁掉foreign资源。
3. 有/无owner混合子树与跨Engine挂载失败，原树和原owner不能被部分修改。
4. 捕获阶段改变目标监听、once嵌套、传播停止或handler抛错，结果符合整次快照并恢复状态。
5. 启动竞争、关闭重入、stop/close失败与deadline后迟到完成，独占surface不能过早交给另一实例。

## Task 1: 核心生命周期与显示树小切片

**Files:** 产物根的package.json、pnpm-workspace.yaml、pnpm-lock.yaml、tsconfig基线；packages/contracts/src的CancellationSignal/Disposable/Diagnostic/HostAdapter；packages/runtime/src的EgretError/CancellationController/Scope/ownership/Event/EventDispatcher/DisplayObject/DisplayObjectContainer/Stage；packages/engine/src的Engine/createEngine/index；tests/*.test.mjs、tests/types、examples/headless.mjs；tools测试与构建入口。

**Interfaces:**
- `CancellationSignal`: readonly aborted/reason、addEventListener("abort", listener, {once?})、removeEventListener；listener无DOM Event参数。`CancellationController.abort(reason?: unknown): void`。
- `Disposable.dispose(): void`及`Releasable.release(): void`；Scope.use接管其中之一，Scope.dispose同步，state为open/closing/closed，signal实现上述最小协议。
- `EventType<T>`和`createEventType<T>(key, {bubbles?, cancelable?})`绑定payload；`new Event(type, payload)`、`on(type, handler, {signal?, capture?, once?, priority?}) -> unsubscribe`、`dispatchEvent(event) -> boolean`表示默认动作未被阻止。
- `DisplayObjectContainer.addChild/removeChild/getChildAt/setChildIndex`；parent只读，numChildren只读；DisplayObject.dispose终结而removeChild仅detach；Stage由Engine创建并绑定。
- `HostAdapter`含surface身份、可选异步start、可选stop、异步close及`setTimeout(callback, delayMs) -> cancelTimer`端口，不要求DOM/Node。`createEngine({host, shutdownTimeoutMs?, onDiagnostic?}) -> Promise<Engine>`；原型默认关闭deadline为1000毫秒，正有限整数，属于失败边界而非性能目标。
- `Engine.stage`、`Engine.createScope()`、`Engine.dispose() -> Promise<void>`；图形功能、资产服务和features不在该段实现。
