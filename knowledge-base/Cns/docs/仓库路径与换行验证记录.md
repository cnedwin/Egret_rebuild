## 修复与验收边界

[路径身份与换行规范](仓库路径身份与换行规范.md) 分别定义可移植逻辑路径与按平台语义比较的绝对物理路径。文件指纹仍须覆盖完整原始字节。词法路径等价不能证明真实文件系统对象身份，也不能授权符号链接逃逸。

拟议规范使用 `* -text` 保留 Git 内容字节，对自研文本采用 UTF-8/LF 编辑器默认值，仅按完整路径、字节长度和原始 SHA-256 豁免完全未变的旧有非规范文本。写入器可以规范化新创作文本，指纹读取器绝不能如此处理。门禁必须同时检查新增、未跟踪和已跟踪公开文件，并在不重写文件的条件下比较工作、暂存和提交字节。
