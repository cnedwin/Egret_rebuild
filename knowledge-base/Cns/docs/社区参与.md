# 社区参与

[English](../../en/docs/community-participation.md) | 简体中文

白鹭从开发初期公开协作，入口是[贡献指南](../CONTRIBUTING.md)。已有核心生命周期、显示树和事件代码及设计知识库，可以从小型代码改进、文档、样本或方案讨论参与。远端仓库和许可证的实际配置在[当前版本](../当前版本.json)登记。

可从文档校勘、官方资料追踪、指标口径、授权样本或接口提案开始。首次参与只需选一项，说明问题、来源、建议与验证方式；不知道关联编号时注明“待维护者关联”。无需先承诺长期投入。

## 从提案到交付

使用 [RFC](../templates/RFC提案.md) 比较方案，经评审后用 [ADR](../templates/ADR决策记录.md) 记录决策。实现任务需先明确接口、负责人、依赖和验收，再开放认领；采用 [实验与验收](../templates/实验与验收.md) 留下可复现证据。讨论意见与实测结果分别记录。

公开仓库启用后，可用 Issue 报告问题、PR 提交变更；维护者应说明是否采纳、依据和下一步。存在分歧时保留备选方案与反对理由，涉及范围变化由项目负责人整理确认。

社区协调、文档维护、技术评审和验收职责随项目发展登记，当前维护者名单待设置。仓库、许可证与贡献流程保持可查询；参与者提交可分享的代码和样本，并按[公开表达规范](开源协作与公开表达规范.md)保护资料权限与私人信息。

## 公开实现的可信度

贡献按[实现与依赖规范](独立实现与第三方依赖规范.md)保留研究来源、第三方归属和自有设计理由。自主核心依据白鹭规格实现；讨论、示例和性能报告说明实现及测试范围。[鸣谢](../ACKNOWLEDGEMENTS.md)提供参考项目、实际依赖和工具索引，社区可以沿出处核查设计并继续改进。
