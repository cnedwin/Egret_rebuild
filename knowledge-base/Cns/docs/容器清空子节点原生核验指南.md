**0.49.0 · S103 / V054。独立评审已接受有限 R2 Canvas／WebGPU 执行；原 R1 失败保留为历史。** 显式模式为 --display-container-remove-children，通过既有 tools/verify-browser-png.mjs 与采集器机制核验普通不透明 Sprite 矩形，独立字面 oracle，不解码 PNG／纹理／字体或 SDK。精确入口／准入接口须以最终已审阅源码为准；本文不授予执行资格。

默认已安装浏览器／原始输入绑定、完整原始 buffer／独立期待、历史来源及普通清理须分别由保存实际结果评审接受。源码的超时／清理义务不等于失败路径已执行，不推导物理 GPU／手机／性能。参见[证据](容器清空子节点证据.md)；完整 Spine R020/V020、迁移 R008/V006、完整 UI／布局、高级 3D 及目标设备／性能接受保持 OPEN 或未验证；package 私有 0.0.0、宿主协议 1.0。
