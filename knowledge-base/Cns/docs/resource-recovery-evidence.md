2026-10-20 · M1.5 · 验证检查点

## 实现能力与验收边界

当前实现连接了规范化资源清单、依赖感知资源组、有界字节加载与完整性校验、分阶段帧上传，以及按设备代际管理的共享 WebGL2/WebGPU 恢复。[契约](resource-recovery-contract.md)规定接口、所有权和固定验收条件。本记录尚不代表 M1.5 完整验收或 M1.2 正式性能验收通过。

代码延续白鹭现有的 AssetManager、租约、帧捕获注册表和 Host 生命周期。源码、测试和程序生成的 PNG 素材为借助 AI 独立编写的第一方成果，采用 Apache-2.0。已有第三方依赖与字体的声明继续适用。引擎没有引入 Chromium 实现代码。

## C7 长时恢复结果

2026-10-20，固定 C7 七案在 Windows / Chrome for Testing 157.0.8103.6 上全部完成，并通过保存结果的独立评审。C01 WebGL2 与 C02 WebGPU 各完成原有 100 次资源循环、十次原生丢失和 30 分钟前台运行，记录输入稳定，并通过参考像素、网络、压力和清理检查。C1–C6 保留原始失败或不完整结果；本结果不能验收 Edge 155.0.4283.62，也不能确立旧失败唯一的 Chromium 因果归属。

| 案例 | 循环 / 丢失 | 前台时长 | 保留资源恢复最大值 | 重新加载恢复最大值 |
| --- | --- | --- | --- | --- |
| C01 WebGL2 | 100 / 10 | 1,800,005.1 ms | 773.2 ms / 上限 2,000 ms | 866.5 ms / 上限 5,000 ms |
| C02 WebGPU | 100 / 10 | 1,800,006.2 ms | 544.6 ms / 上限 2,000 ms | 596.0 ms / 上限 5,000 ms |

C03 借用设备恢复以及 C04–C07 丢失/关闭或恢复/获取/关闭案例也全部完成。七案均记录安全清理，没有待结算操作或清理错误，最终当前逻辑持有量归零。独立复算核对了 685 个原始 RGBA 回读、202 个显示截图、10,672 个声明参考点及全部 alpha 字节。这不代表整帧 RGB 等价或物理屏幕证明。全部 3,637 个原生检查和 4,815 个账目样本支持已记录的结果。

在原有 10 Mbit/s、80 ms 条件下，冷启动交互为 4,437.0–4,609.4 ms，低于 5 s 上限。每个初始场景传输资产 35,984 字节，完整应用 JavaScript 为 347,026–347,032 gzip 字节。固定压力计划在声明的逻辑预算内完成驱逐与重新上传。本次执行关闭了来源保留峰值与私有驻留峰值证据缺口。逻辑清理不证明物理 RAM/VRAM 回收、操作系统进程退役或移动端表现。

## C6 网络诊断

在 Edge 155.0.4283.62 上的有界诊断复现了普通资源替换失败。一个 HTTP 200 请求被 CDP 报告为 ERR_ABORTED，同一次加载的页面记录显示，其数据源自然读取到 EOF、校验并发布字节，PNG 加载也已完成。完整轨迹中，该任务没有数据源取消、reader 取消、原生 abort 或 fetch signal abort；故意取消的对照任务记录了相应标记。观察器没有溢出或报告错误。这排除了本次复现中已覆盖的引擎主动取消路径，不能推广为引擎不存在任何缺陷。

[Chromium 问题 568852319](https://issues.chromium.org/issues/568852319/dupes) 和[修复 8508456](https://chromium-review.googlesource.com/c/chromium/src/+/8508456)描述了相符的已完成 fetch 被误报取消的问题。精确的 [Chrome for Testing 157.0.8103.6 源码标签](https://chromium.googlesource.com/chromium/src/+/refs/tags/157.0.8103.6/third_party/blink/renderer/platform/loader/fetch/response_body_loader.cc)包含终态登记顺序修复。这些来源支持浏览器层解释；本次诊断没有观测浏览器内部，也没有确认该 Edge 版本包含哪些补丁。

C7 使用上述身份明确的独立浏览器执行，并保留其执行文件、版本和实际结果。网络完成断言、工作负载、资源上限和时长保持不变。旧失败和短诊断均不转为通过，不同浏览器的计时结果也不能组成同一基线与候选对。

## 回归与验证工具修正

B1 首次执行在采集器 1,197 次请求配额处遇到 HTTP 429；原始失败及 INCOMPLETE 包装回执继续保留。完成有界配额修正后，B1 真实重跑已通过。这是采集器请求预算问题，不能据此认定渲染存在缺陷。

resource-scene 首次执行在启动场景前拒绝了已安装的 Edge 补丁版本，记录帧数为零。随后，未修改的独立 Canvas 参考程序在 Edge 155.0.4283.62 上复现了全部九份原始字体 RGBA 与度量，结果逐项完全相同。经评审的准入后继允许这一精确环境，保留原 .45 参考、像素及容差；resource-scene 与 prepared-groups 随后完成实际应用执行并通过独立评审。这不验收其他浏览器版本、字体、一般中文渲染、输入法或字体性能。

第二次完整本地集成执行 `m15-full-gate-2` 保持 **FAIL**，退出码为 1：发布检查 290/290 通过；核心测试共报告 4,519 项，其中 4,491 项通过、28 项失败。二十七项失败来自 PNG 控制收到检查器路径，而非被拒文件的路径；SS1 则因旧 Bitmap 编译产物身份不匹配，在登记十个案例前拒绝执行。两者均属于验证工具的兼容问题。

定向修正保留原始身份和控制。PNG 检查器仅修正两处错误的诊断路径；SS1 增加精确评审后的 M1.5 Bitmap/SpriteSheet 完整组合，继续保留旧组合并拒绝未知或混合组合。这些修正没有改变产品源码或产品编译产物。

## 剩余验收

在上述验证截止点，全部计划内浏览器结果均已通过独立评审。最终工作包源码/结果/双语评审及完整受保护合并门禁仍待完成。交付以实际 PR 历史为准；本文不声明新的发布版本。

M1.2 正式成对计时在 M1.5 候选稳定后进行。功能检查、操作次数及 C7 时长结果均不能替代该测量。物理 RAM/VRAM 回收、操作系统进程退役、手机功耗与发热、不可用宿主、完整 Spine 和完整 UI 均不属于本记录的验收结论。各浏览器套件保留自身采样像素或完整区域的边界，组合回归不构成一般性的整帧 RGB 等价声明。
