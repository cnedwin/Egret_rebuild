# 国际社区文档目录规范

[English](../../en/docs/documentation-layout.md) | 简体中文

白鹭重构工程面向全球开源社区。公开简介先提供英文，再附中文简介或完整中文版本。仓库、包和示例的默认阅读入口使用英文，中文配套文件使用 `.zh-CN.md`。

知识库的所有阅读文档，包括证据解释与历史实验 README，英文放在 `knowledge-base/en/`，中文放在 `knowledge-base/Cns/`。英文目录与文件名使用英文词语或既有 API 名称。知识库根目录保留简短的英文优先双语 README，指向两套完整版本。

各语言版本的 `docs/` 承载当前设计与实现专题，`archive/` 承载历史研究；每轮研究／计划、实际执行与独立审计合为一份记录。合并时保留原日期、失败和证据链接，归档不代表重新运行验证。仓库级代理约定适用于整个知识库。

六套权威中文登记册／当前版本视图放在 `Cns/`，英文翻译放在 `en/`，通过登记的精确路径映射指向对应英文阅读文件。ID、状态、数字、依赖与历史证据身份保持一致。

可执行实验、资产、上游文件、中立机器证据与原始许可保留共享目录。历史实验命令在注明的共享目录运行。上游许可原件在资产旁逐字节保留，阅读副本遵循语言目录。

每次推送 GitHub 前，维护完整双语版本、相对链接与来源身份，审阅公开内容及翻译语义，并运行完整 `node tools/prepush.mjs`。结构检查验证目录与路径对应关系，不替代翻译语义、产品性能或完整引擎验收。[迁移记录](../../documentation-layout.json)保留阅读材料的新旧身份。
