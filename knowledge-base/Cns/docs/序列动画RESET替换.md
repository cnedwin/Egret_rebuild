# 托管序列动画 RESET 替换

[English](../../en/docs/sequence-reset.md) | 简体中文

可选入口 `@egret/engine/animation` 导出 `createSequenceResetSlot(engine, scope, target, initial)`，用新的不可变 ContentGroup 代次替换一个普通已挂载容器的唯一 Bitmap。既有 SequencePlayer 的精确租约绑定、旧播放接口、控制器事件和 Engine 时钟保持原契约。这是有界的 M2.4 增量，不表示完整 M2.4 已验收。

## 所有权与准入

初始版本标签、Bitmap 和真实 SequenceController 均为借用。控制器必须由该 Engine 为这个精确 Bitmap 创建。目标不能是 Stage，每个目标只能有一个 RESET 槽。应用负责其结构及控制器；托管 UI 不是此替换目标。

每个请求提供 `policy: 'reset'`、版本标签、同一 Engine 的真实 ContentLoader、精确图片/序列 ID，以及 `playback` 中的普通 SequenceControllerOptions。图片必须是所选序列的单页图集依赖。标签只用于应用描述，不授予资源或设备代次权限。槽借用加载器，只拥有新建的 Scope、资源组、Bitmap、控制器及准备票据。持久布局应放在目标容器上；候选 Bitmap 使用普通默认显示属性。

仅保留最新已接受请求。描述符、身份、依赖关系或容量拒绝不会取消已接受的待处理请求。准入后的内容加载失败，或依赖实际片段的标记/时长校验失败，只终止该候选并保留活动代次。新接受请求取消前一个候选；迟到的提供器结果不能发布，按既有资源回收契约处理。请求准入及实际创建控制器时都检查既有 256 控制器和共享目标声明上限。准入不预留容量，活动与候选控制器重叠时都计入上限。

## 区分就绪、捕获、CPU 发布和呈现

1. `ticket.ready` 只表示 CPU 内容就绪。加载期间旧序列和独立兄弟实例继续推进。候选以零速率初始化并静默启动，然后记录配置速率，仍保持暂停。初始化零时刻标记计入控制器已消费计数，但不调用应用监听器；恢复时不补发，后续循环的零时刻标记遵循原事件语义。
2. `ticket.capture(frameOptions)` 开启短暂的最终窗口，返回真实不可变候选帧，不改变活动显示树。只暂停正在运行的目标前任；应尽快提交或取消该窗口，没有自动超时，也不暂停全局时钟。Host 上传使用独立的既有 `stageSharedFrame` 接口。
3. `ticket.commit()` 校验真实准备子树，并将新活动代次发布为**零时刻暂停**。只回收槽拥有的前任。初始借用前任仍归调用方所有，若此前正在运行则保持暂停，可在合适时机由调用方释放其控制器和资源。结构/内容变化或槽暂停后的调用方命令会拒绝发布。不重绑定活动控制器。
4. 提交独立暂存的 Host 票据并等待完成。CPU 发布、上传就绪、提交和完成是不同状态。发布后的清理失败或 Host 失败不回滚 CPU 发布；清理报错后应读取 `ticket.state` 判断候选是否已提交。
5. 显式调用 `slot.getActive().controller.resume()` 推进新序列。配置速率为零时，须先设为受支持的正速率。

取消或发布前失败会释放全部候选所有者。只有在槽暂停旧运行控制器、且后续没有调用方命令改变其不透明命令修订标识时，才恢复它。调用方显式暂停、恢复、跳转、调速或停止始终保留控制权。原本暂停的初始控制器保持暂停。仅关闭编排 Scope 时，只要借用控制器自身的 Scope 和 Engine 仍开放，就会撤销未被后续命令改变的槽暂停。被拒绝的 stop/dispose 重入不会使已准备候选失效。槽/Scope/Engine 关闭会回收自有资源，槽不会释放借用的初始内容。即使提供器回调抛错，也会尝试清理所有独立所有者。回调可以关闭槽，但请求/捕获/提交重入会被拒绝。

完成、停止或故障的控制器仅通过原目标的弱关联保留 RESET 准入来源证明。只要 Bitmap 及内容仍有效，就可以再次 RESET 替换，而不重启或重绑定这个终止的控制器。取消可重复调用。候选取消或前任回收后，已捕获帧仍遵循既有不可变帧生命周期契约。

## 验证与限制

[公开行为测试](https://github.com/cnedwin/Egret_rebuild/blob/main/tests/sequence-reset.test.mjs) 覆盖独立时钟、相同 ID 的不同代次、静默零时刻标记、畸形/不匹配/外部 Engine 准入、内容失败、取消、取代、迟到完成、过期捕获、调用方命令所有权、共享容量及回收。严格正反类型夹具使用已构建公开入口，默认根入口不导出 RESET 工厂。

[示例](https://github.com/cnedwin/Egret_rebuild/blob/main/examples/sequence-reset/README.zh-CN.md) 从原创四色 PNG/图集输入构建两个像素和时长不同的真实代次。有限采集器使用真实 WebGPU/WebGL2 Host、精确 RGBA 端点参考、画布截图、独立暂存/发布/提交，以及保留帧回放。本地保存结果和最终发布记录分别陈述。不据此宣称手机、IME、性能、物理内存、设备恢复、保留状态替换或完整 M2.4 验收。
