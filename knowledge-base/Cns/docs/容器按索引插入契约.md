## 公共操作

`DisplayObjectContainer.addChildAt<T extends DisplayObject>(child: T, index: number): T` 返回精确传入对象，并保留推导出的子类型。Sprite 和真实 Engine 创建的 Stage 接收者继承该方法。Stage 可接收子节点，但不能成为子节点。使用者通过已构建的 `@egret/engine` 入口调用。

每次校验中，n 是接收者当前真实直接子节点数。接受 **[0, n]** 内的原始整数 index，-0 按零处理；index n 表示追加。小数、负整数、NaN／无穷、字符串、装箱数字、null 和 undefined 不经类型转换即拒绝 INVALID_INDEX。

| 当前关系 | 结果 |
| --- | --- |
| 已分离或属于另一直接父节点 | 在 index 插入，并精确移除当前旧边。保留其他来源／目标兄弟顺序和完整传入子树。 |
| 已是直接子节点 | index 表示最终位置，向前移动不减一。index n 是追加别名，最终位置为 n - 1，数量不变。 |
| 已在最终位置 | 仍认证、执行 preflight 并校验完整最终状态。结构无变化时也可提交新增所需的兼容亲和绑定。 |

[A,B,C] 中，(A,1) 得到 [B,A,C]，(A,3) 得到 [B,C,A]。新的对话框面板可以通过一次操作插入到已有关闭控件之后的背景层。

## 拒绝与 hook 顺序

1. 通过私有容器身份认证接收者；在读取接收者属性或调用 hook 前拒绝 INVALID_DISPLAY_CONTAINER。
2. 从接收者树选择亲和 Engine，存在时先检查真实 Engine 是否开放，再检查接收者存活；ENGINE_CLOSED 优先于 OBJECT_DISPOSED。
3. 通过私有节点身份认证 child，不读取形状／getter／proxy；不真实时拒绝 INVALID_DISPLAY_OBJECT。优先接收者树亲和，否则选传入树亲和，再检查选定 Engine 是否开放。
4. 依次检查 child 存活、Stage 根禁止、循环和当前含尾端索引：OBJECT_DISPOSED、STAGE_ROOT_ONLY、DISPLAY_CYCLE，最后 INVALID_INDEX。
5. 执行原始接收者 assertUsable 与传入 attachability hook。保留起始接收者是否已绑定的区分：已绑定时只执行其自身 bindable hook；起始未绑定时遍历其树；起始选择了 Engine 时遍历传入当前子树。开放检查先于绑定 hook；hook 抛出的值原样传播，遍历中的兼容性检查可拒绝 ENGINE_MISMATCH。重叠树可能多次调用同一 bindable hook。
6. 最后一个注册 hook 完成后，通过捕获的私有读操作获取两棵完整真实当前树、当前父节点／列表和来源直接边。从同一次捕获选择 Engine，接收者优先，根优先、末尾子节点优先深度遍历。先检查 Engine 开放、双方存活、Stage、循环和当前索引，再逐节点检查两棵树的身份、生命周期、直接边及已记录亲和；不存在 Engine 时同样完整校验。畸形／重复边拒绝 DISPLAY_TREE_INVARIANT；来源全部直接边也要校验。
7. 准备一个不外泄的计划并完成全部显式列表／值分配，然后通过捕获的写操作一次发布：此前未绑定节点的兼容亲和、不同来源列表替换、变化的目标列表替换、移动节点父映射。该最终区段不调用注册显示 hook、公共 getter／方法、资源或诊断回调。

公共 parent／numChildren／isDisposed、旧内部名称影子以及重写的显示读取／修改方法不构成状态权威。最终依据是 hook 后的真实当前状态。重入的重新排序／换父节点、Scope 注册、处置或 Engine 关闭均保留权威。

## 有限原子性与所有权

普通校验／preflight／准备拒绝，相对 hook 后状态不增加任何外层树、永久亲和、owner 或资源生命周期写入。成功发布同步且无回调；hook 主动成功产生的副作用在外层拒绝后仍保留。不存在亲和逆操作或 owner 回滚。

同 Engine 跨父节点／跨 Scope 移动保留清理所有者。传入已绑定节点可为兼容的当前接收者树绑定 Engine。永久 Engine A 亲和，包括任何当前后代，均不能转到 Engine B；分离保留亲和。全部未绑定的成功操作不产生 Engine 亲和。插入仅借用状态，不调用 Scope.use、租约获取／释放、dispose／cancel、渲染器或宿主操作。Bitmap 保留真实租约、裁剪及 owner；换父节点后实际 owner 清理仍是终态。

物理 OOM、提交中的原生基础操作失败及任意 realm 隔离不在该有限保证内。私有畸形边／分配观察需要另行授权的单元；普通测试不伪造这些故障。
