# 位图按钮

[English](../../en/docs/bitmap-button-contract.md) | 简体中文

工程预览 0.54.0 在现有 MouseInput API 所在的可选入口 `@egret/engine/web/input` 增加 `createBitmapButton` 及三个擦除类型。默认 Engine、Canvas、WebGPU、Runtime 入口不增加按钮 API。实现为独立编写的第一方 Apache-2.0 代码，不增加依赖或 Host 协议。

## 所有权与选项

传入真实且已启动的 engine、其开放 Scope、同一 Engine 下真实开放的 input、借用 textureLease、同尺寸的 up/pressed/disabled 皮肤区域及 onActivate。输入可属于同一 Engine 下另一个开放 Scope。控件持有私有 SpriteSheet 和真实 Bitmap；原始租约与输入继续由原持有者管理。将 display 挂到真实 Engine Stage，显式命中区域与皮肤尺寸一致。工厂不会自动挂载、推进时间或渲染。

冻结且校验精确接收者的门面提供只读 display/state、可写布尔 enabled 及 dispose()。选项按 engine/scope/input/textureLease/skins/enabled/onActivate 顺序各读一次。皮肤依次读取 up/pressed/disabled，再按 x/y/width/height 各读一次。成功执行用户可调用代码后复查生命周期。抛错 getter 保留原始原因，包括 undefined。enabled 只有一次读取，结果 undefined 时默认 true；其他结果必须为布尔值，null 无效。TypeScript 可选属性继续遵守仓库的精确可选属性规则。

## 输入与退役

状态为 up、pressed、disabled 和终态 disposed。真实原生主输入在公开 begin 路由前建立按下状态；释放或取消在对应路由前恢复 up。onActivate 在完整 activate 路由后执行，并要求同一手势、启用状态、生命周期、挂载关系、显示设置和同一点最终命中复查仍有效。合成 SDK 事件无法建立控件手势。禁用后再启用使手势失效；赋相同 enabled 值在检查后保留有效按下。原始 MouseInput 行为保持不变。

异步或抛错激活回调遵循既有事件和回调诊断，退役失败输入关联的控件。显式释放、Scope/input/Engine 关闭或原始 Bitmap 释放均进入终态。逻辑退役在清理回调前切断回调和关联；清理尝试全部自有资源并保留原因。控件不释放借用租约或共享输入。Engine 持有缓存的 Host 关闭链。

悬停、键盘、触摸、无障碍和完整 EUI 属于后续工作。所选五文件设计在未打包 ESM 中通过输入装配预先加载按钮模块；可选 API 位置不代表零加载、包体、手机、能耗或性能优势。参阅[核验](位图按钮核验.md)、[后续计划](位图按钮实施计划.md)及[示例](../../../examples/bitmap-button/README.zh-CN.md)。
