## 依赖与范围决定

工程身份、迁移差异、素材来源和目标能力提前参与核心接口，不要求可用 Web 核心之前先建完整编辑器、九个计划包或原生虚拟机。

核心接口具备后，完整产品沿资产到场景 3D、选定宿主／发布闭环、共享创作／Agent 工作台和完整迁移推进。权利盘点、旧基线和接口设计可与尚未完成的 M4 外部资格并行；新实现按完整结果选定，不由文档合并自动触发。

一体化平台包含 Coding／调试、主画布、UI／动画、3D 场景／特效、世界／角色工具及目标发布。指定模型 API、Skill、MCP、插件和可见／可设置的 Token 额度属于其 harness，不进入 Runtime 帧权威。

## 证据与发布决定

每项交付记录需求、源码／产物／版本、环境、预期行为、实际结果与剩余限制。代码、受控测试、真实浏览器／设备观察、性能及实际部署分属不同证据域。

普通功能合并需要既有完整保护门禁、独立评审、来源、中英文阅读版及适用真实浏览器证据，不要求重跑无关历史或里程碑验收。长时生命周期／性能和真实宿主声明在实际前置及产物具备时执行。

核心预览公开准确可用入口、示例、依赖及开放项目。分发物须在干净消费者中可用；源码归档或改变 private／版本字段不能证明包验收，公共示例网站另需实际部署验证。

完整 M4 保留 X-D60/1、X-MTouch/1 和 L 验收，必需但不可执行的记录继续开放。完整产品发布还须完成声明的 3D、创作／发布及迁移范围。重排计划不能把缺失 IME、iPhone、授权参考、性能或外部服务结果转换为通过。
