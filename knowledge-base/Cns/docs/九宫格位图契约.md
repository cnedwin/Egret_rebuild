# NineSliceBitmap 契约

[English](../../en/docs/nine-slice-bitmap-contract.md) | 简体中文

工程预览 **0.48.0** · **S102 / V053**。`NineSliceBitmap` 是只拉伸的显示叶节点，用于面板、按钮和对话框背景；调整目标尺寸时保留局部边框厚度。它复用独立实现的 [NS1 几何](九宫格几何NS1契约.md)、真实 Texture 租约与既有纹理渲染。[证据](九宫格位图证据.md)及[原生核验指南](九宫格位图原生核验指南.md)分别记录验收截止点。

## 公开 API

`@egret/runtime` 与 `@egret/engine` 根入口恰好新增一个运行时值 `NineSliceBitmap` 和一个擦除类型 `NineSliceBitmapOptions`；Engine 转发真实 Runtime 绑定，复用已有 `NineSliceInsets2D`。其他入口与包子路径不新增名称，核心仍不依赖 DOM／Node。

```ts
interface NineSliceBitmapOptions {
  readonly width: number;
  readonly height: number;
  readonly insets: NineSliceInsets2D;
}

class NineSliceBitmap extends DisplayObject {
  constructor(textureLease: AssetLease<Texture>, options: NineSliceBitmapOptions);
  get textureLease(): AssetLease<Texture> | undefined;
  get targetWidth(): number;
  get targetHeight(): number;
  get insets(): NineSliceInsets2D;
  resize(width: number, height: number): void;
  dispose(): void;
}
```

它是显示叶，不是 Bitmap／Mesh2D 子类或容器。声明中的私有名义标记服务于类型检查，模块自有身份记录授予实际接收者权限。不提供纹理／内容／sourceRect setter、几何端口、资源加载器、隐式调度或缓存。普通继承变换、alpha、visible、clipRect 及显式 hitArea 保持可用。目标尺寸是局部尺寸，scale 是另一层变换。

## 源视图与借用

输入必须为资源管理器签发的真实 `AssetLease<Texture>`；通过 Runtime 私有身份／值读取与 Texture 活快照确认，公开 getter 或结构仿造不授予权限。源尺寸来自 Texture 的不可变整数裁剪，包括非零 x／y。NS1 UV 相对裁剪，纹理命令保留原始绝对 sourceRect。叶节点不复制图像像素，不推断打包／旋转图集元数据。SpriteSheet 裁剪或返回的 Bitmap 不能替代 Texture 租约。

叶节点借用调用者拥有的精确租约，不取得第二份、不释放租约或 Texture、不隐式请求资源。先注册真实租约，再 `scope.use(leaf)`，获得逆序清理。实际 API 为 `Scope.use`，没有 `Scope.adopt`。跨 Engine 的 Scope／树挂接仍以 `ENGINE_MISMATCH` 拒绝。

## 准入与调整尺寸

构造在读取外部 options 前，依次检查租约身份 → 权限 → Texture 身份／活快照 → Engine 开放。仿造租约以 `NINE_SLICE_BITMAP_LEASE_INVALID` 拒绝，非 Texture 值以 `NINE_SLICE_BITMAP_TEXTURE_INVALID` 拒绝；既有 `ASSET_LEASE_RELEASED`、`TEXTURE_DISPOSED`、`ENGINE_CLOSED` 保持区分。

options／insets 必须为非 null、非数组对象，可使用继承属性及 getter。按 width、height、insets、left、top、right、bottom 精确顺序各读一次，不枚举未知键，不使用迭代器或强制转换。每次成功读取后，按 Engine、同一租约、活 Texture 顺序检查，再读下一项或准入语义。读取抛错时立即以 TypeError 保留精确原始 cause，包括 undefined；失败后的生命周期检查不会覆盖它。捕获的准入／错误／冻结操作在描述符回调期间维护功能契约，不授予进程或对抗性隔离。

全部原始数字类型检查先于范围检查。既有 NS1 工厂决定有限正值源／目标尺寸、有限非负边框、源边框和严格小于源尺寸、目标至少容纳边框和，以及精度拒绝。允许小数与有意的零目标中心，边框有符号零被规范化。不压缩边框，不 tiling，不强制转换，不默认边框。

`resize` 在数值语义前检查接收者、显示生命周期、Engine 与精确资源权限；即使尺寸相同也建立新的自有 NS1 几何，再无回调／事件／公开 setter 地一起提交几何与尺寸。任何提交前失败保留此前已提交尺寸／几何，回滚不复活独立退役的资源。已保存 Engine 帧保留早先自有几何／图像值。先分配再提交是源码义务，不是实际物理 OOM 实验。

## 身份、边界与退役

Mesh2D 类身份与共享捕获内容槽分离。借用 Mesh2D 操作到该叶时以 `MESH_INVALID` 拒绝；借用 NineSliceBitmap 成员到其他对象时以 `NINE_SLICE_BITMAP_INVALID` 拒绝。共享捕获注册不能让新叶取得可变 Mesh 内容端口。

自身边界为 `(0, 0, targetWidth, targetHeight)`，父边界使用普通变换。捕获按既有预算计入未修改 NS1 的十八个三角形。缓存几何不会因 visible、alpha、裁剪或资源权限改变而消失；实际 Engine／显示生命周期及遍历规则仍适用。调整尺寸不自动改变 hitArea。

元数据 getter 要求真实接收者，但不授予资源权限，也不要求 Engine 开放。释放后尺寸及同一冻结 insets 快照仍可读取。叶 live 时 `textureLease` 返回精确借用，即使租约独立退役；叶释放后返回 undefined。释放先清除内容与借用引用，再进入普通基类终态清理；重复操作无效果，Engine 关闭后也可执行。边界查询／resize 仍拒绝已释放对象。

## 渲染与使用

| 路径 | 行为 |
| --- | --- |
| `captureTexturedFrame`／记录型纹理宿主 | 既有自有纹理帧规格；CPU 组合不是原生像素证明。 |
| 显式 `createTexturedWebGPUHost` | 正向渲染路径，真实浏览器验收独立记录。 |
| Canvas 宿主的 `createEngineForProfile` | 渲染前以 `ENGINE_RENDER_PROFILE_UNSUPPORTED` 拒绝，不增加正向 Canvas mesh 路径。 |
| 向 Canvas 提交真实纹理帧 | 修改目标前以 `CANVAS_FRAME_PROFILE_UNSUPPORTED` 拒绝。 |
| 普通非纹理捕获／渲染 | 可见、有内容叶保持 `FRAME_MESH_UNSUPPORTED`，既有跳过分支不变。 |

选择真实纹理宿主／Engine，并取得已注册 Texture 租约后：

```ts
scope.use(lease);
const panel = new NineSliceBitmap(lease, {
  width: 16, height: 12,
  insets: { left: 2, top: 2, right: 2, bottom: 2 },
});
scope.use(panel);
engine.stage.addChild(panel);
const saved = engine.renderTexturedFrame({ width: 20, height: 20 });
panel.resize(12, 16);
engine.renderTexturedFrame({ width: 20, height: 20 });
// The saved frame retains its earlier owned geometry.
```

示例假设源视图为 8 × 8。关闭应用时按既有契约退役所有者 Scope／Engine 及宿主。可运行记录型示例为 `examples/nine-slice-bitmap-headless.mjs`，不测量浏览器像素。

## 来源与后续工作

叶节点、类身份修复、捕获的 Texture intrinsic、测试与原始夹具为独立编写的 **Apache-2.0** 白鹭工程，复用第一方 NS1、Texture、Mesh2D、AssetLease、Scope、捕获与边界契约。AI 协助源码／测试／文档准备，独立源码与保存结果评审仅验收已记录范围。本增量不新增依赖、shader、decoder、帧格式或 SDK 协议。package 保持私有 **0.0.0**，宿主协议 **1.0**。

背景叶不实现完整 EUI／布局、滚动／输入控件、tiling、旋转／trim 图集、旧 scale9Grid 迁移或 3D 材质。完整 Spine **R020/V020** 与迁移 **R008/V006 保持 OPEN**；移动／Native SDK、平台宿主、字体、物理 GPU／GC、电耗及比较性能仍是独立工作。
