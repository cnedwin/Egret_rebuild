## 已接受的真实浏览器不透明子集

成对浏览器核验器 (`tools/sequence-playback/README.zh-CN.md`)使用真实的公开 Engine／Canvas／WebGPU 入口和原创字面量图集。每个后端产生八个新捕获，并重播一次保存的原帧，共 18 次提交；每份 RGBA 缓冲为 8×4。独立评审逐通道比较字面量不透明矩形与全零外部区域：576 像素、2,304 通道，容差 0、差异 0。每个后端派发五次显式 tick，配置上限为 0.5 秒；捕获和重播不推进时间。

保存的执行使用 Node 24.19.0、Playwright/core 1.62.1，以及 Windows x64 release 10.0.26300 上默认的无界面 Microsoft Edge 155.0.4283.45（`msedge`），没有新增浏览器参数、环境或 profile 覆盖。WebGPU 报告 vendor `nvidia`、architecture `blackwell`；这些仅是适配器元数据，不证明硬件加速或物理 scanout。

暂停／恢复保留的采样身份一致；保存帧和采样仍冻结，原图像身份不变。关闭 playback Scope 后，调用方 Bitmap 与租约仍有效。每个后端的 provider 加载／销毁各一次，调用方退役自己的资源。重播使用不同 host 和不同 WebGPU device，不重新采样。四个 host 安全关闭；两个 device 在安全 host close 完成后销毁，destroyed-loss Promise 均完成。顺序依据已接受源码与保存的退役快照，不是每个设备独立的时间戳轨迹。

两个 fixture 与 context 均完成，browser／server 已关闭；待启动、native／GPU 工作、上传／读回字节、隔离、清理错误和 fixture 诊断／事件均为零。所选输入与编译器归属记录前后一致；封闭 Canvas／WebGPU 模块图只允许已选择路径。自有 Windows Job 在成员确认前完成 assignment，保留 worker handle，自然达到 active zero 后关闭；worker／collector／actor 退出码均为 0，原始输出到 EOF、无溢出、强制终止、兜底或后续工作。这只接受该自有执行的关闭，不测量物理内存峰值或通用进程扫描。

接受范围仅为这一不透明 once／loop／暂停／重播矩阵，不接受 alpha 校准、完整 A2、3D／UI／字体、手机、其他宿主、硬件性能、物理 scanout、物理 GPU 退役、许可授权或远程 CI。内部注入式运行时故障对照仍待完成。

## 公开示例

常规构建后，在仓库根目录运行 `node examples/sequence-playback-headless.mjs`。示例 (`examples/sequence-playback-headless.mjs`)记录五次观察：

| 观察标记 | 状态 | 播放秒数 | 采样帧索引 |
| --- | --- | ---: | ---: |
| started-red | running | 0 | 0 |
| green | running | 0.125 | 1 |
| paused-green | paused | 0.125 | 1 |
| resumed-blue | running | 0.375 | 2 |
| completed-blue | completed | 0.5 | 2 |

关闭后仍能读取最后的不可变采样。空游戏诊断来自已接受且未改动示例中的断言；它不是输出 JSON 的字段。加载与销毁观察是 provider 的逻辑生命周期数量。
