# 显示锚点偏移

[English](../../en/docs/display-anchor-offsets-contract.md) | 简体中文

工程预览 0.52.0 · S106 / V057。本契约限定两个继承标量属性；[证据记录](显示锚点偏移证据.md)分别说明各项验证截止点。

## 公开取值与生命周期

`DisplayObject.anchorOffsetX: number` 与 `anchorOffsetY: number` 为现有显示子类定义局部枢轴，包括 Sprite、Bitmap 和 Stage。两者初始均为 +0。元素可绕指定枢轴缩放或旋转，其位置继续用于在父坐标系中放置该枢轴。

每个属性接受全部有限原始 number，包括负值、内容范围之外的枢轴及 -0，并精确保留数值。NaN、无穷大和非 number 值以 `DISPLAY_VALUE_INVALID` 拒绝；不会通过 valueOf 或 toString 强制转换对象。

两个访问器均认证真实的私有显示节点身份。伪造接收者与代理以 `INVALID_DISPLAY_OBJECT` 拒绝，不检查对象形状。对象释放或 Engine 关闭后，getter 仍保留已有数值观察。setter 拒绝顺序为身份、`OBJECT_DISPOSED`、已绑定的 `ENGINE_CLOSED`，最后才是取值校验；拒绝写入保留原标量。两个轴独立写入，不新增组合事务、子类 hook 或生命周期事件。

## 变换与精确零值兼容

保留现有 binary64 系数：`a=cos*scaleX`、`b=sin*scaleX`、`c=-sin*scaleY`、`d=cos*scaleY`。非零枢轴的局部平移按从左到右的顺序求值：

```text
localTx = x - a * anchorOffsetX - c * anchorOffsetY
localTy = y - b * anchorOffsetX - d * anchorOffsetY
```

随后使用现有父乘局部表达式合成平移。局部枢轴映射到父坐标系中指定的 (x,y)，受普通 binary64 算术约束。

两个偏移均与零相等时，包括 -0，保留原平移表达式及求值顺序。额外的零乘项或算术重组都会改变本契约。默认零值兼容使用原始实际观察到的矩阵字节及符号，而不是理想化算术。

## 坐标、边界、裁剪与资源

- localToGlobal/globalToLocal 包含接收者及祖先的枢轴；原有预算、奇异变换拒绝、算术错误和冻结结果继续适用。
- getBounds 保持接收者局部内容测量含义：排除接收者自身枢轴／变换及所有祖先，纳入后代枢轴，并保留原有可见性／裁剪处理。枢轴不修改几何或 Texture 源矩形。
- clipRect 与显式 hitArea 仍使用创作时的局部坐标。捕获和 Stage.hitTest 使用同一枢轴矩阵及原有裁剪／触摸规则。枢轴不产生隐式命中区域、scrollRect、推导尺寸或布局锚定。
- 旧式／图像与纹理捕获共享变换。后续编辑枢轴不会改变已保存冻结帧中的原矩阵、几何及自有图像数据；渲染端口和帧规格保持不变。
- 锚点操作不增加 owner 转移、永久 Engine 亲和性变更、监听器修改、Bitmap 租约替换、Texture 释放、sourceRect 更新或 TextField 栅格所有权变更。原有 Scope／资源准入与清理继续有效。
- 有限枢轴仍可能使后续合成溢出。原有坐标、边界、命中和帧错误继续有效，包括 `COORDINATE_ARITHMETIC_RANGE`、`BOUNDS_ARITHMETIC_RANGE`、`HIT_TEST_ARITHMETIC_RANGE` 和 `FRAME_TRANSFORM_INVALID`。捕获失败不得公开帧或调用渲染端口；局部 getBounds 仍排除极端的自身枢轴。

## 可手工核对的示例

使用单位 Stage、父位置 (5,7)、子位置 (20,30)、缩放 (2,1)、旋转 0、枢轴 (4,3) 和子矩形 (0,0,8,6)。

| 观察 | 结果 |
| --- | --- |
| 子枢轴 (4,3) 的全局坐标 | (25,37) |
| 子局部原点的全局坐标 | (17,34) |
| 子 getBounds | (0,0,8,6) |
| 父 getBounds | (12,27,16,6) |
| 子矩阵 | a=2, b=0, c=0, d=1, tx=17, ty=34 |

局部裁剪 (0,0,4,6) 在同一变换边缘约束渲染和显式命中，不缩小逻辑边界。命中还需 touchEnabled=true、hitArea (0,0,8,6)，且没有其他可交互节点。非轴向旋转使用普通 binary64 三角函数；有限坐标夹具采用 1e-10 容差，零值兼容则比较精确原始字节。

## 范围

实现修改三个现有运行时文件，复用共享变换的五个消费者。不增加根值／类型、package 入口、运行时模块、依赖或渲染命令；package 维持私有 0.0.0，宿主协议为 1.0。

另行限定的桌面 Native 日程使用不透明矩形和保存帧重放，不建立新 Native SDK／后端、实体 GPU 身份、字体、移动平台覆盖、GC 或性能结果。完整 Spine R020/V020、迁移 R008/V006、完整 EUI／布局、高级 3D 和 AI 接口仍为 OPEN 或未验证。参见[剩余计划](显示锚点偏移工程计划.md)。
