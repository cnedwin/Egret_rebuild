[English](../../en/docs/prepared-resource-groups-evidence.md) | 简体中文

工程预览 0.58.0 连接多 Bitmap 绑定、资源组合准备与双层换装场景。[规格](prepared-resource-groups-spec.md)定义接口契约。本记录分别说明已实现行为、已记录桌面结果和后续产品工作。

## 接口与源码评审

`Engine.captureBitmapBindings(scope, targets)` 返回冻结的 `BitmapBindingTicket`，提供 `prepare`、`commit` 和 `dispose`。根入口增加一个擦除类型，39 个运行时值导出保持不变。核心继续不访问 DOM/Node，不增加包依赖，也不改变 Host 协议。

独立评审覆盖目标权限、发布前完整预检、绑定代次、整体提交、租约借用、重入和关闭。示例另行评审协调器、原始 PNG 读取器、依赖与字体所有者、场景会话及浏览器应用。既有第一方资源字节和第三方许可证、来源记录保持不变。

## 真实桌面场景

记录环境为 Windows 10.0.26300 x64、Microsoft Edge 155.0.4283.45、Playwright 1.62.1，语言 zh-CN、密度 1，不增加启动参数。每次运行使用新的 BrowserContext，画布逻辑尺寸为 192×128。

| 渲染模式 | 场景 | 原始读回数 | 结果 |
| --- | --- | ---: | --- |
| Canvas 2D | 正常生命周期 | 17 | 有限流程通过 |
| Canvas 2D | 旧 A 外层 | 5 | 检出指定错误图层 |
| Canvas 2D | 旧 B 饰边 | 5 | 检出指定错误图层 |
| 纹理 WebGPU 场景 | 正常生命周期 | 17 | 有限流程通过 |
| 纹理 WebGPU 场景 | 旧 A 外层 | 5 | 检出指定错误图层 |
| 纹理 WebGPU 场景 | 旧 B 饰边 | 5 | 检出指定错误图层 |

首次六个上下文保留 54 份完整原始 RGBA，共 5,308,416 字节。每个上下文先用公共 SDK 直接渲染并关闭前置场景，再创建应用。正常流程覆盖启动、真实原生鼠标选择右侧角色、0.125 秒前一刻及边界动画、夏日／混搭发布、Error 与 `undefined` 读取失败、保持原始读取的取消、独立的热租约取消、重复换装、移除左侧角色，以及右侧读取仍被保留时关闭。

仓库内的公开验证工具随后又在六个新的上下文中实际运行，另行保留 54 份原始读回。这是对相同有限流程的独立复现，不会扩大像素比较范围。

独立比较器每帧检查 49 个预先定义的点和 1024 像素的固定中文区域，保存点比较共 2,646 次。四个错误图层上下文先验证正常夏日服装，再通过独立持有的真实租约手动修改指定图层。仅该图层的九个点不同，其余点及文字比较全部通过；这些上下文不能计为正常应用验收。保留完整画面不会扩大有限比较范围。

使用前认证两份原始直接 Canvas 中文参考图。它们仅覆盖记录环境下的字体子集与左右选择标签。不透明颜色和输出 alpha 要求精确相等；仅参考图中半透明像素允许一个 RGB 字节的预乘舍入差异。54 次文字区域比较均未观察到通道差异。保留 Canvas 的精确频繁读回提示，没有未预期的控制台或页面错误。

## 所有权与资源账目

请求失败或取消时，先前服装的两个图层保持有效。Error 与 `undefined` 保留原始拒绝原因。读取保持取消和待定关闭分别保留两个真实读取及外部读取器中的 164 字节，直到原始门控操作结束。独立热资源测试先持有两个真实公共租约，再在替换组就绪回调执行前取消。

协调器预留、适配器编码／原始／解码内容、外部读取器持有字节、字体载荷、帧图像、几何及 Host 待定操作分别记录。应用保留首个和最近一个原始 RGBA 结果：同一结果为 98,304 字节，两个不同结果为 196,608 字节。验证器保存文件另计。这些账目描述逻辑载荷和已记录操作，不代表物理分配或驻留测量。

十二组前置场景／应用所有者均达到记录的退役条件。两个协调器、资源源与依赖工作、字体、热租约和待定呈现全部结束，画布置零并移除。WebGPU 报告安全清理，没有待定帧、上传、读回或场景工作。待定工作为零，不代表物理内存为零或垃圾回收立即完成。

原生字体生命周期测试还复现了由 FontFaceSet 观察触发关闭的情况。安装前增加状态检查后，不再发生后续字体添加。同一组八项原生检查在修复后通过，指定关闭用例的迟到添加次数由一次变为零。该结论仅适用于有限字体所有者范围。

## 复现与后续工作

构建仓库后，使用公开配置准备工具：

```text
node tools/prepared-resource-groups/prepare-native-config.mjs --playwright <absolute-playwright-1.62.1-directory> --workdir <existing-external-directory> --profile canvas-2d --kind ordinary
```

工具写入新的配置并打印快照与实际运行命令。先捕获并核对完整输入快照，再实际运行。分别覆盖两种模式（`canvas-2d`、`webgpu-scene-textured`）及三个场景（`ordinary`、`manual-old-A-outer`、`manual-old-B-trim`）。源码身份、完整原始工具包清单、真实可信鼠标操作、完整原始读回和所有者退役均保留在验证器中。原有记录的环境保持不变。独立的直接 Canvas 复测在 Edge 155.0.4283.62 上得到了完全一致的两份完整中文参考缓冲及每个字符串的十二项度量。当前 oracle 仅准入 Edge 155.0.4283.45 和 155.0.4283.62，其他参考环境字段保持不变；未覆盖版本、其他环境及参考字节被修改时仍拒绝比较。必须使用新配置和经评审的快照绑定当前 oracle 身份。补丁版本的参考等价与新的原生应用验收分开记录。

仓库完整检查、强制钩子、GitHub PR／Main 交付与远端 CI 属于独立证据阶段。本记录不代表 CI 通过或完整 P03 验收。通用依赖清单及更多 3D／Spine／音频消费者、完整 UI、生产宿主、通用排版、手机能耗／性能、GPU 物理峰值和完整旧工程迁移仍保持开放。
