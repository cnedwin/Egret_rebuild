# Scope 所有的标量 Tween

[English](../../en/docs/scalar-tween-contract.md) | 简体中文 · [游戏时间](游戏时间核心契约.md)

工程预览 **0.26.0**：显式游戏秒驱动的一次性标量补间。包为 private、**0.0.0**；验证/交付另记。

## 公共接口与显式使用

使用构建后 `@egret/engine` 根入口：`engine.createTween(scope, options): Tween`。新增 `Tween`、`TweenState`、`TweenOptions`、`TweenEasing` 均**仅类型**导出；不透明冻结句柄无运行时构造器/静态 `get`、新工厂或子路径。

选项均 readonly：`from`、`to`、`durationSeconds`，必需 `onUpdate: (value: number) => undefined`，可选 `easing`、`onComplete: () => undefined`。缓动为 `linear`（默认）、`quadIn`、`quadOut`、`quadInOut`。只读观察量为 `state`、`isDisposed`、`elapsedSeconds`、[0,1] 内原始 `progress`、`value`；控制为 `start/pause/resume/stop/dispose(): void`。

应用提供 HostAdapter，先取得借用资源再创建 Tween，让 Scope 逆序清理先停止写回：

```ts
import { createEngine, Sprite } from '@egret/engine';
import type { HostAdapter } from '@egret/engine';

async function movePanel(host: HostAdapter): Promise<void> {
  const engine = await createEngine({ host });
  try {
    const scope = engine.createScope();
    const sprite = scope.use(new Sprite());
    sprite.graphics.beginFill(0x2753a1).drawRect(0, 0, 2, 2);
    engine.stage.addChild(sprite);
    const tween = engine.createTween(scope, {
      from: sprite.x, to: 100, durationSeconds: 1,
      onUpdate(value) { sprite.x = value; return undefined; },
    });
    tween.start(); // no write
    engine.advanceTime(0); // baseline; no write
    for (const t of [0.25, 0.5, 0.75, 1]) engine.advanceTime(t);
    // offers 25, 50, 75, 100; then completed
    engine.captureFrame({ width: 128, height: 8 });
  } finally {
    await engine.dispose();
  }
}
```

`from: sprite.x` 在 API 前求值，Engine 不发现/重读属性；回调是标量适配器。捕获/渲染不推进时间，推进不渲染。构建后重跑：`node --test tests/tween.test.mjs`。

## 准入与状态

依次检查开放 Engine、真实同 Engine Scope、内建开放状态；公共 Scope/clock 覆盖不改变权威。选项须非 null、非数组对象；按 `from`、`to`、`durationSeconds`、`easing`、`onUpdate`、`onComplete` 各读一次，成功后重查上述生命周期。形状/读取抛错以 `TWEEN_OPTIONS_INVALID` 保留精确 cause，包括撤销 Proxy；成功读取关闭生命周期先报该拒绝。不发布失败句柄/订阅。

端点有限，-0 变 +0，binary64 `to-from` 有限；时长有限为正，无天数上限；回调可调用。无效值为 `TWEEN_OPTIONS_INVALID`，非有限差值为 `TWEEN_RANGE_INVALID`。忽略额外键，不留选项，仅留标量/回调。Scope 拥有冻结 idle 句柄，不写回/订阅；elapsed/progress 初始 0，value 为 `from`。同 Scope use 去重，接管为 `OWNERSHIP_CONFLICT`。

start 先取得真实订阅，再提交 running/锚点；拒绝留 idle，可重试。idle pause/resume 为 `TWEEN_NOT_STARTED`；running/paused start 为 `TWEEN_ALREADY_STARTED`。pause 冻结上次样本；resume 携带已提供 elapsed，以当前游戏 elapsed 重设锚点；重复暂停/恢复无作用。

状态为 `idle`、`running`、`paused`、`completed`、`stopped`、`failed`。后三者终结（`isDisposed=true`），start/pause/resume 为 `TWEEN_TERMINAL`。stop/dispose 同步幂等：未终结者变 stopped，已有终态保留；不复位/最终写回/完成。

getter/方法检查接收者，否则 `TWEEN_INVALID`。start/pause/resume 依次检查 Engine、自身回调重入、状态；closing/closed 优先 `ENGINE_CLOSED`。关闭后观察量与 stop/dispose 可用。

## 时间与插值

running/paused 各占 **256 个混合存活注册**中一槽；idle 无槽，无独立 Tween 上限或调用方/Scope 历史界限。start、锚点同 elapsed 回调、paused tick 均不写回。

固定携带基数加整段 `tick.elapsedSeconds-anchor`；delta 须有限，先比剩余时长再加法，终点精确选 duration；非终点 elapsed 有限且严格增长，否则 `TWEEN_TIME_RANGE`。每个到达 running tick 最多一次。轮到前暂停保留样本，恢复丢弃未观察区间；前序失败跳过后，下一次按当前 elapsed 采样、不重放。全局暂停、源单调性、delta 上限、长间隔恢复遵守[时钟契约](游戏时间核心契约.md)。

原始 `p = elapsed/duration` 的四种缓动依次为 `p`、`p*p`、`p*(2-p)`、`p<0.5 ? 2*p*p : 1-2*(1-p)*(1-p)`。中间值为 `from + (to-from)*easedP`，提交前须有限，否则 `TWEEN_RANGE_INVALID`；终点精确提供 `to`。相同端点仍有正时长更新与完成。无 epsilon、自定义缓动、颜色/向量插值、角度绕回。

elapsed/progress/value 在调用写回**之前**提交。value 是最后提供值，不证明 setter 成功；失败保留观察量及应用副作用，相同已接受源不会重放。

## 回调与生命周期

回调同步且只返回 **undefined**。抛错以 `TWEEN_UPDATE_FAILED`/`TWEEN_COMPLETE_FAILED` 保留精确 cause；其他返回值在同一错误中嵌套 `TWEEN_CALLBACK_RETURN_INVALID`。Promise/thenable 拒绝被观察，不等待/接受/取消；观察或诊断观察者失败不替换 cause。时钟包裹 `CLOCK_CALLBACK_FAILED`，报告一次 engine/error 诊断并停止后续候选，无重复 Tween 诊断。

写回或完成中调用自身 start/pause/resume，在 Engine 检查后报 `TWEEN_REENTRANT`；stop/dispose 允许。可创建/启动另一个 Tween，新订阅留待后续时钟快照。同 Engine 嵌套时间/帧操作保留 `CLOCK_REENTRANT`。

最终写回成功后，仍 running 且 Engine/Scope 开放才提交 completed；退役释放存储的回调与订阅，再调用当前局部完成回调一次。完成失败保留 completed/最终观察量。写回或算术失败退役为 failed，但先前 stop/close 的终态优先，终态不复活。最终写回中 stop/关闭 Scope 或 Engine 会抑制完成；Scope closing 中到达 tick 也先停止、不写回。

清理释放借用，不拥有目标。同步 Scope.dispose 可能在写回返回前释放资源，关闭自身 Scope 后不得继续使用。Engine.dispose 共享同一 Promise，立即停止 idle/running/paused Tween，经现有时钟/帧屏障后按 Scope → Stage → assets → host 清理。禁止的 Promise 不增加屏障。存储借用清空，当前调用/历史可仍存在，无 GC/堆保证。

伪造/外来 Scope 为 `TWEEN_SCOPE_INVALID`，真实 closing/closed Scope 为 `SCOPE_CLOSED`；已有所有权与时钟注册错误（包括 `CLOCK_CALLBACK_LIMIT`）保留原规则。
