## 显式模式与输入

既有 PNG 核验器提供第一方采集器、有限模块图、原始输入／读回记录及浏览器清理机制。NineSliceBitmap 使用显式选择模式：

```text
node tools/verify-browser-png.mjs --nine-slice-bitmap --admission <absolute-reviewed-admission-json> --output <fresh-absolute-directory-outside-repository>
```

命令不安装软件，不改变依赖 owner 或渲染器；NineSlice 准入不能进入默认 PNG 路径。省略本模式时保留此前资格检查的 PNG 路径；本夹具不解码 PNG／字体、不导入 Spine SDK。

准入状态为 `NINE_SLICE_BITMAP_NATIVE_SOURCE_AND_ACTUAL_INPUTS_ADMITTED`，图规格为 `nine-slice-bitmap`。编码夹具列表明确为空，`schedulePin` 绑定原始安排字节。必需独立评审角色为源码 `plan`、`productSource`、`collectorSource`，以及实际 `missingEntryRed`、`cpu`、`build`、`strictTypes`、`policy`。原始 PASS 资格且零发现评审、完整 owner／路径／原始 pin 及其源码／编译输出／证据关系必须一致；当前哈希不能替代原始评审绑定。

产品绑定包括全部六个修改源文件，含 Texture 捕获的 intrinsic，以及对应十二个 JS／DTS。采集器／oracle 绑定覆盖夹具及四个宿主端文件，原始安排另行绑定。图／reader／依赖／运行时 pin 保留完整身份。新模式只准入显式夹具与三个已构建公开根入口 `@egret/engine`、`@egret/engine/webgpu`、`@egret/engine/web`，不增加通用别名、私有产品导入或通配解析器。针对本隔离准备接受的物理自有 robust-predicates owner，不改变默认 PNG 的 owner 要求。

已安装 Node **24.19.0**、Playwright/core **1.62.1** 与真实 Edge 可执行文件通过原始输入记录检查。浏览器启动保持默认 headless `msedge`、DPR **1**，不增加调用者 flags 或替换可执行文件。依赖发现与源码批准不代表已启动浏览器或 GPU 身份。

## 冻结组合与 oracle

公开夹具为 `tools/nine-slice-bitmap-native/fixture.mjs`，独立字面期待位于 `oracle.mjs`，精确安排在 `schedule.json`。它创建原始 **12 × 12** ImageData2D 像素与真实 Texture 裁剪 **(2,2,8,8)**，经 Engine 资源管理器取得；真实 Scope 先注册租约再注册叶，不以结构 Texture 替代，也不借几何工厂生成期待像素。

叶位于透明 **24 × 24** 目标的 **(2,2)**，边框固定为两单位。冻结安排为：

| 步骤 | 必需观察 |
| --- | --- |
| N1 | 以 16 × 12 构造，捕获并提交真实自有纹理帧。 |
| N2 | resize 为 12 × 16，保留原帧，捕获并提交新几何。 |
| N3 | 退役来源 Engine／Scope／租约／Texture／宿主／device，在新真实纹理 WebGPU 宿主、Engine 与 device 上重放精确 N1 帧。 |

安排要求 **三次提交**、**两次捕获**、**一次重放**；每份原始 RGBA 读回为 **576 像素／2304 通道**，总计 **6912 通道**，容差 **零**。N1／重放 buffer 还须完全一致。Node oracle 的原始调色板／矩形行独立于产品捕获几何，断言前保存原始字节。已接受执行以一个主例完成这一安排，独立匹配三份完整缓冲，包括 N1／N3 相同的 2304 字节重放。

## 拒绝与退役

两项独立 Canvas 负例分别要求 Engine 规格创建时 `ENGINE_RENDER_PROFILE_UNSUPPORTED`，及向已启动 Canvas 宿主直接提交真实纹理帧时 `CANVAS_FRAME_PROFILE_UNSUPPORTED`；后者比较原生目标字节不变。正向 Canvas 提交为 **零**，不增加 Canvas mesh 渲染器或隐式模式升级。

启动、提交及读回保留原始异步票据。安全返回前，夹具核对帧／上传／读回／几何工作待处理为零，关闭借用宿主，再销毁每个应用自有 device 并观察其 loss。超时或未结算原件保留所有权／隔离及不完整清理。采集器另行拥有 loopback、context／browser 关闭、输出记录及运行前后源／运行时身份检查。源码义务与成功普通清理本身不验收强制取消或失败清理路径。

已接受普通运行结算十四个外层／十五个内层 ticket，销毁两个应用自有 device，context／浏览器／服务器关闭，待处理 ticket 及主错误／清理错误为零；源／运行环境／图记录稳定，默认 headless Edge 155.0.4283.45 未增加启动 flags。adapter 身份为 **UNOBSERVED**；强制超时／失败清理路径未执行，也未执行错误 oracle 反事实对照。在该 Native 验收截止点，公开材料门禁及 GitHub 交付是独立的待完成阶段。

## 范围与来源

第一方夹具复用白鹭独立编写的 NS1、Texture、AssetLease、Scope、自有帧与纹理 WebGPU 契约，通过具名模式扩展已有第一方 PNG 工具，不引入 decoder／shader 或运行时依赖。代码、原始像素及字面期待适用 Apache-2.0；AI 准备与独立源码／结果审阅各保留范围。
