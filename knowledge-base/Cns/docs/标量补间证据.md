## 实际覆盖的能力

真实 Engine 创建 Scope 所有的标量 Tween：有限起终点、正数时长、内建缓动和同步写回。构造／启动不采样，后续 tick 提供到达的数值。[游戏时间核心契约](游戏时间核心契约.md)定义显式时间，没有计时器、隐式渲染或异步回调任务。

真实 Engine、Scope 与借用显示资源支持独立缓动数值、暂停／恢复锚点、跳过时间段、选项读取顺序、原样原因、接收者／所有权守卫、共享时钟容量、监听顺序、终结状态、返回拒绝及关闭清理。适配 alpha 是应用代码，不代表通用属性动画接口。不可到达的数值边缘保留为源码审查；逻辑退役不证明 GC、物理内存或性能。
