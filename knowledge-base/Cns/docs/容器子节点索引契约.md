# 直接子节点索引契约

[English](../../en/docs/container-child-index-contract.md) | 简体中文

**0.50.0 · S104 / V055。** DisplayObjectContainer.getChildIndex(child: DisplayObject): number 只读查询精确当前直接子节点，以 O(n) 扫描私有真实顺序，不建立列表快照／缓存，不修改树、转移 owner、操作资源或调用显示回调。Sprite／Stage 继承，根值／类型、子入口、依赖及协议不变。

~~~ts
const index = layer.getChildIndex(child); // Current zero-based direct-child index.
layer.setChildIndex(otherChild, index); // Separate existing mutation.
~~~

返回添加／移除／换父／重排后的当前零起始直接位置，不搜索后代、不返回 -1 或缓存旧位置。普通 DisplayObject 不获得成员，根入口不导出独立 getChildIndex 函数。

拒绝顺序为真实容器身份 → 既有 Engine 开启检查 → 接收者生命周期 → 真实子节点身份 → 子节点生命周期 → 私有直接父成员关系 → 私有身份扫描；对应 INVALID_DISPLAY_CONTAINER、ENGINE_CLOSED、OBJECT_DISPOSED、INVALID_DISPLAY_OBJECT、OBJECT_DISPOSED、NOT_A_CHILD、DISPLAY_TREE_INVARIANT。即使子参数非法，Engine 关闭也先于接收者销毁；缺参／null／基础值／结构仿制／proxy 无权限，真实子类可用。未挂接、孙节点、自身、Stage 根或其他容器／Engine 中对象在寿命检查后为 NOT_A_CHILD；不读取外部 Engine，也不执行挂接准入。

私有列表／parent 与严格对象身份提供权限，不调用公共 parent／numChildren／getChildAt／assertUsable／移除／重排／dispose 覆盖。不新增快照或第二索引；O(n) 是实现描述，不是实测吞吐、OOM／GC 或比较性能。私有父／列表不一致拒绝只经源码核验，没有执行破坏私有状态的故障；既有内部生命周期副作用维持原边界，不承诺任意 JavaScript 隔离。

成功／拒绝均保持树顺序／parent／后代、对象身份、监听、Scope owner、永久亲和、Texture 租约及自有帧；不新增事件／timer／帧／资源请求、不分离／销毁／释放／转移 owner。setChildIndex 仍是独立变更，不新增查询与重排的原子事务。
