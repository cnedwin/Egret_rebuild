## 设备与口径

- Windows 前台 Edge 158.0.4370.33、NVIDIA GeForce RTX 5090 Laptop，WebGL2 使用 ANGLE D3D11，WebGPU 使用非回退 Blackwell 适配器。
- Android 为 Galaxy Z Fold7（SM-F966U1）、Android 17、Chrome 157.0.8103.78、ANGLE Adreno 830 及 Qualcomm Adreno 8xx WebGPU。首轮屏幕及标签会话的真实横屏视口为 873 × 325 CSS 像素；补充会话的真实竖屏视口为 411 × 813，两者 DPR 均为 2.625。通过 USB 本地专属页面注入浏览器触摸事件。未使用真人手指或浏览器视口模拟；测试未更改系统方向，也未观测两会话间姿态变化的过程。测试后恢复原前台、页面、USB 亮屏设置并归还设备租约。
- 桌面适配用例调整浏览器视口。手机上的竖屏、平板尺寸及指定刘海 insets 使用真机 GPU 浏览器内的脚本容器尺寸与输入值，尚未覆盖实体折叠状态变化或真实刘海识别。
- `verify --screens` 仍是独立的无头软件渲染、多配置模拟检查。Node 测试也单独记录。

## 保留的失败与工具验证边界

Windows 未修改的 `examples/play/verify-views.mjs` 在最终 outline 正则处失败。独立复现得到实际的 `Buy 60 [focused]`，旧断言预期按钮名后立即接下一段文本，未包含当前正确的焦点标记。另行验证 Sound、Buy、Sell 的角色、名称、稳定标识、边界、启用状态、activate/focus 动作以及第二次购买后的 480 金币状态。原失败保留在记录中，本报告没有修改引擎或测试。#516 第一次尝试时另一测试进程合法持有手机租约，未执行手机操作；租约释放后双后端复验通过。

初次设备调试发现超时、示例服务器路由拒绝及无头浏览器执行文件版本不匹配也保留为采集异常。后续分别使用 Chrome 正常前台、局部服务明确允许对应示例文件和选用既有无头软件浏览器，未修改引擎代码。

#462、#484、#485、#487、#489–#492、#494、#495 属于指南、工具、静态检查、存档结构及 Agent 工作流，沿用各自测试，不把指南中的软件帧时提升为硬件性能。#447、#475 及 #474/#478 的微信专属部分仍需实际微信宿主、开发者工具、输入法及平台验收。

## 复跑与剩余验收

使用本次固定提交、Node 26.7.0 及仓库正常安装/构建流程。复用 `examples/play/verify-screen-fit.mjs`、`examples/play-taps/verify.mjs`、`examples/play/verify-gestures.mjs`、`examples/play/verify-views.mjs`、`examples/play/verify-view-parts.mjs`、`examples/label-budget/verify.mjs`、`examples/paragraph-canvas/verify.mjs`、`examples/screen-check/verify.mjs` 的实际场景与断言。原辅助脚本强制软件渲染时，硬件复验使用前台真实浏览器、明确所用后端并保留失败。手机使用专属本地页面和真实视口，输入前测量目标坐标。机器可读记录附本次窄屏尺寸、输入结果、适配器信息及 PNG/像素读回摘要。

真实微信、Safari、Firefox、iPhone、实体手柄、读屏、真人触控、折叠/旋转及真实刘海均有独立待验收项。完整模型烘焙/预览 CLI、真实旧工程各 fixed 模式迁移沿用各自验收。本轮短时正确性测试没有测量 GPU 执行时间、功耗或持续帧时预算。#55 与 #92 继续按原验收口径记录。
