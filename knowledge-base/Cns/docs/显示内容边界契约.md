# 显示内容边界——有界契约提案

状态：有界公共实现已记录 CPU／类型及受影响桌面观察，并完成范围内独立源码与保存渲染审阅；双语公开材料审阅、最终 prepush 及堆叠远端交付分别保持待完成。

## 公开接口与用途

```ts
export interface BoundsQueryOptions {
  readonly maxNodes?: number;
  readonly maxPrimitives?: number;
}
// DisplayObjectContainer、Sprite、Bitmap、Stage 继承此方法。
DisplayObject.getBounds(options?: BoundsQueryOptions): Rectangle2D;
```

引擎门面以类型形式导出选项，并复用已有只读 Rectangle2D。每次成功返回独立、冻结的记录，恰含 x、y、width、height 四个有限数值字段，并把负零规范为正零。结果不保留节点、选项、图元、租约或图像。没有可变输出矩形或目标坐标空间参数。旧式输出矩形适配器仍待处理。带未知字段的新鲜对象字面量会触发 TypeScript 多余属性检查；包含一个已识别选项字段的结构化变量可以带额外字段。运行时忽略未知字段且不读取它们，不修改选项。省略选项或字段，以及未类型化调用中的 undefined 字段值，采用默认值；精确可选属性类型不允许在有类型的选项字面量中显式设置 undefined 字段。

本增量为后续布局提供内容测量，不提供布局尺寸更新、失效机制、命中测试、输入资格、考虑裁剪的可见边界或像素边界。不新增几何类、任意几何扩展钩子、依赖或平台支持。现有命名文档中“变换后边界”的表述需补充本增量限定：后代变换计入接收者局部边界；其他坐标空间另立后续契约。

## 坐标空间与纳入内容

接收者定义局部坐标。排除其自身及全部祖先的变换；Stage 作为接收者时也排除 Stage 自身变换。每个后代沿层级采用帧捕获与坐标查询已有的父矩阵 × 局部矩阵组合顺序。脱离 Stage 的树有效；仅改变接收者的父节点不会改变该局部测量。不使用逆矩阵，因此接收者变换奇异也有效；后代奇异变换可将正面积内容压成点或线。

内容包括权威状态中的矩形 Graphics 图元，以及非空 Bitmap 槽位缓存的裁剪尺寸，后者以局部 (0,0) 为原点。裁剪源的 x/y 不平移显示几何。可见性、透明度（含填充透明度）、颜色、裁剪矩形、实时图像使用权、宿主像素/DPR 及可绘制状态都不筛选内容。绑定引擎仍开放时，租约退休或 Texture 被释放不会抹去缓存尺寸；清空 Bitmap 租约则移除缓存几何。查询不读取图像/租约使用权，也不授予像素访问权。

每个已接纳图元均消耗一个图元预算单位，包括宽或高为零的矩形；非空 Bitmap 消耗一个，清空槽位不消耗。作者提交的矩形只要任一尺寸为零就不贡献内容，并跳过端点及角点算术。正面积矩形即使随后因舍入或后代变换退化仍贡献内容。私有 hasContent 标志区分“没有贡献项”和“退化贡献项”，不增加公开字段。无贡献项返回 {x:0,y:0,width:0,height:0}；位于 (7,9) 的点返回 {x:7,y:9,width:0,height:0}。零尺寸或全零记录都不能证明逻辑内容为空。

## 数值边界

后代变换必须完整保留现有组合表达式及求值顺序：角度单位为度，先计算 (rotation % 360) × PI / 180，局部系数使用 sin/cos 与带符号缩放，然后父矩阵乘局部矩阵。不吸附直角，不补偿抵消，不复用逆矩阵内核，也不设奇异阈值。每个访问到的后代，其完成后的六个矩阵系数必须有限，即使它没有内容。被排除的接收者及祖先变换不参与求值。

对每个正面积图元，先算 right = x + width、bottom = y + height，二者须有限。四个角点分别按 X = a*x + c*y + tx、Y = b*x + d*y + ty 的顺序求值，结果均须有限。合并这些已求值角点；不能先聚合子节点包围盒再变换。合并后算 width = maxX - minX、height = maxY - minY，检查有限，并规范返回四字段的负零。矩阵、端点、角点或最终尺寸任一非有限即抛 BOUNDS_ARITHMETIC_RANGE，不静默丢弃出错内容。普通有限 binary64 舍入和下溢（包括几何退化）被接受。

这是对已求值 binary64 几何的测量，尺寸相减也采用普通 binary64 运算，不承诺向外舍入的保守包围。返回的 x + width 不一定还原 maxX。例如矩形 (1,0,1,1) 与 (2^53,0,2,1) 的已求值极值为 1 和 2^53+2；精确差 2^53+1 按最近偶数舍入为宽 2^53。后续命中测试或粗筛契约若没有自己的数值契约，不能把此记录作为唯一排除依据。本接口也不承诺正逆变换往返、精确实数几何或性能。

## 接纳、生命周期与失败

在读取任何公开 getter 或调用方选项之前，先用私有身份验证真实接收者；伪造对象及真实节点的代理均抛 BOUNDS_RECEIVER_INVALID。选项之前先检查接收者生命周期，再检查绑定引擎开放状态；二者同时失效时 OBJECT_DISPOSED 先于引擎关闭错误。存活且未绑定的节点有效；已脱离树但仍绑定的节点受原引擎生命周期限制。

选项必须为 undefined 或非 null、非数组对象；函数和原始值无效。仅对一次 Array.isArray 调用设置窄范围来源异常捕获；已撤销代理抛出的异常作为 BOUNDS_INPUT_INVALID 的原样 cause。数组语义拒绝在该捕获之外。按 maxNodes、maxPrimitives 顺序，各通过普通属性查找读取一次，包括继承 getter。两次读取均成功后，才重新检查接收者生命周期/引擎开放状态，再验证数值。第一次抛出则不读第二次；第二次来源异常优先于第一字段语义无效。任何读取抛出值，包括 undefined 或 EgretError，即使读取期间释放节点/关闭引擎，也作为 BOUNDS_INPUT_INVALID 的原样 cause 保留。读取全部成功但导致释放/关闭时，生命周期错误优先于字段语义。来源捕获不能包装语义或生命周期错误。不枚举、不探测原型、不保留选项。

先验证 maxNodes，再验证 maxPrimitives：分别为 [1,65536]、[1,262144] 范围内的有限整数数值。默认值为 4096 节点和 65536 图元。无效值抛 BOUNDS_INPUT_INVALID。这是明确的接纳限制，不是时间、字节、任意 getter 工作量或多次调用总量保证。

捕获选项后，观察 getter 已完成的修改、换父及重入所留下的权威状态。每次调用独立持有累积量和遍历状态，不调用遍历回调、子类钩子或公开 getter。先访问接收者；每节点先按插入顺序处理 Graphics，再处理非空 Bitmap 槽位，随后按当前权威子节点索引顺序深度优先。空、隐藏、被裁剪节点均计数。获取下一个子节点之前检查节点预算；读取下一个内容项几何之前检查图元预算。按此顺序首次遇到的 BOUNDS_TREE_LIMIT 或 BOUNDS_CONTENT_LIMIT 获胜。进入节点时检查私有身份/树一致性及生命周期/引擎开放状态；后代矩阵检查先于其内容。重复身份、应有子项缺失或父指针不匹配抛 DISPLAY_TREE_INVARIANT。发布前重新检查已访问节点的生命周期；失败不返回部分结果。有效公开树操作无法构造一致性损坏。

查询不修改树、绑定、资源、帧编号、绘制计数或宿主状态。身份/状态读取绕过可覆盖的 x/y/scale/rotation、parent/children/numChildren、isDisposed、Bitmap 尺寸/租约/裁剪 getter 以及 assertUsable 钩子。用户选项 getter 可以自行执行用户代码；查询不会撤销其副作用。

## 字面量验证计划，不是结果

公开门面测试将隔离真实 API 缺失 RED，并检查 Bitmap 门面模块能正常加载。字面量组覆盖接收者/Stage 变换排除、精确平移和反射、带明确浮点容差的嵌套旋转/切变、直接角点与聚合 AABB 的区别、不以原点初始化、零面积/退化内容、隐藏/透明/裁剪内容、Bitmap 缓存/退休/清空状态、冻结/独立返回、负零、溢出/下溢、2^53 尺寸样例、顺序 getter 异常及修改/重入、生命周期、恶意公开 getter，以及包含接收者的宽树/深树预算。不私下导入运行时，不使用产品辅助函数充当预期值计算器。

公开类型样例同时检查完整函数类型相等、可选参数元组、只读返回值/选项、继承方法，以及结构化选项与新鲜字面量的区别；负例覆盖无效预算、显式 undefined 字段、修改返回值/选项、旧式输出参数和额外参数。现有 Bitmap/帧/纹理/树/坐标回归、严格核心类型/边界门禁及全量无头验证通过后，再执行受影响的真实 Canvas、矩形 WebGPU、B1 桌面验收并绑定源码/构建身份。这些门禁不证明手机、跨浏览器、性能、GPU 边界计算或完整 UI 支持。验收之前需要独立源码、数值边界及双语审查。
