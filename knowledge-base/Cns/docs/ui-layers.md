# UI 弹出层与模态层

[English](../../en/docs/ui-layers.md) | 简体中文

M3.4 通过 @egret/engine/ui 提供可选的根级层合成。实现复用 Engine 的显示所有权、Scope、指针路由、键盘焦点、段落与字体资源及现有原生编辑器，不增加调度器、渲染器、资源管理器或宿主输入监听路径。

## 公开契约

createUiLayerManager({engine, scope, input, keyboard?, viewport, maxLayers?, editorPolicy?, onInvalidate?}) 借用真实 Engine、Scope 和输入通道。viewport 是显式、尺寸为正的 Stage 坐标矩形。每个 Engine 最多一个层管理器，每个根最多一个层所有者；默认注册上限16，硬上限32。原生编辑器与根交互订阅保留既有有界生命周期。editorPolicy 默认 commit；cancel 取消尚未提交的组合输入，普通已提交编辑仍由模型保留。

register({id, root, kind, anchor?, initialFocus?, closeOnEscape?, closeOnOutside?, backdropColor?, backdropAlpha?}) 返回可重复释放的注册句柄。根必须真实、存活，并使用同一 Engine 和完全相同的指针及可选键盘通道；结构复制和其他引擎的根会被拒绝。kind 为 base、popup 或 modal。基础层持续可见；覆盖层在首次 sync 后隐藏。根仍归调用者所有。注册期间不能替换根的共享指针通道。注册、sync 和视口发布应在输入分发与帧回调之外执行；生命周期退役仍可在输入分发或 Scope、Engine 关闭期间执行。

open(id)、close(id) 和 setViewport(rect) 仅记录意图。关闭覆盖层也会关闭其上全部覆盖层；基础层不能开关。调用者完成相关根的 prepare/commit 后，再调用 sync()，在原生编辑器同步与帧捕获前发布位置、顺序和交互资格。结果包括 committed、unchanged、pending 或 closed，以及已提交意图修订和 postCommitErrors。onInvalidate 请求调用者沿同一流程发布，不递归通知重入失效；下次结果返回前最多保留64个观察回调错误。通知失败，包括抛出 undefined，都不意味着已发布状态回滚。

## 几何与发布

锚点指向另一个已注册根中已提交的叶节点或可见稳定键行。边界与根、列表裁剪相交；隐藏、回收、删除和完全裁出视口的锚点不可用。绑定的是注册身份，重复使用 id 不会复活旧锚点。弹出层优先位于下方（默认逻辑间距4）或指定的上方；另一侧可容纳时翻转，然后约束在给定视口内。在横向上，align 决定哪两条边对齐：start（默认）让覆盖层的起始边对齐锚点的起始边，center 对齐两者的中心，end 对齐两者的末端，例如挂在一行末尾职务框下面的菜单；结果同样约束在视口内。无锚点的覆盖层居中。覆盖层大于视口时以 UI_LAYER_VIEWPORT_TOO_SMALL 拒绝并保留先前发布；调用者需要提供合适的布局与视口。

覆盖层根在 Stage 上排序，脱离锚点的滚动裁剪，同时保留自身内容裁剪。本配置继承托管 UI 的单位 Stage 变换，不猜测 CSS 变换、不旋转原生编辑器，也不压缩段落以强行容纳。

新覆盖层打开时等待就绪的已提交内容。关闭已经发布的覆盖层不等待无关或尚未完成的内容。层呈现与内容布局使用独立代次：旧内容准备凭证会过期，不能恢复过时的可见与命中状态。位置、隐藏和焦点资格调整复用已提交行，无须重新测量或绑定。UiSnapshot.layerRevision 仅在层托管发布后出现；原有内容修订含义保持不变。

先验证，再取消活动接触，并在取消回调之后重新验证。意图、根或内容修订改变时，旧续接返回 pending。根与背景屏障在没有应用回调的区间内发布，之后才通知原生编辑器和焦点。调用者完成后续内容提交并再次 sync，不增加隐藏重试循环，也不伪造事务回滚。

## 指针、键盘和原生编辑

命中、捕获和取消由既有指针通道提供。独立 Scope 中的背景屏障位于覆盖层之后，消费层外接触，包括用于关闭弹出层的第一次接触，不将激活传给底层场景。弹出层默认在层外接触结束时关闭；模态层默认不关闭。最高模态层下方的根不接受指针。层发布改变前取消活动接触；移动与动作控件及其贡献责任保持不变。

最上方覆盖层包含逻辑键盘与原生编辑焦点。Tab、Shift+Tab 仅在其真实根内的合格目标之间循环，排除同通道的其他注册目标。没有可遍历子项时，由私有哨兵保留 Escape 入口。initialFocus 使用现有已实现列表行，否则由现有通道选择有效目标。Escape 仅关闭最上方可关闭层；组合输入仍按输入法自己的 Escape 语义处理。

后台原生编辑会话按 editorPolicy 收口，释放 DOM 控件、字体租约和行保留。恢复交互或逻辑焦点不会自动弹出键盘。关闭时仅恢复仍合格的保存目标，否则在存活层中选择有效目标。删除、隐藏或回收的目标不能因保存了 id 而复活。这是逻辑焦点包含，不等于完整浏览器语义、inert 或辅助技术实现。

## 生命周期与示例

每个已注册覆盖层在独立 Scope 中持有一个背景屏障，重复开关直接复用；取消注册、根关闭和管理器关闭会释放监听、焦点目标注册和该 Scope。管理器释放后保留借用的根与输入通道，恢复基础层、隐藏覆盖层。应用在输入分发之外释放视图，再通过常规路径释放根与 Scope。示例真正改变宽度时重建视图，继续使用相同模型、字体和缓存，并保留层栈、草稿与选择；仅键盘高度变化时保留当前视图。

现有[原生编辑表单](https://github.com/cnedwin/Egret_rebuild/blob/main/examples/text-editing/README.zh-CN.md)提供 layers=1 可选模式：列表 → 资料详情 → 重命名 → 详情或列表。重命名使用草稿模型，保存才写入原始字段，取消保留原值。UI 根与原生编辑器共享已有字体替换和生命周期；默认与固定夹具分别保留。

[下拉示例](https://github.com/cnedwin/Egret_rebuild/blob/main/examples/ui-dropdown/README.zh-CN.md)把一个弹出层锚定在滚动列表中被激活的那一行上，使用 align end，并且每换一行就重新注册一次。下面的设备结果早于 align 和这个示例。

## 证据与剩余工作

[有界结果摘要](https://github.com/cnedwin/Egret_rebuild/blob/main/examples/text-editing/layer-verification-summary.json)记录实际源码身份与检查。CPU SDK/类型结果、桌面 WebGL2/WebGPU、模拟响应式尺寸和实体设备结果分别标注。首次 Android 验证受锁屏限制而拒绝，并恢复了原状态。设备解锁后，在 SM-F966U1／Android17 上通过注入接触及实际三星软键盘组合输入，分别观察 WebGPU、WebGL2，共32项断言，覆盖系统旋转、前后台、保存与取消、字体替换和活动会话关闭。两项源码问题已修复，原失败保留。这是当前设备的有限结果，不代表完整手机、输入法或辅助技术资格；开发会话结束时恢复临时 USB 唤醒设置的原值。

完整控件、手势仲裁、语义投影、真实输入法、iPhone、辅助技术、完整 M3.4/#90 与 M4 验收继续 OPEN。M1.2 仍为10.3ms、目标8ms。原有11个工作包和贡献者范围不变。本增量按白鹭契约独立实现，没有引入第三方代码或新素材；既有字体、提供器和运行时声明及历史记录保持完整。

手机补充验证区分程序化回退焦点和实际键盘遍历。真正改变宽度时，先结束重命名组合输入，再保存草稿与选区；结束会话不会将草稿保存到原始模型。
