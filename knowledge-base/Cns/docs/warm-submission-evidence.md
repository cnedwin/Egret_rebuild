初次聚焦集成运行保留了 353 例通过、25 例失败。后继测试改为观察实际 setBindGroup 选择的资源，区分待完成隔离、空闲保留与关闭时销毁；真正的临时 staging 保留退休故障覆盖。待完成量计费、重入、首个原因及只清理一次的断言仍保留。误以为相邻矩形不会合并的压力夹具，现改为分别提交 144 字节和 288 字节请求。失败与修正后的尝试均保留。

最初裁剪计数器计入了模拟 writeTexture 日志的拷贝；修正后的同步窗口在首次原生 error scope 调用前结束。辅助模块首次 Node 24 运行仅为补充，随后已在固定 Node 26.7.0 上重跑。被拒绝的 B1 筛选／非规范调用不计验收；接受的完整调度采用当前场景循环中的变异锚点。控制执行器现拒绝继承的 Node 执行参数／选项／路径，并显式使用已验证的子进程环境，其 23 项入口检查及最终六组重跑通过。这些受控失败不证明物理分配失败或实际耗时性能。

专用原生结果记录 Windows x64、无附加启动参数的无头 Edge 155.0.4283.45 与 Playwright 1.62.1。109 模块运行闭包完整，服务清单含夹具、oracle 与 HTML 共 112 行。保留的 402 项输入身份和 70 项产物均经独立核验。回执匹配当前十一节点产品图中的十项，未保留不参与执行的私有 prepareTexturedSubmission2D.d.ts；该声明另有当前图、源码边界与构建／类型证据，不能合称原生十一节点覆盖。

原生 API／读回与分配计数证据不证明硬件加速、移动端支持、物理显存、功耗、持续性能、设备丢失恢复或独立 OS 子进程退休。0.61 的专用缓存矩阵继续保留历史 OPEN，除非明确的覆盖评审接受后继证据。完整 UI、完整 Spine、目标宿主和迁移仍为独立里程碑。实现、夹具和文档为采用 AI 辅助的第一方 Apache-2.0 成果，不增加运行时依赖。
