# 显示拾取应用与有界证据

[English](../../en/docs/display-picking-example.md) | 简体中文

工程预览 **0.30.0** 将既有 HT1 查询组合成小型应用：自定义矩形、CSS 鼠标坐标、真实类型化分发与显式 Canvas 渲染。它增加示例代码，不增加 SDK 输入路由或包 API。包保持 private `0.0.0`、协议 `1.0`。参阅[运行指南](../../../examples/hit-test/README.zh-CN.md)及既有 [HT1 契约](显示命中HT1.md)。

## 自定义行为

320×200 逻辑场景含 Stage 在内共九个节点、五个合格角色。画布 CSS 大小为 640×400，无 border／padding；坐标减去 CSS 原点后缩放到逻辑单位，不做截断、舍入或 DPR 修正。仅准入有限的主鼠标左键输入。真实 `Stage.hitTest` 使用 `maxNodes: 9`。

| 字面逻辑点 | 示例预期结果 |
| --- | --- |
| (56, 48) | 上层；隐藏上层后显示下层命中。 |
| (168, 32) | 被裁剪的绿色子节点；隐藏祖先或关闭祖先 touchChildren 后压制输入。关闭 touchChildren 时仍渲染绿色。 |
| (16, 128) / (48, 136) | 左／右；共享边界属于右侧。 |
| (80, 136) / (20, 160) | 超出右／底半开边界，未命中。 |

五个角色监听者、Stage 捕获、root 冒泡及 Stage 冒泡构成八个 Scope 订阅。成功拾取分发真实 `Event`，负载为冻结的 `{globalX, globalY, button, pointerType}`。四条监听记录分别表示 Stage 捕获、被选角色 atTarget、root 冒泡及 Stage 冒泡。监听者记录路径；分发返回后，场景代码清除／重绘一个反馈矩形并渲染一次，反馈不由监听者绘制。未命中保存负载、清空路径，不分发也不渲染。

## 所有权与启动

应用管理六组目标／类型／回调／capture：pointerdown、三个切换 click、Close 与 pagehide。缓存的同一个关闭 Promise 禁止回调、尝试每次监听移除，再等待获取完成、释放 Scope／Engine 并将借用画布归零／移除。获取不等待 Close。延迟 Engine 会被保留供清理，不发布场景；首次渲染中关闭后，在发布 Ready 前再次复核阶段。显式失败标志保留首个抛出的 `undefined`，随后清理继续。Scope signal 取消后尝试八个类型化取消订阅闭包。Main 仅导出标量观察和共享关闭操作。
