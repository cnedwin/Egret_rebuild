## 已实现能力与范围

显式 `@egret/engine/webgl2` 入口导出 `createSharedWebGL2Host` 及九个擦除类型；显式 `@egret/engine/webgl2/scene3d` 入口导出固定的 `createSharedSceneWebGL2Host` 别名及两个擦除类型。默认 Engine 与 Canvas 入口不加载 WebGL2 模块。Host 消费既有真实共享帧、图像／页身份及固定场景值；Engine、Stage、Scope、资源、租约及游戏时钟继续作为共用权威。

[契约](webgl2-executor-contract.md)规定有序准入、精确 GL 状态与颜色配方、整记录 arena、有界 PBO/fence 退役、generation token、就绪及 context 恢复。共享存储与保留内部模块已提取，同时保留原 WebGPU 包装层行为。实现不提供自定义 shader、原生对象、调用方场景插件或通用后端注册表。

M1.4 从 M1.3 已交付的 main `10a37d9dfdeb8762eced73577282127d1c4e4bde`、[PR #75](https://github.com/cnedwin/Egret_rebuild/pull/75) 继续。[M1 计划](m1-rendering-resource-plan.md)仍将 M1.5 统一会话／资源清单／持续恢复与 M1.2 正式计时单独列为工作。安全关闭、Host 就绪或操作数下降均不能证明这些目标。

## 保留的失败与修复

首次原始资格验证为 INCOMPLETE：在失效事件 microtask 内请求恢复，早于事件分发结束。经过评审的修复把请求移至下一事件循环任务，原期限及参考不变。第二次运行通过，第一次记录继续保留。

受控回归暴露了生命周期与所有权缺口，包括关闭／失效竞争、可失败所有者退役、固定对象解绑、实际 backing 尺寸、待决准入、恢复尝试期限、未知创建计费及完成证明内失效。最终 G18–G20 进一步暴露关闭时跳过剩余所有者／监听器、部分恢复后残留固定句柄，以及已确认失效被错误记为 unknown。分别清理、重置各 generation 字段、保留已确认失效语义修复这些情况。此前 RED 日志及卡住轮询器的有界终止记录继续保留。

## 复现与剩余验收

使用文档固定工具链与构建产物。有限公开声明检查为 `node tools/shared-webgl2-types.mjs`。两个原生工具使用已安装 Playwright，以及仓库／依赖所有者目录之外、尚不存在的绝对输出目录：

    node tools/verify-shared-webgl2.mjs --playwright <absolute-installed-playwright-directory> --channel msedge --output <absolute-fresh-pixel-output>
    node tools/verify-shared-webgl2-lifetime.mjs --playwright <absolute-installed-playwright-directory> --channel msedge --output <absolute-fresh-lifetime-output>

第一入口负责固定像素／指定反例矩阵；第二入口负责单独的有限生命周期／深度／状态计划，其公开后继已有单独保留并通过独立复核的成功结果。产品清理不主动制造原生失效；生命周期夹具使用浏览器真实 `WEBGL_lose_context` 扩展，真实失效／恢复不可用时记为 INCOMPLETE。额外提出的错误深度／状态变异差值未执行，不获得验收计入。
