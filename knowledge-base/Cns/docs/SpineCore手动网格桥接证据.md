## 原始数值与所有权 oracle

程序生成夹具有一张 16 × 16 页面、四顶点非加权网格、六个索引、两根骨骼及一秒 `bend` 动画，采用线性平移与稀疏分量 deform。字面理想表使用时间 **0、0.25、0.5、0.75、1**。仅对这五个样本，位置分量使用预先确定的绝对误差界 **2^-19 = 0.0000019073486328125**，相对容差为零。UV、索引及白色 light color 精确一致。此前同一宿主重复／后退几何使用零容差；旧几何与捕获帧字节不变。

误差界在姿态执行前，依据固定 Core 角度常量、宿主三角函数前提、binary64 余量及 Float32 舍入推导；没有拟合实际 Core 输出，也没有在失败后扩大界限。保存用例记录包含通过／失败观察，不包含逐分量实测值；此处不编造数值测量。该误差界不通用于所有准入源、任意时间、其他运行时版本或物理渲染。
