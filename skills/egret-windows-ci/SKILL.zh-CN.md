# 白鹭 Windows CI

[English](SKILL.md) | 简体中文

每种独立失败都形成准确诊断、有界修复及可复用的预防决定。本 Skill 不增加发布或账号操作授权。

## 接收现场

读取当前 PR 的 head／base，以及实际失败的 Windows 作业、运行／尝试次数、步骤和日志。原始记录只采集一次，保存到工程外的私有证据目录。保留结果须绑定输入；PR 更新时间变化不等于新增源码提交。在已配置的 Windows 维护者机器上遇到 Git 上下文或凭据失败，先使用已安装的 `$egret-windows-git` 入口，再考虑昂贵检查；不能为修复测试拒绝而重置账号。

离线工具支持已保存的作业 JSON、普通日志，以及现有 API 工具的 `{status,data}` 响应：

```text
node <skill-directory>/scripts/summarize-windows-failure.mjs --job <job.json> --log <log-recording> --head <expected-head-sha> --out <new-private-receipt.json>
```

工具保留输入原始哈希、拒绝覆盖，生成诊断候选。退出码 0 只表示记录处理完成，失败作业或 head 不符也可如此；它不是 CI 成功或准入结果。依据源码证据补齐待确认根因和后续字段。工具不会访问 GitHub、重跑或审批；作业 head 也不证明实际合并预览检出，准入合并候选时须另行核对。

## 按实际停止点判断

| 观察 | 先调查 | 长期处理 |
| --- | --- | --- |
| `SS1_BOUNDARY_SOURCE_OWNER`／整组身份变化 | 实际变化的源码／产物与所有者记录 | 正确源码稳定后建立一次经评审的当前接续，保留历史钉子 |
| 切分支／依赖变化后工作区包缺失 | 声明依赖、实际工作区链接和导入来源 | 在昂贵检查前恢复固定版本的锁文件安装；不手建别名，也不修改源码钉子 |
| 模块解析／复制夹具过期 | 真实依赖闭包与文件所有者 | 修复夹具／闭包及对应聚焦控制 |
| 原始字节／路径卫生 | 实际字节与明确的 Windows 物理路径语义 | 规范作者入口和共享身份工具，不归一化哈希 |
| 断言／编译器诊断 | 区分产品、策略与夹具 | 最小复现及受影响回归 |
| 日志缺失／作业未结束 | 作业状态、实际步骤和服务证据 | 保持未完成；无日志不证明容量故障 |

以实际终止拒绝为依据，不能把预期负向测试输出当作根因。签名只标识失败域，不证明根因；保留原失败与未知项。

## 修复与收口

记录身份、停止点、已核实根因／责任方、变化输入、聚焦结果、复用证据、剩余必需检查及预防措施。复用输入未变的成功证据，只补受影响部分和最终候选的必需保护检查。已确认的基础设施重试保留同候选成功作业；head／base／tree 变化时重新判断证据适用性，不自动重放全部历史检查。

扩展源码所有者文件时，先核对读取历史标记之前前缀的有界读取器及逆向夹具。新增内容应使用既有读取器准入语法，或移出该前缀；不能为偶然的语法变化扩大读取器权限。

新增可选 SDK 入口而改变包导出或私有别名时，除共享门禁外，还应核对现有的各个独立包／源码所有者。当前原始字节检查与旧语义导出投影可能都需要同一项有界新增。用准确逆向变换证明每份完整前身；图数量应从该所有者的实际闭包推导，不能照搬另一清单的数量。下次推送候选前集中执行受影响的独立检查，保留全部原钉子和拒绝断言。

采集器准入经评审的当前接续时，核对全部当前身份测试消费者。选择同一个有界当前映射，明确断言其成员及当前／前身身份，保留历史表和未知字节拒绝控制。当前断言过期应修正测试，不能据此改变运行时字节、采集成员或重跑输入未变的浏览器／设备证据。

状态机修复应一起核对准入的终止、所有权与错误边界，包含既有冒泡及回调失败，不按单个标量例子反复补丁。浏览器／设备／性能验收分别保留。

更新既有根因类别与工作包。仅在能改变今后处理时增加回归、明确所有者／准入或小范围修订 Skill；不能每出现一次就建立维护框架。保留正常钩子、独立评审、公开双语文档和分支保护。不能重算封存历史、豁免真实失败、绕过钩子，或用手工子集通过冒充完整 CI。

已注册的源码声明前缀中，哈希断言使用 new RegExp，避免正则字面量；现有读取器有意拒绝未加引号的斜线、模板和除法。下次推送前运行相关声明与逆向还原用例，不能只检查直接源码图基线；不扩展读取器权限。
